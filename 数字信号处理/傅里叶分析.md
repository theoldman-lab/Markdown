# 傅里叶分析

## 引言

### 0.1 为什么是复指数——LTI 系统的特征函数

线性时不变（LTI）系统分析的核心在于：寻找一类信号，使其通过系统后形式不变，仅大小和相位发生变化：

$$
\begin{aligned}
\text{连续：} &\quad y(t) = h(t) * e^{j\omega t} = H(j\omega)\, e^{j\omega t} \\[4pt]
\text{离散：} &\quad y[n] = h[n] * e^{j\omega n} = H(e^{j\omega})\, e^{j\omega n}
\end{aligned}
$$

其中 $H(j\omega) = \int_{-\infty}^{+\infty} h(t) e^{-j\omega t} dt$ 和 $H(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} h[n] e^{-j\omega n}$ 分别称为连续和离散系统的**频率响应**。复指数信号是 LTI 系统的**特征函数**，频率响应是**特征值**。

由此产生频域分析的基本范式：将任意信号表示为复指数信号的线性组合，则系统输出 = 每个分量乘以对应的特征值再叠加。傅里叶分析的本质就是回答两个问题：

1. **分析**（Analysis）：信号的复指数分解——求各分量的权重
2. **综合**（Synthesis）：从频域权重恢复原信号

---

### 0.2 信号的四种基本形态与五种变换

信号按其时间域的两个属性——**连续/离散**与**周期/非周期**——共形成四种基本组合，对应五类傅里叶变换：

| 时域属性 | 周期 | 非周期 |
|---------|------|-------|
| **连续** | **CFS**（连续傅里叶级数）<br>时域连续周期 → 频域离散、非周期 | **CFT**（连续傅里叶变换）<br>时域连续非周期 → 频域连续、非周期 |
| **离散** | **DFS**（离散傅里叶级数）<br>时域离散周期 → 频域离散、周期 | **DTFT**（离散时间傅里叶变换）<br>时域离散非周期 → 频域连续、周期 |

第五种变换 **DFT**（离散傅里叶变换）是 DTFT 的频域等间隔采样，专为有限长序列设计，也是唯一可在计算机上直接计算的变换。

---

### 0.3 时域-频域对偶法则

五种变换的时域与频域属性始终通过公式结构直接体现——无需死记，直接看公式：

**"连续 vs 非周期"**：表达式中出现连续变量上的积分 $\int d\omega$ 或 $\int dt$，意味着该域是连续的（也是非周期的）。例如 CFT 的综合方程对 $\omega$ 做全实轴积分 $\int_{-\infty}^{+\infty} \dots d\omega$，表明时域连续。

**"离散 vs 周期"**：表达式中出现离散求和 $\sum_k$ 或 $\sum_n$，意味着该域是离散的。如果求和范围是有限的（如 $\sum_{k=0}^{N-1}$），则该域同时也是周期的。例如 CFS 的综合方程将 $x(t)$ 表示为 $\sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t}$——求和指标 $k$ 取全体整数，频域离散且非周期。

具体对照：

| 公式形式 | 体现的域属性 | 例子 |
|---------|-------------|------|
| $\displaystyle\sum_{k=-\infty}^{+\infty} a_k$ | 该域**离散** | CFS 综合：$x(t) = \sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t}$（频域离散） |
| $\displaystyle\sum_{n=0}^{N-1} x[n]$ | 该域**离散且周期** | DFS 综合：$\tilde{x}[n] = \sum_{k=0}^{N-1} \tilde{X}[k] e^{jk\frac{2\pi}{N}n}$（频域离散、周期 $N$） |
| $\displaystyle\int_{-\infty}^{+\infty} X\,d\omega$ | 该域**连续非周期** | CFT 综合：$x(t) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$（频域连续非周期） |
| $\displaystyle\int_{-\pi}^{\pi} X\,d\omega$ | 该域**连续且周期** | DTFT 综合：$x[n] = \frac{1}{2\pi}\int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$（频域连续、周期 $2\pi$） |
| $\displaystyle\sum_{n=0}^{N-1} x[n] e^{-jk\frac{2\pi}{N}n}$ | 该域**离散** | DFS/DFT 分析：$n$ 为离散求和 → 时域离散 |

总结为两条：**积分 → 连续（非周期），有限求和 → 离散周期**。DFT 处于公式完全对称的终点——分析方程和综合方程均为有限求和 $\sum_{n=0}^{N-1}$，时域和频域对等。

## 1. 周期信号的傅里叶分析

周期信号在时域仅占用一段有限区间即可描述整个信号。从公式上看：综合方程 $x(t) = \sum_{k} a_k e^{jk\omega_0 t}$ 的求和指标 $k$ 取离散整数值——时域周期直接表现为频域离散谱线（而非连续积分）。这是"**时域周期 ⇔ 频域离散**"对偶法则的第一个体现。

---

### 1.1 连续周期信号：傅里叶级数（CFS）

#### 1.1.1 正交性

连续周期信号 $x(t) = x(t + T)$，基频 $\omega_0 = 2\pi/T$。复指数谐波族 $\phi_k(t) = e^{jk\omega_0 t}$（$k \in \mathbb{Z}$）在区间 $[t_0, t_0+T]$ 上两两正交：

$$
\int_{T} e^{jk\omega_0 t} e^{-jl\omega_0 t}\, dt =
\begin{cases}
T, & k = l \\
0, & k \neq l
\end{cases}
$$

#### 1.1.2 分析-综合方程

利用正交性作投影，得 CFS 的分析与综合方程：

$$
\boxed{
\begin{aligned}
\text{综合：}&\quad x(t) = \sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t} \\[4pt]
\text{分析：}&\quad a_k = \frac{1}{T} \int_{T} x(t) e^{-jk\omega_0 t} dt
\end{aligned}
}
$$

**对偶解读**：
- 综合方程中求和指标 $k$ 取全体整数（$k \in \mathbb{Z}$）→ 频域是**离散**的
- 分析方程中对 $t$ 做连续积分 $\int_T dt$ → 时域是**连续**的；积分区间为单周期 $[0,T]$ → 时域是**周期**的
- $a_k$ 无周期约束（$k$ 取遍 $\mathbb{Z}$，$a_k$ 本身不满足 $a_{k+N}=a_k$）→ 频域是**非周期**的

- $a_k$ 为第 $k$ 次谐波的**复权重**，$|a_k|$ 为幅度、$\angle a_k$ 为相位
- $a_0 = \frac{1}{T}\int_T x(t)dt$ 为**直流分量**（周期平均值）
- $k < 0$ 的谐波用于构成实数信号的共轭对

实信号满足 $a_{-k} = a_k^*$，可写为三角形式：

$$
x(t) = a_0 + \sum_{k=1}^{+\infty} \bigl[ A_k \cos(k\omega_0 t) + B_k \sin(k\omega_0 t) \bigr]
$$

其中 $A_k = a_k + a_{-k} = 2\,\text{Re}(a_k)$，$B_k = j(a_k - a_{-k}) = -2\,\text{Im}(a_k)$。

#### 1.1.3 收敛性与吉布斯现象

**狄利克雷充分条件**：$x(t)$ 在一个周期内满足：① 绝对可积 $\int_T |x(t)| dt < \infty$；② 有限个极值点；③ 有限个第一类间断点。则：

- 在连续点：级数收敛于 $x(t)$
- 在间断点：收敛于 $\frac{x(t^+) + x(t^-)}{2}$（左右极限均值）

**吉布斯现象**：用 $N$ 项部分和 $x_N(t) = \sum_{k=-N}^{N} a_k e^{jk\omega_0 t}$ 逼近含跳变的信号时，跳变点附近出现过冲，幅度约为跳变高度的 **$9\%$**（$\approx 0.0895$ 倍）。该过冲不因 $N$ 增大而消失，仅向跳变点压缩。

#### 1.1.4 对称性

| 对称性 | 条件 | CFS 系数特点 |
|--------|------|-------------|
| 偶对称 | $x(-t) = x(t)$ | $a_k$ 为实数，仅余弦项 |
| 奇对称 | $x(-t) = -x(t)$ | $a_k$ 为纯虚数，仅正弦项 |
| 半波奇对称 | $x(t \pm T/2) = -x(t)$ | $a_k = 0$（$k$ 为偶数），仅奇次谐波 |

#### 1.1.5 典型信号的 CFS 系数

| 信号 | $a_k$ | 衰减规律 |
|------|-------|---------|
| 余弦 $\cos(\omega_0 t)$ | $a_{\pm 1} = 1/2$，其余 $=0$ | 单频线谱 |
| 方波（奇对称） | $a_k = \begin{cases} 0, & k \text{ 偶} \\ 2A/(jk\pi), & k \text{ 奇} \end{cases}$ | $\sim 1/k$ |
| 三角波（偶对称） | $a_k = \begin{cases} 4A/(k^2\pi^2), & k \text{ 奇} \\ 0, & k \text{ 偶} \end{cases}$ | $\sim 1/k^2$ |
| 锯齿波 | $a_0 = A/2$，$a_k = A/(jk\pi)$（$k \neq 0$） | $\sim 1/k$ |
| 周期冲激串 $\sum_n \delta(t - nT)$ | $a_k = 1/T$（所有 $k$） | 均匀谱 |

**衰减规律**：信号越平滑，高次谐波衰减越快——方波（有间断）$\sim 1/k$，三角波（连续但尖点）$\sim 1/k^2$。

#### 1.1.6 CFS 的性质

| 性质 | 时域 | 频域（CFS 系数） |
|------|------|-----------------|
| **线性** | $A x(t) + B y(t)$ | $A a_k + B b_k$ |
| **时移** | $x(t - t_0)$ | $a_k e^{-jk\omega_0 t_0}$ |
| **频移** | $e^{jl\omega_0 t} x(t)$ | $a_{k-l}$ |
| **时间反转** | $x(-t)$ | $a_{-k}$ |
| **尺度变换** | $x(at)$ | $a_k$ 形式不变，基频变为 $\|a\|\omega_0$ |
| **一阶微分** | $\dfrac{dx}{dt}$ | $jk\omega_0 a_k$ |
| **$n$ 阶微分** | $\dfrac{d^n x}{dt^n}$ | $(jk\omega_0)^n a_k$ |
| **一阶积分** | $\int x(t) dt$ | $\dfrac{a_k}{jk\omega_0}$（$k \neq 0$） |
| **周期卷积** | $\dfrac{1}{T}\int_T x(\tau) y(t-\tau) d\tau$ | $a_k b_k$ |
| **时域相乘** | $x(t) y(t)$ | $\displaystyle\sum_{l=-\infty}^{+\infty} a_l b_{k-l}$ |
| **帕斯瓦尔** | $\displaystyle\frac{1}{T}\int_T \|x\|^2 dt$ | $\displaystyle\sum_{k=-\infty}^{+\infty} \|a_k\|^2$ |

> **注**：CFS 的时域乘 $t$ 会破坏周期性，因此不存在与 FT 对应的频域微分/积分性质。

### 1.2 离散周期序列：离散傅里叶级数（DFS）

#### 1.2.1 正交性

周期为 $N$ 的序列 $\tilde{x}[n] = \tilde{x}[n+N]$，基频 $\omega_0 = 2\pi/N$。谐波族 $\phi_k[n] = e^{jk\frac{2\pi}{N}n}$ 满足：

$$
\sum_{n=0}^{N-1} e^{j(k-l)\frac{2\pi}{N}n} =
\begin{cases}
N, & (k-l) \equiv 0 \pmod{N} \\
0, & \text{其他}
\end{cases}
$$

与连续情况的本质区别：由于 $e^{j(k+N)\frac{2\pi}{N}n} = e^{jk\frac{2\pi}{N}n}$（离散复指数的频率周期性），**仅有 $N$ 个独立谐波**。周期为 $N$ 的信号只需 $N$ 个复指数即可精确表示——这是离散系统固有的有限维特性。

#### 1.2.2 分析-综合方程

$$
\boxed{
\begin{aligned}
\text{综合：}&\quad \tilde{x}[n] = \sum_{k=0}^{N-1} \tilde{X}[k] e^{jk\frac{2\pi}{N}n} \\[4pt]
\text{分析：}&\quad \tilde{X}[k] = \frac{1}{N} \sum_{n=0}^{N-1} \tilde{x}[n] e^{-jk\frac{2\pi}{N}n}
\end{aligned}
}
$$

**对偶解读**：
- 综合方程中的求和 $\sum_{k=0}^{N-1}$ 是**有限范围** → 频域**离散且周期**（$\tilde{X}[k+N]=\tilde{X}[k]$，仅有 $N$ 个独立值）
- 分析方程中的求和 $\sum_{n=0}^{N-1}$ 也是**有限范围** → 时域**离散且周期**（$\tilde{x}[n+N]=\tilde{x}[n]$）

- $\tilde{X}[k]$ 本身也是周期为 $N$ 的周期序列
- 求和区间可任取连续的 $N$ 点（索引 $\bmod N$）
- **有限求和 vs 无穷级数**：DFS 综合方程仅含 $N$ 项，是精确的有限表示，不存在收敛性问题

#### 1.2.3 DFS 的性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $a\tilde{x}_1[n] + b\tilde{x}_2[n]$ | $a\tilde{X}_1[k] + b\tilde{X}_2[k]$ |
| **时移** | $\tilde{x}[n - n_0]$ | $e^{-jk\frac{2\pi}{N}n_0} \tilde{X}[k]$ |
| **频移** | $e^{jl\frac{2\pi}{N}n} \tilde{x}[n]$ | $\tilde{X}[k - l]$ |
| **时间反转** | $\tilde{x}[-n]$ | $\tilde{X}[-k]$ |
| **共轭** | $\tilde{x}^*[n]$ | $\tilde{X}^*[-k]$ |
| **周期卷积** | $\displaystyle\sum_{m=0}^{N-1} \tilde{x}_1[m] \tilde{x}_2[n-m]$ | $N \tilde{X}_1[k] \tilde{X}_2[k]$ |
| **时域相乘** | $\tilde{x}_1[n] \tilde{x}_2[n]$ | $\displaystyle\frac{1}{N}\sum_{l=0}^{N-1} \tilde{X}_1[l] \tilde{X}_2[k-l]$ |
| **一阶差分** | $\tilde{x}[n] - \tilde{x}[n-1]$ | $(1 - e^{-jk\frac{2\pi}{N}}) \tilde{X}[k]$ |
| **帕斯瓦尔** | $\displaystyle\frac{1}{N}\sum_{n=0}^{N-1} \|\tilde{x}[n]\|^2$ | $\displaystyle\sum_{k=0}^{N-1} \|\tilde{X}[k]\|^2$ |

实序列的共轭对称性（$\tilde{X}[N-k] = \tilde{X}^*[k]$）使得：
- $|\tilde{X}[k]|$ 偶对称，$\arg\tilde{X}[k]$ 奇对称
- $\tilde{X}[0]$ 为实数；$N$ 为偶数时 $\tilde{X}[N/2]$ 也是实数

#### 1.2.4 典型周期序列的 DFS

| 时域信号 | DFS 系数 $\tilde{X}[k]$ | 说明 |
|---------|------------------------|------|
| $\tilde{x}[n] = 1$ | $\begin{cases} 1, & k = 0 \\ 0, & k \neq 0 \end{cases}$ | 直流 |
| $e^{jk_0\frac{2\pi}{N}n}$ | $\begin{cases} 1, & k = k_0 \\ 0, & k \neq k_0 \end{cases}$ | 单频复指数 |
| $\cos(k_0\frac{2\pi}{N}n)$ | $\begin{cases} 1/2, & k = \pm k_0 \\ 0, & \text{其他} \end{cases}$ | 实余弦 |
| $\sin(k_0\frac{2\pi}{N}n)$ | $\begin{cases} -j/2, & k = k_0 \\ j/2, & k = -k_0 \\ 0, & \text{其他} \end{cases}$ | 实正弦 |
| 周期矩形脉冲串（宽 $L$，$L \leq N$） | $\tilde{X}[k] = \dfrac{1}{N} \cdot \dfrac{1 - e^{-jk\frac{2\pi}{N}L}}{1 - e^{-jk\frac{2\pi}{N}}}$ | Dirichlet 核 |
| 周期冲激串（间隔 $N$） | $\tilde{X}[k] = 1/N$ | 均匀谱 |

---

### 1.3 CFS 与 DFS 对比

| 特征 | CFS | DFS |
|------|-----|-----|
| **时域域** | 连续时间 $t$ | 离散时间 $n$ |
| **周期** | 连续值 $T$（任意正实数） | 整数 $N$（任意正整数） |
| **基频** | $\omega_0 = 2\pi/T$（连续值） | $\omega_0 = 2\pi/N$（固定步长） |
| **独立谐波数** | $\infty$ | $N$ |
| **综合方程** | 无穷级数 $\sum_{k=-\infty}^{+\infty}$ | $N$ 项有限求和 $\sum_{k=0}^{N-1}$ |
| **分析方程** | 连续积分 $\frac{1}{T}\int_T$ | 离散求和 $\frac{1}{N}\sum_{n=0}^{N-1}$ |
| **频域特征** | 离散、非周期 | 离散、周期（$N$） |
| **收敛性** | 需要狄利克雷条件 + 吉布斯现象 | 有限项精确表示，无收敛问题 |
| **积分/求和区间** | 任一长度为 $T$ 的区间 | 任一 $N$ 个连续整数（$\bmod N$） |

**CFS → DFS 的抽样桥梁**：对连续周期信号 $x(t)$（周期 $T$）在一个周期内均匀采样 $N$ 点，得离散周期序列 $\tilde{x}[n] = x(nT/N)$。若 $x(t)$ 的 CFS 系数 $a_k$ 仅在 $|k| < N/2$ 内非零（带限信号），则采样后的 DFS 系数 $\tilde{X}[k]$ 与 CFS 系数满足：

$$
\tilde{X}[k] = \frac{1}{N} \sum_{r=-\infty}^{+\infty} a_{k + rN}
$$

当 $N$ 足够大（$N >$ 最高非零谐波阶数的 2 倍），$\tilde{X}[k] = a_k/N$（无混叠），DFS 精确保留了 CFS 的全部信息——这正是用 DFT 在计算机上分析连续周期信号的理论基础。

## 2. 非周期信号的傅里叶分析

非周期信号可视为周期趋于无穷的周期信号。从公式上看：CFS 综合方程 $x(t) = \sum_{k} a_k e^{jk\omega_0 t}$ 中，随 $T \to \infty$，$\omega_0 = 2\pi/T \to d\omega$，求和 $\sum_{k} \to \int d\omega$——离散谱线融合为连续谱。这是"**时域非周期 ⇔ 频域连续**"的公式层面体现。

---

### 2.1 连续非周期信号：傅里叶变换（CFT）

#### 2.1.1 从 CFS 到 CFT（$T \to \infty$ 极限）

设 $x(t)$ 为有限长（或衰减足够快）的信号，构造周期延拓 $\tilde{x}(t)$（周期 $T$，基频 $\omega_0 = 2\pi/T$）。当 $T \to \infty$ 时 $\tilde{x}(t) \to x(t)$。

$\tilde{x}(t)$ 的 CFS 系数 $a_k = \frac{1}{T}\int_{-T/2}^{T/2} x(t) e^{-jk\omega_0 t} dt$。令 $X_0(j\omega) = \int_{-T/2}^{T/2} x(t) e^{-j\omega t} dt$ 为一个周期内的变换，则 $a_k = \frac{1}{T} X_0(jk\omega_0)$。代入综合方程：

$$
x(t) = \sum_{k=-\infty}^{+\infty} \frac{1}{T} X_0(jk\omega_0) e^{jk\omega_0 t}
$$

$T \to \infty$ 时 $\omega_0 = \frac{2\pi}{T} \to d\omega$，$k\omega_0 \to \omega$，$\frac{1}{T} = \frac{d\omega}{2\pi}$，求和过渡为积分，得 CFT 对。

#### 2.1.2 分析-综合方程

$$
\boxed{
\begin{aligned}
\text{分析：}&\quad X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt \\[4pt]
\text{综合：}&\quad x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega
\end{aligned}
}
$$

**对偶解读**：
- 两方程均为全实轴上的连续积分 $\int_{-\infty}^{+\infty} dt$ 和 $\int_{-\infty}^{+\infty} d\omega$ → 时域和频域**对等**：均为**连续非周期**
- $X(j\omega)$ 为连续变量 $\omega$ 的函数 → 频域连续；积分区间 $(-\infty, +\infty)$ 无周期约束 → 频域非周期

- $X(j\omega)$ 为**频谱密度**（单位频率的幅度），与 CFS 的 $a_k$ 含义不同
- 综合方程中的 $1/2\pi$ 源于 $T\to\infty$ 时 $1/T = d\omega / 2\pi$ 的尺度变换
- CFS 与 CFT 的统一关系：$a_k = \tfrac{1}{T} X(jk\omega_0)$——$a_k$ 是 $X(j\omega)/T$ 在离散频率点的采样

#### 2.1.3 收敛条件与广义 CFT

**狄利克雷充分条件**：① 绝对可积 $\int |x(t)| dt < \infty$；② 有限个极值点；③ 有限个间断点。满足时 $X(j\omega)$ 连续且 $\lim_{|\omega|\to\infty} X(j\omega) = 0$（Riemann-Lebesgue 引理）。

**广义 CFT**：对不满足绝对可积的信号（直流、阶跃、复指数），引入狄拉克 $\delta(\omega)$ 定义广义变换：

| 信号 | 绝对可积？ | 广义 CFT | 方法 |
|------|-----------|---------|------|
| $\delta(t)$ | 是 | $1$ | 直接 |
| $1$ | 否 | $2\pi\delta(\omega)$ | 对偶性 |
| $u(t)$ | 否 | $\dfrac{1}{j\omega} + \pi\delta(\omega)$ | 极限逼近 |
| $e^{j\omega_0 t}$ | 否 | $2\pi\delta(\omega - \omega_0)$ | 频移 |
| $\text{sgn}(t)$ | 否 | $\dfrac{2}{j\omega}$ | 极限逼近 |

#### 2.1.4 周期信号的 CFT

周期信号 $x(t) = \sum_k a_k e^{jk\omega_0 t}$ 也可纳入 CFT 框架：

$$
X(j\omega) = \sum_{k=-\infty}^{+\infty} a_k \cdot \mathcal{F}\{e^{jk\omega_0 t}\} = \boxed{2\pi \sum_{k=-\infty}^{+\infty} a_k \delta(\omega - k\omega_0)}
$$

周期信号的 CFT 是集中在谐波频率 $k\omega_0$ 处的等距冲激串，强度为 $2\pi a_k$。这使 CFS 成为 CFT 的特例。

#### 2.1.5 常用 CFT 变换对

| $x(t)$ | $X(j\omega)$ | 说明 |
|--------|-------------|------|
| $\delta(t)$ | $1$ | 冲激 — 均匀谱 |
| $1$ | $2\pi\delta(\omega)$ | 直流 — 零频冲激 |
| $\delta(t - t_0)$ | $e^{-j\omega t_0}$ | 时移冲激 |
| $e^{-at} u(t),\; a>0$ | $\dfrac{1}{a + j\omega}$ | 单边指数衰减 |
| $e^{-a|t|},\; a>0$ | $\dfrac{2a}{a^2 + \omega^2}$ | 双边指数衰减（洛伦兹形） |
| $\text{rect}(t/\tau)$ | $\tau\,\text{sinc}(\omega\tau/2\pi)$ | 矩形脉冲 |
| $e^{j\omega_0 t}$ | $2\pi\delta(\omega - \omega_0)$ | 复指数 — 频移冲激 |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$ | 余弦 — 对称冲激对 |
| $\sin(\omega_0 t)$ | $-j\pi[\delta(\omega - \omega_0) - \delta(\omega + \omega_0)]$ | 正弦 — 反对称冲激对 |
| $u(t)$ | $\dfrac{1}{j\omega} + \pi\delta(\omega)$ | 单位阶跃 |
| $e^{-t^2/2\sigma^2}$ | $\sqrt{2\pi}\sigma\, e^{-\sigma^2\omega^2/2}$ | 高斯脉冲（CFT 仍为高斯） |

#### 2.1.6 CFT 的性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $A x(t) + B y(t)$ | $A X(j\omega) + B Y(j\omega)$ |
| **时移** | $x(t - t_0)$ | $e^{-j\omega t_0} X(j\omega)$ |
| **频移** | $e^{j\omega_0 t} x(t)$ | $X(j(\omega - \omega_0))$ |
| **时间反转** | $x(-t)$ | $X(-j\omega)$ |
| **尺度变换** | $x(at)$ | $\dfrac{1}{\|a\|} X(j\omega/a)$ |
| **时域卷积** | $x(t) * h(t)$ | $X(j\omega) H(j\omega)$ |
| **频域卷积** | $x(t) y(t)$ | $\dfrac{1}{2\pi} X(j\omega) * Y(j\omega)$ |
| **$n$ 阶微分** | $\dfrac{d^n x}{dt^n}$ | $(j\omega)^n X(j\omega)$ |
| **一阶积分** | $\displaystyle\int_{-\infty}^t x(\tau) d\tau$ | $\dfrac{X(j\omega)}{j\omega} + \pi X(0)\delta(\omega)$ |
| **频域微分** | $t^n x(t)$ | $j^{\,n} \dfrac{d^{\,n}X}{d\omega^{\,n}}$ |
| **对偶性** | $X(jt)$ | $2\pi x(-\omega)$ |
| **帕斯瓦尔** | $\displaystyle\int_{-\infty}^{+\infty} \|x(t)\|^2 dt$ | $\displaystyle\frac{1}{2\pi}\int_{-\infty}^{+\infty} \|X(j\omega)\|^2 d\omega$ |

- 尺度变换：时域压缩 $a>1$ 对应频域展宽且幅度降低——**时宽-带宽积守恒**
- 卷积定理：时域卷积 ↔ 频域乘积是 LTI 系统频域分析的核心
- 对称性：实信号满足 $X(-j\omega) = X^*(j\omega)$（幅度偶对称、相位奇对称）；实偶信号 → 实偶频谱，实奇信号 → 纯虚奇频谱
- 对偶性：$\delta(t) \leftrightarrow 1$ 与 $1 \leftrightarrow 2\pi\delta(\omega)$ 对偶；$\text{rect}(t) \leftrightarrow \text{sinc}(\omega)$ 与 $\text{sinc}(t) \leftrightarrow \text{rect}(\omega)$ 对偶

### 2.2 离散非周期序列：离散时间傅里叶变换（DTFT）

#### 2.2.1 从 DFS 到 DTFT（$N \to \infty$ 极限）

周期序列 $\tilde{x}[n]$（周期 $N$）的 DFS 综合方程为 $\tilde{x}[n] = \sum_{k=0}^{N-1} \tilde{X}[k] e^{jk\frac{2\pi}{N}n}$。令 $\omega_k = k \cdot \frac{2\pi}{N}$，$\Delta\omega = \frac{2\pi}{N}$，改写为：

$$
\tilde{x}[n] = \frac{1}{2\pi} \sum_{k=0}^{N-1} \bigl[N\tilde{X}[k]\bigr] e^{j\omega_k n} \Delta\omega
$$

$N \to \infty$ 时 $\Delta\omega \to d\omega$，$N\tilde{X}[k] \to X(e^{j\omega})$，求和过渡为积分。

#### 2.2.2 分析-综合方程

$$
\boxed{
\begin{aligned}
\text{分析：}&\quad X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n} \\[4pt]
\text{综合：}&\quad x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega
\end{aligned}
}
$$

**对偶解读**：
- 分析方程中对 $n$ 做离散求和 $\sum_{n=-\infty}^{+\infty}$ → 时域是**离散**（非周期）的
- 综合方程中对 $\omega$ 做连续积分 $\int_{-\pi}^{\pi} d\omega$ → 频域是**连续**的；积分区间 $[-\pi,\pi]$ 恰好是 $X(e^{j\omega})$ 的一个完整周期 → 频域是**周期**（周期 $2\pi$）的
- $X(e^{j(\omega+2\pi)}) = X(e^{j\omega})$ 直接体现在综合方程的积分限中

- **$2\pi$ 周期性**：$X(e^{j(\omega + 2\pi)}) = X(e^{j\omega})$（时域离散 → 频域周期，对偶法则的直接体现）
- **连续谱**：$X(e^{j\omega})$ 是 $\omega$ 的连续函数
- $X(e^{j\omega})$ 是 $e^{j\omega}$ 的函数，记号暗示周期性

#### 2.2.3 收敛条件与广义 DTFT

| 条件 | 要求 | DTFT 性质 |
|------|------|----------|
| **绝对可和** | $\sum \|x[n]\| < \infty$ | 一致收敛，$X(e^{j\omega})$ 连续 |
| **平方可和** | $\sum \|x[n]\|^2 < \infty$ | 均方收敛（如 $\operatorname{sinc}$ 序列） |
| **广义 DTFT** | 均不满足 | 引入 $\delta(\omega)$（$u[n]$、$e^{j\omega_0 n}$） |

常数序列的广义 DTFT 为周期冲激串：$1 \leftrightarrow 2\pi \sum_{k=-\infty}^{+\infty} \delta(\omega - 2\pi k)$，与连续域 $1 \leftrightarrow 2\pi\delta(\omega)$ 的区别是频域的周期性延拓。

#### 2.2.4 DTFT 与 DFS 的关系

周期序列 $\tilde{x}[n]$（周期 $N$）的 DTFT 是其 DFS 系数构建的冲激串：

$$
X(e^{j\omega}) = 2\pi \sum_{k=-\infty}^{+\infty} \tilde{X}[k] \,\delta\!\left(\omega - \frac{2\pi k}{N}\right)
$$

这与连续域中周期信号的 CFT 为谐波频率处的冲激串完全对应。

#### 2.2.5 典型 DTFT 变换对

| $x[n]$ | $X(e^{j\omega})$ | 条件 |
|--------|-----------------|------|
| $\delta[n]$ | $1$ | 绝对可和 |
| $\delta[n - n_0]$ | $e^{-j\omega n_0}$ | 绝对可和 |
| $1$（常数序列） | $2\pi \sum_k \delta(\omega - 2\pi k)$ | 广义 |
| $a^n u[n],\; \|a\|<1$ | $\dfrac{1}{1 - a e^{-j\omega}}$ | 绝对可和 |
| $R_M[n]$（长 $M$ 矩形窗） | $e^{-j\omega\frac{M-1}{2}} \dfrac{\sin(\omega M/2)}{\sin(\omega/2)}$ | 绝对可和 |
| $\dfrac{\sin(Wn)}{\pi n},\; 0<W<\pi$ | $\begin{cases} 1, & \|\omega\| < W \\ 0, & W < \|\omega\| \leq \pi \end{cases}$ | 平方可和 |
| $a^{\|n\|},\; \|a\|<1$ | $\dfrac{1 - a^2}{1 - 2a\cos\omega + a^2}$ | 绝对可和 |
| $e^{j\omega_0 n}$ | $2\pi \sum_k \delta(\omega - \omega_0 - 2\pi k)$ | 广义 |
| $\cos(\omega_0 n)$ | $\pi \sum_k [\delta(\omega - \omega_0 - 2\pi k) + \delta(\omega + \omega_0 - 2\pi k)]$ | 广义 |
| $u[n]$（单位阶跃） | $\dfrac{1}{1 - e^{-j\omega}} + \pi \sum_k \delta(\omega - 2\pi k)$ | 广义 |

#### 2.2.6 DTFT 的性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $a x_1[n] + b x_2[n]$ | $a X_1(e^{j\omega}) + b X_2(e^{j\omega})$ |
| **时移** | $x[n - n_0]$ | $e^{-j\omega n_0} X(e^{j\omega})$ |
| **频移** | $e^{j\omega_0 n} x[n]$ | $X(e^{j(\omega - \omega_0)})$ |
| **时间反转** | $x[-n]$ | $X(e^{-j\omega})$ |
| **共轭** | $x^*[n]$ | $X^*(e^{-j\omega})$ |
| **时域卷积** | $x_1[n] * x_2[n]$ | $X_1(e^{j\omega}) X_2(e^{j\omega})$ |
| **频域卷积** | $x_1[n] x_2[n]$ | $\dfrac{1}{2\pi} \int_{-\pi}^{\pi} X_1(e^{j\theta}) X_2(e^{j(\omega - \theta)}) d\theta$ |
| **一次差分** | $x[n] - x[n-1]$ | $(1 - e^{-j\omega}) X(e^{j\omega})$ |
| **累加** | $\displaystyle\sum_{k=-\infty}^{n} x[k]$ | $\dfrac{X(e^{j\omega})}{1 - e^{-j\omega}} + \pi X(e^{j0}) \sum_k \delta(\omega - 2\pi k)$ |
| **频域微分** | $n x[n]$ | $j \dfrac{d X(e^{j\omega})}{d\omega}$ |
| **帕斯瓦尔** | $\displaystyle\sum_n \|x[n]\|^2$ | $\displaystyle\frac{1}{2\pi} \int_{-\pi}^{\pi} \|X(e^{j\omega})\|^2 d\omega$ |

- 与 CFT 的差异：微分/积分 → 差分/累加；频域卷积为 $[-\pi,\pi]$ 上的**周期卷积**
- 对称性：实序列满足 $X(e^{-j\omega}) = X^*(e^{j\omega})$；奇偶分解 $x_e[n] \leftrightarrow \operatorname{Re}\{X\}$、$x_o[n] \leftrightarrow j\operatorname{Im}\{X\}$
- 能量谱密度 $S_{xx}(\omega) = \|X(e^{j\omega})\|^2$，总能量 $E = \frac{1}{2\pi}\int_{-\pi}^{\pi} S_{xx}(\omega) d\omega$

### 2.3 CFT 与 DTFT 对比

| 特征 | CFT | DTFT |
|------|-----|------|
| **时域** | 连续时间 $t$ | 离散时间 $n$ |
| **综合方程** | $\frac{1}{2\pi}\int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$ | $\frac{1}{2\pi}\int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$ |
| **分析方程** | $\int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt$ | $\sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n}$ |
| **频域特征** | 连续、非周期 | 连续、周期（$2\pi$） |
| **积分区间** | $(-\infty, +\infty)$ | $[-\pi, \pi]$（一个周期） |
| **收敛条件** | 绝对可积 | 绝对可和 |
| **广义变换的冲激** | 单个 $\delta$ | 周期冲激串 $\sum_k \delta(\omega - 2\pi k)$ |

**抽样定理——CFT 与 DTFT 的桥梁**：

对连续信号 $x_a(t)$ 以间隔 $T_s$ 采样得 $x[n] = x_a(nT_s)$，其 DTFT 与 CFT 的关系为：

$$
\boxed{X(e^{j\omega}) = \frac{1}{T_s} \sum_{k=-\infty}^{+\infty} X_a\!\left(j\frac{\omega - 2\pi k}{T_s}\right)}
$$

其中 $\omega = \Omega T_s$ 为归一化频率。

**直观理解**：时域离散化 → DTFT 是 CFT 的**周期延拓 + 尺度缩放**。若 $x_a(t)$ 为带限信号（$X_a(j\Omega) = 0$ 对 $|\Omega| \geq \Omega_s/2$），则周期延拓的无混叠条件为采样频率 $\Omega_s = 2\pi/T_s \geq 2\Omega_{\max}$（奈奎斯特条件），此时 $[-\pi,\pi]$ 内的 DTFT 正比于 CFT。

这一关系是数字信号处理的基石：满足采样定理时，连续信号的全部信息完好保存在其离散样本的 DTFT 中，可经理想低通滤波器无失真重建。

## 3. 计算机上的傅里叶分析：DFT 与 FFT

DTFT 的频域是连续函数，计算机无法直接计算。将 DTFT 的 $[0, 2\pi)$ 区间等间隔采样 $N$ 点，得到**离散傅里叶变换**（DFT）——唯一定义在有限长的时域和频域上的变换，是数字信号处理的计算基石。

---

### 3.1 DFT 的定义与性质

#### 3.1.1 定义：DTFT 的频域采样

有限长序列 $x[n]$（$0 \leq n \leq N-1$）的 $N$ 点 DFT 定义为 DTFT 在 $[0, 2\pi)$ 上的 $N$ 点等间隔采样：

$$
\boxed{
\begin{aligned}
X[k] &= \sum_{n=0}^{N-1} x[n] W_N^{kn}, \quad k = 0, \ldots, N-1 \\[4pt]
x[n] &= \frac{1}{N} \sum_{k=0}^{N-1} X[k] W_N^{-kn}, \quad n = 0, \ldots, N-1
\end{aligned}
}
$$

**对偶解读**：
- 两方程均为有限长离散求和 $\sum_{n=0}^{N-1}$ 和 $\sum_{k=0}^{N-1}$ → 时域和频域**对等**：均为**离散、有限长**（隐含周期性）
- DFT 是唯一公式结构完全对称的变换——分析与综合方程仅差归一化因子 $1/N$ 和旋转因子符号

其中 $W_N = e^{-j2\pi/N}$ 为旋转因子，$[W_N]_{kn} = W_N^{kn}$ 构成范德蒙德矩阵 $\mathbf{W}_N$，满足 $\mathbf{W}_N \mathbf{W}_N^* = N\mathbf{I}_N$，即 $\frac{1}{\sqrt{N}}\mathbf{W}_N$ 为酉矩阵。

与 DTFT 的关系：

$$
X[k] = X(e^{j\omega})\big|_{\omega = 2\pi k/N}
$$

**频域采样定理**：若 $x[n]$ 长度为 $M$，取 $N \geq M$ 点 DFT，则可由 $X[k]$ 无失真地恢复 DTFT（sinc 插值）：

$$
X(e^{j\omega}) = \sum_{k=0}^{N-1} X[k] \, \Phi\!\left(\omega - \frac{2\pi k}{N}\right), \quad
\Phi(\omega) = \frac{1}{N} e^{-j\omega(N-1)/2} \frac{\sin(\omega N/2)}{\sin(\omega/2)}
$$

DFT 与 DFS 系数在主值区间形式上一致（仅差的归一化位置），但 DFT 隐含了时域和频域的周期性延拓。

#### 3.1.2 常用序列的 DFT

| $x[n]$（$0 \leq n \leq N-1$） | $N$ 点 DFT $X[k]$ | 说明 |
|---|---|---|
| $\delta[n]$ | $1$ | 均匀谱 |
| $1$ | $\begin{cases} N, & k = 0 \\ 0, & k \neq 0 \end{cases}$ | 直流 |
| $e^{j\frac{2\pi}{N} k_0 n}$ | $\begin{cases} N, & k = k_0 \\ 0, & k \neq k_0 \end{cases}$ | 单频复指数 |
| $\cos(\frac{2\pi}{N} k_0 n)$ | $\begin{cases} N/2, & k = \pm k_0 \\ 0, & \text{其他} \end{cases}$ | 实余弦 |
| $a^n$ | $\dfrac{1 - a^N}{1 - a W_N^{-k}}$ | 截断指数 |
| $R_M[n]$（长 $M$ 矩形窗，$M \leq N$） | $e^{-j\frac{\pi}{N}k(M-1)}\dfrac{\sin(\pi k M/N)}{\sin(\pi k/N)}$ | Dirichlet 核 |

#### 3.1.3 循环移位与循环卷积

DFT 的运算是在 $\bmod N$ 意义下进行的——这是 DFT 区别于 DTFT 的本质特征。

**循环移位**：

$$
x[(n - m) \bmod N] \;\longleftrightarrow\; W_N^{km} X[k]
$$

**循环卷积**——DFT 最核心的运算：

$$
x_1[n] \circledast x_2[n] \triangleq \sum_{m=0}^{N-1} x_1[m] x_2[(n - m) \bmod N] \;\longleftrightarrow\; X_1[k] X_2[k]
$$

**循环卷积与线性卷积的关系**：设 $x_1[n]$ 长 $N_1$、$x_2[n]$ 长 $N_2$，线性卷积长 $N_1 + N_2 - 1$。

$$
x_1[n] \circledast_N x_2[n] = \sum_{r=-\infty}^{+\infty} (x_1 * x_2)[n - rN], \quad n = 0, \ldots, N-1
$$

- $N \geq N_1 + N_2 - 1$：循环卷积 = 线性卷积（补零后等价）
- $N < N_1 + N_2 - 1$：时域混叠

这提供了用 FFT 快速计算线性卷积的方法：补零至 $N \geq N_1 + N_2 - 1$，计算 $N$ 点 FFT → 频域相乘 → IFFT。

#### 3.1.4 DFT 的性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $a x_1[n] + b x_2[n]$ | $a X_1[k] + b X_2[k]$ |
| **循环时移** | $x[(n - m) \bmod N]$ | $W_N^{km} X[k]$ |
| **循环频移** | $W_N^{-ln} x[n]$ | $X[(k - l) \bmod N]$ |
| **共轭** | $x^*[n]$ | $X^*[(-k) \bmod N]$ |
| **时间反转** | $x[(-n) \bmod N]$ | $X[(-k) \bmod N]$ |
| **循环卷积** | $x_1[n] \circledast x_2[n]$ | $X_1[k] X_2[k]$ |
| **时域乘积** | $x_1[n] x_2[n]$ | $\dfrac{1}{N} X_1[k] \circledast X_2[k]$ |
| **帕斯瓦尔** | $\displaystyle\sum_{n=0}^{N-1} \|x[n]\|^2$ | $\displaystyle\frac{1}{N}\sum_{k=0}^{N-1} \|X[k]\|^2$ |

- 实序列对称性：$X[N-k] = X^*[k]$，奇偶分解 $x_e[n] = \frac{x[n]+x[N-n]}{2} \leftrightarrow \operatorname{Re}\{X[k]\}$，$x_o[n] = \frac{x[n]-x[N-n]}{2} \leftrightarrow j\operatorname{Im}\{X[k]\}$
- 与 CFT/DTFT 的差异：所有移位和反转在 $\bmod N$ 意义下进行（循环操作）

#### 3.1.5 补零与频率分辨率

对 $L$ 长序列补 $N - L$ 个零后做 $N$ 点 DFT：

$$
X_N[k] = \sum_{n=0}^{L-1} x[n] W_N^{kn} = X(e^{j\omega})\big|_{\omega = 2\pi k/N}
$$

| 概念 | 含义 | 补零效果 |
|------|------|----------|
| **计算分辨率** | 频域采样间隔 $\Delta\omega = 2\pi/N$ | 随 $N$ 增大而减小，频谱曲线更平滑 |
| **物理分辨率** | 区分两个等强正弦波的最小频率间隔 | 由信号实际长度 $L$ 决定（$\approx 2\pi/L$），补零不改变 |
| **频谱泄漏** | 能量从信号频率扩散到邻近频率 | 补零可揭示更多泄漏细节但不减少泄漏 |

---

### 3.2 快速傅里叶变换（FFT）

#### 3.2.1 旋转因子的特殊性质

旋转因子 $W_N = e^{-j2\pi/N}$ 满足：

- **周期性**：$W_N^{k+N} = W_N^k$
- **对称性**：$W_N^{k+N/2} = -W_N^k$（$N$ 为偶数时）
- **可缩放性**：$W_N^{mk} = W_{N/m}^k$

FFT 算法通过递归地利用这些特性，将直接 DFT 的 $O(N^2)$ 降至 $O(N\log N)$。

#### 3.2.2 基 2 时域抽取（DIT-FFT）

设 $N = 2^L$。将 $x[n]$ 按奇偶拆分为两个 $N/2$ 点序列：

$$
X[k] = \underbrace{\sum_{r=0}^{N/2-1} x[2r] W_{N/2}^{rk}}_{G[k]} + W_N^k \underbrace{\sum_{r=0}^{N/2-1} x[2r+1] W_{N/2}^{rk}}_{H[k]}
$$

$G[k]$ 和 $H[k]$ 是周期为 $N/2$ 的序列。利用 $W_N^{k+N/2} = -W_N^k$，得蝶形运算：

$$
\boxed{
\begin{aligned}
X[k]       &= G[k] + W_N^k H[k], \quad & k = 0, \ldots, N/2-1 \\
X[k + N/2] &= G[k] - W_N^k H[k], \quad & k = 0, \ldots, N/2-1
\end{aligned}
}
$$

**递归结构**：

蝶形运算的基本单元：

```
G[k] ──┬──────► X[k] = G[k] + W_N^k H[k]
       │
H[k] ──┼─×W_N^k─► X[k+N/2] = G[k] - W_N^k H[k]
       │   (-1)
```

$L$ 级递归共 $\frac{N}{2}\log_2 N$ 个蝶形，每蝶形 1 次复乘（$W_N^k H[k]$）+ 2 次复加。

#### 3.2.3 运算量对比

| 方法 | 复乘次数 | $N=1024$ 时 |
|------|---------|-------------|
| 直接 DFT | $N^2$ | $\approx 1.05 \times 10^6$ |
| 基 2 FFT | $\frac{N}{2}\log_2 N$ | $\approx 5.12 \times 10^3$ |
| **加速比** | $\displaystyle\frac{2N}{\log_2 N}$ | **约 200 倍** |

逆 FFT 与正 FFT 结构相同，仅需将 $W_N$ 替换为 $W_N^{-1}$，输出乘以 $1/N$。

---

### 3.3 用 DFT 分析连续信号

实际应用中，连续信号 $x_a(t)$ 经采样、截断后送入 DFT。三个关键参数决定了分析质量。

#### 3.3.1 参数选取

设采样频率 $f_s$、采样点数 $N$，记录长度 $T_0 = NT_s = N/f_s$。

| 参数 | 符号 | 决定因素 |
|------|------|---------|
| **频率分辨率** | $\Delta f = f_s / N = 1/T_0$ | 记录长度越长，分辨率越高 |
| **最高可观测频率** | $f_{\max} = f_s / 2$（奈奎斯特频率） | 为防止混叠，需 $f_s \geq 2 f_{\max}$ |

给定期望的频率分辨率 $\Delta f$ 和信号最高频率 $f_{\max}$，采样参数需满足：

$$
f_s \geq 2 f_{\max}, \qquad N \geq \frac{f_s}{\Delta f} \quad\Longrightarrow\quad T_0 \geq \frac{1}{\Delta f}
$$

#### 3.3.2 频谱泄漏

DFT 对有限长序列（隐含矩形窗截断）进行周期延拓。若信号频率不是 $\Delta f$ 的整数倍，截断处的跳变产生泄漏——信号能量从主瓣扩散到旁瓣。

**矩形窗的 DFT**（Dirichlet 核）：

$$
W_R(\omega) = \frac{\sin(\omega N/2)}{\sin(\omega/2)}
$$

- **主瓣宽度** $= 4\pi/N$，决定频率分辨能力
- **旁瓣峰值** $\approx -13$ dB，强的旁瓣可能淹没邻近的微弱信号

**不同窗函数的特性**：

| 窗函数 | 主瓣宽度 | 最高旁瓣 | 适用场景 |
|--------|---------|---------|---------|
| 矩形窗 | $4\pi/N$ | $-13$ dB | 频率分辨率优先 |
| 汉宁窗 | $8\pi/N$ | $-31$ dB | 通用分析 |
| 汉明窗 | $8\pi/N$ | $-41$ dB | 旁瓣抑制优先 |
| 布莱克曼窗 | $12\pi/N$ | $-57$ dB | 强旁瓣抑制 |

**折中原则**：主瓣窄（分辨率高）↔ 旁瓣低（泄漏小），二者不可兼得。

#### 3.3.3 栅栏效应与补零

DFT 仅在 $2\pi k/N$ 处给出频谱值，如同透过栅栏观测连续谱。若信号频率落在两采样点之间，峰值会被漏看。

**补零缓解栅栏效应**：在 $L$ 点信号后补 $N-L$ 个零做 $N$ 点 DFT，增加频域采样密度，使离散谱点更密集地覆盖连续 DTFT。

> **实践准则**：选择合适的采样频率和窗函数 → 确保足够的记录长度满足分辨率 → 必要时补零细化频谱显示。但需记住——**物理分辨率仅取决于信号长度**，补零不创造新信息。

## 4. LTI 系统分析

傅里叶变换将卷积化为乘积，是分析 LTI 系统最自然的频域工具。连续系统由微分方程刻画，离散系统由差分方程刻画，但频域分析的范式完全一致。

---

### 4.1 频率响应——系统的频域描述

频率响应是系统冲激响应的傅里叶变换，也是复指数输入对应的特征值：

$$
\begin{aligned}
\text{连续：}&\quad H(j\omega) = \int_{-\infty}^{+\infty} h(t) e^{-j\omega t} dt, \qquad y(t) = h(t) * e^{j\omega t} = H(j\omega)\, e^{j\omega t} \\[4pt]
\text{离散：}&\quad H(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} h[n] e^{-j\omega n}, \qquad y[n] = h[n] * e^{j\omega n} = H(e^{j\omega})\, e^{j\omega n}
\end{aligned}
$$

#### 4.1.1 连续系统

由常系数线性微分方程 $\sum_{m=0}^{M} b_m \frac{d^m y}{dt^m} = \sum_{n=0}^{N} a_n \frac{d^n x}{dt^n}$，对两边取 CFT 并利用微分性质：

$$
\boxed{H(j\omega) = \frac{Y(j\omega)}{X(j\omega)} = \frac{\sum_{n=0}^{N} a_n (j\omega)^n}{\sum_{m=0}^{M} b_m (j\omega)^m}}
$$

$H(j\omega)$ 是 $j\omega$ 的有理函数，其因式分解为：

$$
H(j\omega) = K\frac{\prod_{n=1}^{N} (j\omega - z_n)}{\prod_{m=1}^{M} (j\omega - p_m)}
$$

- **零点** $z_n$：使 $H(j\omega) = 0$ 的频率
- **极点** $p_m$：使 $H(j\omega) \to \infty$ 的频率，决定系统的固有模态
- $|H(j\omega)|$ 为幅频响应，$\angle H(j\omega)$ 为相频响应

#### 4.1.2 离散系统

由线性常系数差分方程 $\sum_{k=0}^{N} a_k y[n-k] = \sum_{m=0}^{M} b_m x[n-m]$（$a_0 = 1$），对两边取 DTFT：

$$
\boxed{H(e^{j\omega}) = \frac{\sum_{m=0}^{M} b_m e^{-j\omega m}}{\sum_{k=0}^{N} a_k e^{-j\omega k}}}
$$

$H(e^{j\omega})$ 是 $e^{j\omega}$ 的有理函数，也是 $\omega$ 的 $2\pi$ 周期函数。

| 系统 | 频率响应 | 典型示例 | 冲激响应 |
|------|---------|---------|---------|
| 一阶连续 | $\dfrac{a_0}{b_1 j\omega + b_0}$ | $\dfrac{1}{a + j\omega}$ | $e^{-at}u(t)$ |
| 一阶离散 | $\dfrac{b_0}{a_0 + a_1 e^{-j\omega}}$ | $\dfrac{1}{1 - a e^{-j\omega}}$ | $a^n u[n]$ |
| 二阶离散 | 双极点有理分式 | $\dfrac{1}{1 - 2r\cos\theta e^{-j\omega} + r^2 e^{-j2\omega}}$ | $\dfrac{r^n\sin[(n+1)\theta]}{\sin\theta}u[n]$ |

---

### 4.2 系统响应求解

#### 4.2.1 零状态响应（频域法）

零初始条件下，输出完全由输入和系统决定：

| 步骤 | 连续 | 离散 |
|------|------|------|
| ① 求输入谱 | $X(j\omega) = \mathcal{F}\{x(t)\}$ | $X(e^{j\omega}) = \text{DTFT}\{x[n]\}$ |
| ② 频域相乘 | $Y(j\omega) = H(j\omega) X(j\omega)$ | $Y(e^{j\omega}) = H(e^{j\omega}) X(e^{j\omega})$ |
| ③ 逆变换 | $y(t) = \mathcal{F}^{-1}\{Y(j\omega)\}$ | $y[n] = \text{IDTFT}\{Y(e^{j\omega})\}$ |

当 $Y$ 为有理函数时，部分分式展开后逐项查表求逆：

| 连续系统的逆 CFT | 离散系统的逆 DTFT |
|---|---|
| $\dfrac{1}{j\omega + a} \to e^{-at}u(t)$ | $\dfrac{1}{1 - a e^{-j\omega}} \to a^n u[n]$ |
| $\dfrac{1}{(j\omega + a)^n} \to \dfrac{t^{n-1}}{(n-1)!}e^{-at}u(t)$ | — |
| $\dfrac{\omega_0}{(j\omega + a)^2 + \omega_0^2} \to e^{-at}\sin(\omega_0 t)u(t)$ | — |

#### 4.2.2 零输入响应（特征方程法）

无外部输入时，系统的行为由初始状态和固有模态决定。设响应为 $e^{st}$（连续）或 $r^n$（离散），代入齐次方程得特征方程：

$$
\begin{aligned}
\text{连续：}&\quad \sum_{m=0}^{M} b_m s^m = 0 \\[4pt]
\text{离散：}&\quad \sum_{k=0}^{N} a_k r^{-k} = 0
\end{aligned}
$$

特征根即系统的极点。零输入响应为各模态的线性组合：

$$
\begin{aligned}
\text{连续：}&\quad y_{zi}(t) = \sum_{m=1}^{M} C_m e^{s_m t} \\[4pt]
\text{离散：}&\quad y_{zi}[n] = \sum_{i=1}^{N} C_i r_i^n
\end{aligned}
$$

系数由初始条件确定：连续系统由 $y(0^+), y'(0^+), \ldots$ 确定，离散系统由 $y[-1], y[-2], \ldots$ 确定。

**完全响应** = 零输入响应 + 零状态响应。FT/DTFT 默认零初始条件，仅能求零状态响应。同时处理初值和输入需借助拉普拉斯变换或 $z$ 变换。

---

### 4.3 因果性与稳定性

#### 4.3.1 因果性

| | 连续系统 | 离散系统 |
|---|---------|---------|
| **时域判据** | $h(t) = 0$ 对 $t < 0$ | $h[n] = 0$ 对 $n < 0$ |
| **频域判据** | — | 佩利-维纳条件：$\int_{-\pi}^{\pi} \|\ln H(e^{j\omega})\| d\omega < \infty$ |

佩利-维纳条件的含义：因果系统的幅频响应不可在某一频段恒为零（否则相频响应无解），且衰减不能太快。

#### 4.3.2 稳定性

| | 连续系统 | 离散系统 |
|---|---------|---------|
| **时域判据** | $h(t)$ 绝对可积 | $h[n]$ 绝对可和 |
| **频域判据** | 极点全在左半平面（$\operatorname{Re}(p_m) < 0$） | 极点全在单位圆内（$\|p\| < 1$） |

#### 4.3.3 极点位置 ⇔ 时域模态

| 极点位置 | 模态 | 稳定性 |
|----------|------|--------|
| **连续**：负实根 $s = -a$ | $e^{-at}$（衰减） | 稳定 |
| **连续**：共轭复根 $s = -a \pm j\omega_0$ | $e^{-at}\sin(\omega_0 t + \phi)$（衰减振荡） | 稳定 |
| **连续**：虚轴 $s = \pm j\omega_0$ | $\sin(\omega_0 t + \phi)$（等幅振荡） | 临界稳定 |
| **连续**：右半平面 $\operatorname{Re}(s) > 0$ | $e^{at}$（发散） | 不稳定 |
| **离散**：$\|p\| < 1$ | 指数衰减 | 稳定 |
| **离散**：$\|p\| = 1$ | 等幅振荡/常数 | 临界稳定 |
| **离散**：$\|p\| > 1$ | 指数增长 | 不稳定 |

### 4.4 滤波器概述

#### 4.4.1 理想低通滤波器

| | 连续理想低通 | 离散理想低通 |
|---|-------------|-------------|
| **频率响应** | $H(j\omega) = \begin{cases} 1, & \|\omega\| < \omega_c \\ 0, & \text{其他} \end{cases}$ | $H(e^{j\omega}) = \begin{cases} 1, & \|\omega\| < \omega_c \\ 0, & \text{其他} \end{cases}$ |
| **冲激响应** | $h(t) = \dfrac{\sin(\omega_c t)}{\pi t}$ | $h[n] = \dfrac{\sin(\omega_c n)}{\pi n}$ |
| **响应长度** | $\mathbb{R}$（无穷长，非因果） | $\mathbb{Z}$（无穷长，非因果） |

#### 4.4.2 可实现性问题

理想滤波器的冲激响应具有两个致命问题：
1. **非因果**：$h(t) \neq 0$ 对 $t < 0$，输出超前输入
2. **无限长**：衰减仅为 $\sim 1/t$（离散为 $\sim 1/n$），不可直接截断

因此理想滤波器**物理不可实现**。实际滤波器在幅频响应的通带纹波、阻带衰减和过渡带宽之间权衡。

#### 4.4.3 实际滤波器设计思路

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **FIR（加窗法）** | 截断理想冲激响应 + 加窗平滑 | 严格线性相位，稳定 | 阶数较高 |
| **IIR** | 有理系统函数逼近理想响应 | 低阶高效 | 非线性相位，需关注稳定性 |
| **频率采样** | 对理想频响采样 → IDFT → FIR | 频率响应在采样点精确匹配 | 采样点之间不可控 |

**选型建议**：相位敏感场合（通信、音频）优先 FIR；计算资源受限场合（嵌入式）可选用 IIR。

### 5.1 五种变换总览

| 变换 | 时域特征及公式 | 频域特征及公式 |
|------|--------------|--------------|
| **CFS** | **连续、周期**<br>$\displaystyle a_k = \frac{1}{T}\int_T x(t) e^{-jk\omega_0 t} dt$<br>分析方程对 $t$ 做连续积分 $\int_T$，积分域为单周期 $T$ → 时域连续且周期 | **离散、非周期**<br>$\displaystyle x(t) = \sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t}$<br>综合方程求和指标 $k \in \mathbb{Z}$ 取全体整数 → 频域离散，$a_k$ 无周期约束 → 频域非周期 |
| **CFT** | **连续、非周期**<br>$\displaystyle x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega$<br>综合方程对 $\omega$ 做全实轴积分 → 时域 $t$ 是连续变量，无周期约束 | **连续、非周期**<br>$\displaystyle X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt$<br>分析方程对 $t$ 做全实轴积分 → $\omega$ 是连续变量，无周期约束 (两域对等) |
| **DFS** | **离散、周期**<br>$\displaystyle \tilde{X}[k] = \frac{1}{N} \sum_{n=0}^{N-1} \tilde{x}[n] e^{-jk\frac{2\pi}{N}n}$<br>分析方程对 $n$ 做有限求和 $\sum_{n=0}^{N-1}$ → $n$ 离散且周期为 $N$ | **离散、周期**<br>$\displaystyle \tilde{x}[n] = \sum_{k=0}^{N-1} \tilde{X}[k] e^{jk\frac{2\pi}{N}n}$<br>综合方程对 $k$ 做有限求和 $\sum_{k=0}^{N-1}$ → $k$ 离散且周期为 $N$ (两域对等) |
| **DTFT** | **离散、非周期**<br>$\displaystyle X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n}$<br>分析方程对 $n$ 做离散求和 → $n$ 离散，无周期约束 → 时域离散非周期 | **连续、周期**<br>$\displaystyle x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega$<br>综合方程对 $\omega$ 做连续积分，积分域为 $[-\pi,\pi]$ → $\omega$ 连续且周期 $2\pi$ |
| **DFT** | **离散、有限长**<br>$\displaystyle X[k] = \sum_{n=0}^{N-1} x[n] W_N^{kn}$<br>分析方程对 $n$ 做有限求和 $\sum_{n=0}^{N-1}$ → $n$ 离散有限，隐含周期 | **离散、有限长**<br>$\displaystyle x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] W_N^{-kn}$<br>综合方程对 $k$ 做有限求和 $\sum_{k=0}^{N-1}$ → $k$ 离散有限 (两域完全对等) |

### 5.2 变换之间的递进关系

五种变换不是孤立的，它们在极限操作和采样操作下相互转化：

```
                        T→∞ 极限
               CFS ──────────────────► CFT
                │                        │
         时域采样│                  时域采样│
               (N点)                  (T_s间隔)
                ▼                        ▼
               DFS ──────────────────► DTFT
                │        N→∞ 极限         │
                │                        │
                │       取主值区间        │   频域采样(N点)
                └──────────► DFT ◄────────┘
```

**关键递进路径**：

| 路径 | 操作 | 核心关系式 |
|------|------|-----------|
| CFS → CFT | 周期 $T \to \infty$ | $a_k \cdot T \to X(j\omega)$，$\sum \to \int$ |
| DFS → DTFT | 周期 $N \to \infty$ | $N\tilde{X}[k] \to X(e^{j\omega})$，$\sum \to \int$ |
| CFT → DTFT | 时域以 $T_s$ 采样 | $\displaystyle X(e^{j\omega}) = \frac{1}{T_s} \sum_k X_a\!\left(j\frac{\omega-2\pi k}{T_s}\right)$ |
| CFS → DFS | 时域以 $T/N$ 间隔采样 $N$ 点 | $\displaystyle \tilde{X}[k] = \frac{1}{N} \sum_r a_{k+rN}$ |
| DTFT → DFT | 频域 $N$ 点采样 | $X[k] = X(e^{j\omega})\|_{\omega = 2\pi k/N}$ |
| DFS → DFT | 取主值区间 $[0, N-1]$ | $X[k] = \tilde{X}[k]$（$0 \leq k \leq N-1$） |

**等价表述**：对于带限周期信号，CFS → DFS → DFT 这条路径在无混叠条件下是信息无损的，CFS 的无穷多系数最终浓缩为 $N$ 点 DFT。

---

### 5.3 性质的对偶全景

五种变换的性质"层层继承"，核心操作在连续域和离散域之间存在对应映射：

| 连续域操作 | 离散域操作 | 变换归属 |
|-----------|-----------|---------|
| 时域卷积 | 时域卷积（线性/循环） | CFT、DTFT、DFT |
| 频域乘积 | 频域乘积 | CFT、DTFT、DFT |
| 时间微分 $\frac{d}{dt}$ | 时间差分 $x[n] - x[n-1]$ | CFT ↔ DTFT |
| 频域微分 $j\frac{d}{d\omega}$ | 频域微分 $j\frac{d}{d\omega}$ | CFT、DTFT |
| 乘 $t$ | 乘 $n$ | CFT、DTFT |
| 时域积分 | 累加 | CFT ↔ DTFT |
| 线性时移（连续） | 循环时移（$\bmod N$） | CFT/C/CT ↔ DFS/DFT |
| 帕斯瓦尔（能量守恒） | 帕斯瓦尔（能量守恒） | 全部五种变换 |

### 5.4 从理论到实践

全文从复指数作为 LTI 系统特征函数出发，沿四个维度展开傅里叶分析：

1. **周期信号**（时域周期 → 频域离散）：CFS 与 DFS，无穷级数与有限求和的对照
2. **非周期信号**（时域非周期 → 频域连续）：CFT 与 DTFT，积分变换与求和变换的对照
3. **计算工具**：DFT 作为 DTFT 的频域采样，FFT 将其计算量从 $O(N^2)$ 降至 $O(N\log N)$
4. **系统分析**：频率响应、卷积定理、零状态/零输入响应、稳定性判据——连续与离散共享同一套分析范式

**实践闭环**：

```
              采样 + 截断             DTFT             N点采样             FFT
连续信号 x_a(t) ────────► 有限长序列 x[n] ──────► DTFT X(e^{jω}) ──────► DFT X[k] ──────► 频谱
                            ▲                                                     │
                            │                    IDFT + 重建                    │
                            └────────────────────────────────────────────────────┘
```

所有傅里叶变换的本质都是信号在复指数基上的正交分解。连续/离散与周期/非周期的四种组合由对偶法则约束，变换之间通过极限和采样操作相连。**DFT 作为完全离散化的终点，是唯一可在计算机上直接计算的变换——这是连接傅里叶理论与数字信号处理实践的桥梁。**
