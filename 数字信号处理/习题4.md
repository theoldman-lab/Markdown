## 一、z 反变换

**题目 1** 求 $X(z) = \dfrac{1}{z-a},\ |z| > |a|$ 的反变换。

**题目 2** 求 $X(z) = \ln\left(1 - \dfrac{1}{2}z^{-1}\right),\ |z| > \dfrac{1}{2}$ 的反变换。

**题目 3** 已知 $X(z) = \dfrac{z}{(z-1)(z-2)^2},\ |z| > 2$，求 $x[n]$。

**题目 4** 已知某信号 $y[n] = \left(\dfrac{1}{9}\right)^n u[n]$，试确定两个信号，它们的 $z$ 变换 $X(z)$ 满足如下条件：
- ① $Y(z^2) = \dfrac{1}{2}[X(z) + X(-z)]$；
- ② $X(z)$ 仅有一个零点和一个极点。

**解：**

---

**题目 1** $X(z) = \dfrac{1}{z-a} = z^{-1} \cdot \dfrac{z}{z-a}$

由基本变换对 $\dfrac{z}{z-a} \leftrightarrow a^n u[n]$（ROC: $|z| > |a|$），结合时移性质 $z^{-1}$：

$$\boxed{x[n] = a^{n-1} u[n-1]}$$

---

**题目 2** $X(z) = \ln\left(1 - \frac{1}{2}z^{-1}\right),\ |z| > \frac{1}{2}$

利用幂级数展开 $\ln(1-x) = -\sum_{n=1}^{\infty} \frac{x^n}{n}$（$|x| < 1$）。ROC $|z| > \frac{1}{2}$ 保证了 $\big|\frac{1}{2}z^{-1}\big| < 1$：

$$X(z) = -\sum_{n=1}^{\infty} \frac{1}{n}\left(\frac{1}{2}\right)^n z^{-n} = \sum_{n=1}^{\infty} \left[-\frac{1}{n}\left(\frac{1}{2}\right)^n\right] z^{-n}$$

与 $X(z) = \sum x[n]z^{-n}$ 对比：

$$\boxed{x[n] = -\frac{1}{n}\left(\frac{1}{2}\right)^n u[n-1]}$$

---

**题目 3** $X(z) = \dfrac{z}{(z-1)(z-2)^2},\ |z| > 2$

先求 $X(z)/z$ 的部分分式展开：

$$\frac{X(z)}{z} = \frac{1}{(z-1)(z-2)^2} = \frac{A}{z-1} + \frac{B}{z-2} + \frac{C}{(z-2)^2}$$

$$1 = A(z-2)^2 + B(z-1)(z-2) + C(z-1)$$

- $z=1$：$1 = A(1) \Rightarrow A = 1$
- $z=2$：$1 = C(1) \Rightarrow C = 1$
- $z=0$：$1 = 4A + 2B - C = 4 + 2B - 1 \Rightarrow B = -1$

$$\frac{X(z)}{z} = \frac{1}{z-1} - \frac{1}{z-2} + \frac{1}{(z-2)^2}$$

$$X(z) = \frac{z}{z-1} - \frac{z}{z-2} + \frac{z}{(z-2)^2}$$

利用 $\dfrac{z}{(z-a)^2} \leftrightarrow n a^{n-1} u[n]$，得：

$$\boxed{x[n] = \big[1 - 2^n + n 2^{n-1}\big]\,u[n]}$$

---

**题目 4** $y[n] = \big(\frac{1}{9}\big)^n u[n]$，$Y(z) = \dfrac{z}{z - \frac{1}{9}}$，$Y(z^2) = \dfrac{z^2}{z^2 - \frac{1}{9}}$。

条件 $Y(z^2) = \frac{1}{2}[X(z) + X(-z)]$ 等价于提取 $x[n]$ 的偶数项：$\frac{1}{2}[X(z)+X(-z)]$ 仅保留 $n$ 为偶数的项。

设 $X(z) = K\dfrac{z-a}{z-b}$（一零点一极点），则：

$$X(-z) = K\frac{-z-a}{-z-b} = K\frac{z+a}{z+b}$$

$$\frac{1}{2}[X(z) + X(-z)] = \frac{1}{2}K\left[\frac{z-a}{z-b} + \frac{z+a}{z+b}\right] = K \cdot \frac{z^2 - ab}{z^2 - b^2}$$

令 $w = z^2$，与 $Y(w) = \dfrac{w}{w - 1/9}$ 比较：

$$K \cdot \frac{w - ab}{w - b^2} = \frac{w}{w - 1/9}$$

比较系数得 $K = 1$，$ab = 0$，$b^2 = \frac{1}{9}$，故 $a = 0$，$b = \pm\frac{1}{3}$。

两个信号为：

$$\boxed{X_1(z) = \frac{z}{z - \frac{1}{3}},\quad |z| > \frac{1}{3};\qquad X_2(z) = \frac{z}{z + \frac{1}{3}},\quad |z| > \frac{1}{3}}$$

---

## 二、零极点与系统函数

**题目 5** 已知系统的零极图如图 7.11 所示，且 $H(\infty)=1$，求该系统的系统函数 $H(z)$ 和单位样值响应 $h[n]$。

（图中显示：零点在 $z = -\dfrac{1}{3}$，$z = 0$；极点在 $z = \dfrac{1}{2}$，$z = \dfrac{3}{4}$）

**题目 6** 已知一因果离散 LTI 系统 $y[n] = \sum\limits_{k=0}^{n} \sum\limits_{i=0}^{k} x[i]$，求该系统的系统函数 $H(z)$ 及单位样值响应 $h[n]$。

**解：**

**题目 5** 由零极点及 $H(\infty)=1$：

$$H(z) = K \cdot \frac{(z + \frac{1}{3})z}{(z - \frac{1}{2})(z - \frac{3}{4})}$$

$H(\infty) = K = 1$，故：

$$\boxed{H(z) = \frac{z(z + \frac{1}{3})}{(z - \frac{1}{2})(z - \frac{3}{4})}}$$

求 $h[n]$（系统因果，ROC: $|z| > \frac{3}{4}$）：

$$\frac{H(z)}{z} = \frac{z + \frac{1}{3}}{(z - \frac{1}{2})(z - \frac{3}{4})} = \frac{A}{z - \frac{1}{2}} + \frac{B}{z - \frac{3}{4}}$$

$$A = \frac{\frac{1}{2}+\frac{1}{3}}{\frac{1}{2}-\frac{3}{4}} = \frac{\frac{5}{6}}{-\frac{1}{4}} = -\frac{10}{3},\qquad B = \frac{\frac{3}{4}+\frac{1}{3}}{\frac{3}{4}-\frac{1}{2}} = \frac{\frac{13}{12}}{\frac{1}{4}} = \frac{13}{3}$$

$$H(z) = -\frac{10}{3}\cdot\frac{z}{z - \frac{1}{2}} + \frac{13}{3}\cdot\frac{z}{z - \frac{3}{4}}$$

$$\boxed{h[n] = \left[-\frac{10}{3}\left(\frac{1}{2}\right)^{\!n} + \frac{13}{3}\left(\frac{3}{4}\right)^{\!n}\right]u[n]}$$

---

**题目 6** $y[n] = \sum_{k=0}^{n} \sum_{i=0}^{k} x[i]$ 为双重累加，等价于两次与 $u[n]$ 卷积：

$$\sum_{i=0}^{k} x[i] = u[k]*x[k],\quad \sum_{k=0}^{n} (\cdot) = u[n]*(\cdot)$$

$$Y(z) = \left(\frac{z}{z-1}\right)^2 X(z)$$

$$\boxed{H(z) = \frac{z^2}{(z-1)^2}}$$

逆变换：$\dfrac{z}{z-1} \leftrightarrow u[n]$，而 $\dfrac{z^2}{(z-1)^2}$ 对应 $u[n]*u[n]$：

$$h[n] = \sum_{k=0}^{n} u[k]\,u[n-k] = \sum_{k=0}^{n} 1 = n+1,\ n \ge 0$$

$$\boxed{h[n] = (n+1)u[n]}$$

---

## 三、差分方程与系统响应

**题目 7** 已知某一因果离散 LTI 系统的差分方程为 $y[n+2] + y[n+1] + y[n] = x[n]$，且 $y[0]=1,\ y[1]=2$，当输入 $x[n]=u[n]$ 时，求系统的响应。

**题目 8** 已知系统框图如图 7.14 所示，求该因果系统的系统函数 $H(z)$，当 $k$ 为何值时该系统是稳定的？若 $k=1$，且对所有的 $n$，$x[n] = \left(\dfrac{2}{3}\right)^n$，求 $y[n]$。

（图中框图结构：输入 $x[n]$ 进入加法器，输出 $w[n]$；$w[n]$ 经过 $z^{-1}$ 延迟后反馈回第一个加法器，增益为 $-\dfrac{k}{3}$；同时 $w[n]$ 直接进入第二个加法器，延迟后的信号也进入第二个加法器，增益为 $-\dfrac{k}{4}$，最终输出 $y[n]$）

**解：**

**题目 7** 用特征方程法。差分方程 $y[n+2] + y[n+1] + y[n] = x[n]$，特征方程 $r^2 + r + 1 = 0$，根 $r_{1,2} = e^{\pm j2\pi/3}$。

$n \ge 0$ 时 $x[n] = u[n] = 1$，设特解 $y_p = K$：$K + K + K = 1 \Rightarrow K = \frac{1}{3}$。

通解：$y[n] = \frac{1}{3} + C_1 e^{j2\pi n/3} + C_2 e^{-j2\pi n/3}$（$n \ge 0$）。

由 $y[0]=1,\ y[1]=2$ 定系数：

$$C_1 + C_2 = \frac{2}{3},\quad C_1 e^{j2\pi/3} + C_2 e^{-j2\pi/3} = \frac{5}{3}$$

解得 $C_1 = \dfrac{1}{3} - j\dfrac{2}{\sqrt{3}},\ C_2 = C_1^*$。利用 $C_1 e^{j2\pi n/3} + C_2 e^{-j2\pi n/3} = 2\,\text{Re}\{C_1 e^{j2\pi n/3}\}$，化简得：

$$\boxed{y[n] = \left[\frac{1}{3} + \frac{2}{3}\cos\frac{2\pi n}{3} + \frac{4\sqrt{3}}{3}\sin\frac{2\pi n}{3}\right]u[n]}$$

---

**题目 8** 由框图列方程：

$$w[n] = x[n] - \frac{k}{3}w[n-1],\qquad y[n] = w[n] - \frac{k}{4}w[n-1]$$

取 z 变换：$W(z) = \dfrac{X(z)}{1 + \frac{k}{3}z^{-1}}$，$Y(z) = W(z)\!\left(1 - \frac{k}{4}z^{-1}\right)$。

$$\boxed{H(z) = \frac{Y(z)}{X(z)} = \frac{1 - \frac{k}{4}z^{-1}}{1 + \frac{k}{3}z^{-1}} = \frac{z - \frac{k}{4}}{z + \frac{k}{3}}}$$

因果系统，极点 $z = -\dfrac{k}{3}$。稳定条件：

$$\left|-\frac{k}{3}\right| < 1 \quad \Rightarrow \quad \boxed{|k| < 3}$$

若 $k=1$，系统稳定。输入 $x[n] = \left(\dfrac{2}{3}\right)^n$（对所有 $n$）为系统的特征函数：

$$y[n] = H\!\left(\frac{2}{3}\right) \cdot \left(\frac{2}{3}\right)^{\!n} = \frac{\frac{2}{3} - \frac{1}{4}}{\frac{2}{3} + \frac{1}{3}} \cdot \left(\frac{2}{3}\right)^{\!n} = \frac{5}{12} \cdot \left(\frac{2}{3}\right)^{\!n}$$

$$\boxed{y[n] = \frac{5}{12}\left(\frac{2}{3}\right)^{\!n}}$$

---

## 四、系统综合分析与完全响应

**题目 9** 已知某因果离散 LTI 系统的系统函数 $H(z) = \dfrac{z^2}{z^2 - \frac{1}{6}z - \frac{1}{6}}$，输入 $x[n] = 4u[n]$，系统的初始值 $y[-1]=0,\ y[-2]=12$。

求：
- ① 画出系统的零极图，并标明 ROC；
- ② 求系统的频率响应；
- ③ 求单位样值响应；
- ④ 求系统的差分方程，系统的完全响应（标明零输入、零状态响应，自由、强迫响应，稳态响应、暂态响应）。

**解：**

$H(z) = \dfrac{z^2}{z^2 - \frac{1}{6}z - \frac{1}{6}} = \dfrac{z^2}{(z - \frac{1}{2})(z + \frac{1}{3})}$

① 零点：$z = 0$（二重）；极点：$z = \frac{1}{2}$、$z = -\frac{1}{3}$（均在单位圆内）。因果系统，ROC: $|z| > \frac{1}{2}$。零极图：实轴上 $z=\frac{1}{2}$ 和 $z=-\frac{1}{3}$ 处各有一极点，原点处有二重零点，ROC 为圆外区域。

② 系统稳定（极点均在单位圆内），频率响应 $H(e^{j\omega}) = \dfrac{e^{j2\omega}}{e^{j2\omega} - \frac{1}{6}e^{j\omega} - \frac{1}{6}}$。

③ $H(z)/z = z/[(z-\frac{1}{2})(z+\frac{1}{3})] = \dfrac{3/5}{z-\frac{1}{2}} + \dfrac{2/5}{z+\frac{1}{3}}$

$$h[n] = \left[\frac{3}{5}\!\left(\frac{1}{2}\right)^{\!n} + \frac{2}{5}\!\left(-\frac{1}{3}\right)^{\!n}\right]u[n]$$

④ 差分方程：$H(z) = \dfrac{1}{1 - \frac{1}{6}z^{-1} - \frac{1}{6}z^{-2}} \ \Rightarrow\ \boxed{y[n] - \frac{1}{6}y[n-1] - \frac{1}{6}y[n-2] = x[n]}$

**完全响应：** $x[n] = 4u[n]$，$y[-1]=0,\ y[-2]=12$。

单边 z 变换代入初始条件：

$$Y(z) - \frac{1}{6}[z^{-1}Y(z) + y[-1]] - \frac{1}{6}[z^{-2}Y(z) + z^{-1}y[-1] + y[-2]] = X(z)$$

$$Y(z)\!\left(1 - \frac{1}{6}z^{-1} - \frac{1}{6}z^{-2}\right) - 2 = X(z)$$

**零输入响应**（$X(z)=0$）：$Y_{zi}(z) = \dfrac{2}{1 - \frac{1}{6}z^{-1} - \frac{1}{6}z^{-2}} = \dfrac{2z^2}{(z-\frac{1}{2})(z+\frac{1}{3})}$

$$\frac{Y_{zi}(z)}{z} = \frac{6/5}{z-\frac{1}{2}} + \frac{4/5}{z+\frac{1}{3}} \ \Rightarrow\ \boxed{y_{zi}[n] = \left[\frac{6}{5}\!\left(\frac{1}{2}\right)^{\!n} + \frac{4}{5}\!\left(-\frac{1}{3}\right)^{\!n}\right]u[n]}$$

**零状态响应**：$X(z) = \dfrac{4z}{z-1}$，$Y_{zs}(z) = \dfrac{4z^3}{(z-1)(z-\frac{1}{2})(z+\frac{1}{3})}$

$$\frac{Y_{zs}(z)}{z} = \frac{6}{z-1} - \frac{12/5}{z-\frac{1}{2}} + \frac{2/5}{z+\frac{1}{3}}$$

$$\boxed{y_{zs}[n] = \left[6 - \frac{12}{5}\!\left(\frac{1}{2}\right)^{\!n} + \frac{2}{5}\!\left(-\frac{1}{3}\right)^{\!n}\right]u[n]}$$

**完全响应：** $y[n] = y_{zi}[n] + y_{zs}[n]$

$$\boxed{y[n] = \left[6 - \frac{6}{5}\!\left(\frac{1}{2}\right)^{\!n} + \frac{6}{5}\!\left(-\frac{1}{3}\right)^{\!n}\right]u[n]}$$

**响应分类：**
- 自由响应（固有模态）：$-\frac{6}{5}(\frac{1}{2})^n + \frac{6}{5}(-\frac{1}{3})^n$
- 强迫响应：$6$（由输入 $u[n]$ 产生的特解）
- 稳态响应：$\lim_{n\to\infty} y[n] = 6$
- 暂态响应：$-\frac{6}{5}(\frac{1}{2})^n + \frac{6}{5}(-\frac{1}{3})^n$（随 $n\to\infty$ 衰减为 0）

## 五、z 变换计算

**题目 10** 已知 $x[n] = a^n \{u[n] - u[n-8]\},\ a>0$。求 $X(z)$，并画出零极图。

**题目 11** 求信号 $x[n] = \left(\dfrac{1}{4}\right)^n u[n] + \left(\dfrac{1}{2}\right)^n u[-n-1]$ 的 $z$ 变换，画出零极图，并标明收敛域。

**题目 12** 求 $x[n] = n 2^n u[-n]$ 的 $z$ 变换。

**题目 13** 已知信号 $x[n]$ 的 $z$ 变换为 $X(z) = \dfrac{z^4}{\left(z-\frac{1}{2}\right)(z^2-1)},\ |z|>1$，不求逆变换计算 $x[0]$ 的值。

**解：**

---

**题目 10** $x[n] = a^n u[n] - a^n u[n-8]$。

$$a^n u[n-8] = a^8 \cdot a^{n-8} u[n-8] \quad\leftrightarrow\quad a^8 z^{-8} \cdot \frac{z}{z-a}$$

$$X(z) = \frac{z}{z-a} - \frac{a^8 z^{-8} z}{z-a} = \frac{z(1 - a^8 z^{-8})}{z-a} = \frac{z^8 - a^8}{z^7(z-a)}$$

因式分解 $z^8 - a^8 = (z-a)(z^7 + a z^6 + a^2 z^5 + \cdots + a^7)$，消去 $(z-a)$：

$$X(z) = \frac{z^7 + a z^6 + a^2 z^5 + a^3 z^4 + a^4 z^3 + a^5 z^2 + a^6 z + a^7}{z^7}$$

零极图：$X(z)$ 有一个 7 阶极点 $z = 0$；7 个零点位于 $z = a\,e^{j 2\pi k / 8}$（$k = 1,2,\ldots,7$），均匀分布在以 $|z|=a$ 为半径的圆上，不含 $z=a$（$k=0$ 处的零点与极点已消去）。

---

**题目 11** $x[n] = \left(\frac{1}{4}\right)^n u[n] + \left(\frac{1}{2}\right)^n u[-n-1]$

右边分量：$\mathcal{Z}\{(\frac{1}{4})^n u[n]\} = \dfrac{z}{z - \frac{1}{4}}$，ROC: $|z| > \frac{1}{4}$。

左边分量 $\mathcal{Z}\{a^n u[-n-1]\} = \dfrac{-z}{z-a}$，ROC: $|z| < |a|$。故：

$$\mathcal{Z}\{(\tfrac{1}{2})^n u[-n-1]\} = \frac{-z}{z - \frac{1}{2}},\quad |z| < \frac{1}{2}$$

$$X(z) = \frac{z}{z - \frac{1}{4}} - \frac{z}{z - \frac{1}{2}} = \frac{-\frac{1}{4}z}{(z - \frac{1}{4})(z - \frac{1}{2})}$$

ROC: $\frac{1}{4} < |z| < \frac{1}{2}$（双边信号）。

零极图：零点 $z = 0$；极点 $z = \frac{1}{4}$、$z = \frac{1}{2}$（均在正实轴）。ROC 为两极点间的环形区域。

---

**题目 12** $x[n] = n 2^n u[-n]$（$x[n] \neq 0$ 仅当 $n \le 0$）。

$$X(z) = \sum_{n=-\infty}^{0} n\,2^n z^{-n} = \sum_{n=-\infty}^{0} n\left(\frac{2}{z}\right)^{\!n}$$

令 $m = -n$：

$$X(z) = \sum_{m=0}^{\infty} (-m)\left(\frac{z}{2}\right)^{\!m} = -\sum_{m=0}^{\infty} m\left(\frac{z}{2}\right)^{\!m}$$

由 $\sum_{m=0}^{\infty} m r^m = \dfrac{r}{(1-r)^2}$（$|r| < 1$），取 $r = \frac{z}{2}$：

$$X(z) = -\frac{\frac{z}{2}}{(1 - \frac{z}{2})^2} = -\frac{2z}{(z-2)^2}$$

ROC: $|z| < 2$。

$$\boxed{X(z) = -\frac{2z}{(z-2)^2},\quad |z| < 2}$$

---

**题目 13** $X(z) = \dfrac{z^4}{(z-\frac{1}{2})(z^2-1)} = \dfrac{z^4}{(z-\frac{1}{2})(z-1)(z+1)}$，ROC: $|z| > 1$。

信号为右边信号。$x[0]$ 为 $X(z)$ 的洛朗展开中 $z^0$ 的系数。做长除法：

分母 $D(z) = (z-\frac{1}{2})(z-1)(z+1) = z^3 - \frac{1}{2}z^2 - z + \frac{1}{2}$

$$X(z) = \frac{z^4}{z^3 - \frac{1}{2}z^2 - z + \frac{1}{2}} = z + \frac{1}{2} + \frac{\frac{5}{4}z^2 - \frac{1}{4}}{D(z)}$$

其中 $z$ 项对应 $x[-1]$，常数 $\frac{1}{2}$ 对应 $x[0]$。

$$\boxed{x[0] = \frac{1}{2}}$$

## 六、差分方程求系统函数

**题目 14** 已知某一因果离散 LTI 系统的差分方程为

$$y[n] - y[n-1] + \frac{1}{2}y[n-2] = x[n-1]$$

求：
- ① 该系统的系统函数 $H(z)$，画出零极图，标明收敛域；
- ② 单位样值响应 $h[n]$；
- ③ 当输入 $x[n] = 5\cos(\pi n)$ 时，求系统的响应。

---

**题目 15** 某因果离散 LTI 系统的差分方程为

$$y[n] - \frac{5}{6}y[n-1] + \frac{1}{6}y[n-2] = x[n] + a x[n-1]$$

求：
- ① 若输入 $x[n] = (-1)^n$ 时，输出 $y[n] = 2(-1)^n$，求该系统的系统函数 $H(z)$；
- ② 当输入 $x[n] = u[n]$ 时，求该系统的零状态响应；
- ③ 当输入 $x[n] = (-2)^n$ 时，对所有的 $n$，求 $y[n]$。

**解：**

---

**题目 14** 取 z 变换（零初始状态）：

$$Y(z)\big(1 - z^{-1} + \tfrac{1}{2}z^{-2}\big) = z^{-1}X(z)$$

$$H(z) = \frac{z^{-1}}{1 - z^{-1} + \frac{1}{2}z^{-2}} = \frac{z}{z^2 - z + \frac{1}{2}}$$

① 极点 $z = \frac{1 \pm j}{2} = \frac{1}{\sqrt{2}}e^{\pm j\pi/4}$（模 $\frac{1}{\sqrt{2}} \approx 0.707$），零点 $z = 0$。系统因果，ROC: $|z| > \frac{1}{\sqrt{2}}$。

零极图：一对共轭极点位于 $\frac{1}{\sqrt{2}}e^{\pm j\pi/4}$，单零点在原点。

② $H(z) = \dfrac{z}{(z - \frac{1}{\sqrt{2}}e^{j\pi/4})(z - \frac{1}{\sqrt{2}}e^{-j\pi/4})}$

$$\frac{H(z)}{z} = \frac{-j}{z - \frac{1}{\sqrt{2}}e^{j\pi/4}} + \frac{j}{z - \frac{1}{\sqrt{2}}e^{-j\pi/4}}$$

$$\boxed{h[n] = 2\left(\frac{1}{\sqrt{2}}\right)^{\!n}\sin\frac{n\pi}{4}\;u[n]}$$

③ $x[n] = 5\cos(\pi n) = 5(-1)^n$。频率响应 $H(e^{j\pi})$：

$$H(e^{j\pi}) = \frac{e^{-j\pi}}{1 - e^{-j\pi} + \frac{1}{2}e^{-j2\pi}} = \frac{-1}{1 - (-1) + \frac{1}{2}} = -\frac{2}{5}$$

$|H(e^{j\pi})| = \frac{2}{5}$，$\angle H(e^{j\pi}) = \pi$。

$$\boxed{y[n] = 5\cdot\frac{2}{5}\cos(\pi n + \pi) = -2\cos(\pi n) = -2(-1)^n}$$

---

**题目 15** 取 z 变换（零初始状态）：

## 七、系统框图实现

**题目 16** 已知离散 LTI 系统的系统函数为

$$H(z) = \frac{1 - \frac{7}{4}z^{-1} - \frac{1}{2}z^{-2}}{1 + \frac{1}{4}z^{-1} - \frac{1}{8}z^{-2}}$$

试画出该系统的直接 II 型、串联型及并联型框图结构，并求该系统的差分方程。

**解：**

**差分方程**

$$Y(z)\!\left(1 + \frac{1}{4}z^{-1} - \frac{1}{8}z^{-2}\right) = X(z)\!\left(1 - \frac{7}{4}z^{-1} - \frac{1}{2}z^{-2}\right)$$

$$\boxed{y[n] + \frac{1}{4}y[n-1] - \frac{1}{8}y[n-2] = x[n] - \frac{7}{4}x[n-1] - \frac{1}{2}x[n-2]}$$

---

**直接 II 型**

令中间变量 $w[n]$：

$$w[n] = x[n] - \frac{1}{4}w[n-1] + \frac{1}{8}w[n-2]$$
$$y[n] = w[n] - \frac{7}{4}w[n-1] - \frac{1}{2}w[n-2]$$

框图结构（文字描述）：两个 $z^{-1}$ 延迟单元串联，$x[n]$ 送入第一个加法器，延迟链输出 $w[n-1]$、$w[n-2]$ 分别以增益 $-1/4$ 和 $+1/8$ 反馈回输入端。输出端由 $w[n]$、$w[n-1]$（增益 $-7/4$）、$w[n-2]$（增益 $-1/2$）三个支路求和得到 $y[n]$。

---

**串联型（级联型）**

对 $H(z)$ 分子分母分解因式（以 $z^{-1}$ 为变量）：

分母 $1 + \frac{1}{4}z^{-1} - \frac{1}{8}z^{-2} = (1 - \frac{1}{4}z^{-1})(1 + \frac{1}{2}z^{-1})$

分子 $1 - \frac{7}{4}z^{-1} - \frac{1}{2}z^{-2} = (1 - 2z^{-1})(1 + \frac{1}{4}z^{-1})$

$$H(z) = \frac{1 - 2z^{-1}}{1 - \frac{1}{4}z^{-1}} \cdot \frac{1 + \frac{1}{4}z^{-1}}{1 + \frac{1}{2}z^{-1}} = H_1(z) \cdot H_2(z)$$

框图结构（文字描述）：两个一阶子系统串联。

- **第一级** $H_1(z) = \dfrac{1 - 2z^{-1}}{1 - \frac{1}{4}z^{-1}}$：一个延迟单元，反馈增益 $+1/4$，前馈增益 $-2$。
- **第二级** $H_2(z) = \dfrac{1 + \frac{1}{4}z^{-1}}{1 + \frac{1}{2}z^{-1}}$：一个延迟单元，反馈增益 $-1/2$，前馈增益 $+1/4$。

两级顺序可互换。

---

**并联型**

$$\frac{1 - \frac{7}{4}z^{-1} - \frac{1}{2}z^{-2}}{(1 - \frac{1}{4}z^{-1})(1 + \frac{1}{2}z^{-1})} = \frac{A}{1 - \frac{1}{4}z^{-1}} + \frac{B}{1 + \frac{1}{2}z^{-1}}$$

令 $w = z^{-1}$，部分分式：

$$A = \left.\frac{1 - \frac{7}{4}w - \frac{1}{2}w^2}{1 + \frac{1}{2}w}\right|_{w=4} = \frac{1-7-8}{1+2} = \frac{-14}{3}$$
$$B = \left.\frac{1 - \frac{7}{4}w - \frac{1}{2}w^2}{1 - \frac{1}{4}w}\right|_{w=-2} = \frac{1+\frac{7}{2}-2}{1+\frac{1}{2}} = \frac{5/2}{3/2} = \frac{5}{3}$$

$$H(z) = \frac{-\frac{14}{3}}{1 - \frac{1}{4}z^{-1}} + \frac{\frac{5}{3}}{1 + \frac{1}{2}z^{-1}}$$

框图结构（文字描述）：两个一阶子系统并联，输出求和。

- **子系统一** $H_a(z) = \dfrac{1}{1 - \frac{1}{4}z^{-1}}$，增益 $-\dfrac{14}{3}$：一个延迟单元，反馈增益 $+1/4$，输出乘以 $-\dfrac{14}{3}$。
- **子系统二** $H_b(z) = \dfrac{1}{1 + \frac{1}{2}z^{-1}}$，增益 $\dfrac{5}{3}$：一个延迟单元，反馈增益 $-\dfrac{1}{2}$，输出乘以 $\dfrac{5}{3}$。

两路输出相加得 $y[n]$。共需两个延迟单元。

## 八、采样间隔与频谱分析

**题目 17** 如果信号 $x_1(t)$ 的最高频率为 $100\text{ Hz}$，$x_2(t)$ 的最高频率为 $300\text{ Hz}$，试确定对以下每一个信号进行冲激串采样，所允许的最大采样间隔 $T$。

- ① $f(t) = x_1(t) + x_2(t)$
- ② $f(t) = x_1(t/2)$
- ③ $f(t) = x_2(2t)$
- ④ $f(t) = x_1(t) x_2(t/3)$

**解：**

奈奎斯特采样定理：$f_s \ge 2f_{\max}$，最大采样间隔 $T_{\max} = \dfrac{1}{2f_{\max}}$。

---

**①** $f(t) = x_1(t) + x_2(t)$

加法不展宽频谱，$f_{\max} = \max(100,\ 300) = 300$ Hz。

$$T_{\max} = \frac{1}{2 \times 300} = \frac{1}{600}\ \text{s}$$

---

**②** $f(t) = x_1(t/2)$

时域展宽 $2$ 倍 → 频域压缩 $2$ 倍，$f_{\max} = 100 / 2 = 50$ Hz。

$$T_{\max} = \frac{1}{2 \times 50} = \frac{1}{100}\ \text{s}$$

---

**③** $f(t) = x_2(2t)$

时域压缩 $2$ 倍 → 频域展宽 $2$ 倍，$f_{\max} = 300 \times 2 = 600$ Hz。

$$T_{\max} = \frac{1}{2 \times 600} = \frac{1}{1200}\ \text{s}$$

---

**④** $f(t) = x_1(t)\,x_2(t/3)$

两信号时域相乘 → 频域卷积，最高频率为两信号最高频率之和。

$x_2(t/3)$：时域展宽 $3$ 倍 → $f_{\max2} = 300/3 = 100$ Hz。

$$f_{\max} = f_{\max1} + f_{\max2} = 100 + 100 = 200\ \text{Hz}$$

$$T_{\max} = \frac{1}{2 \times 200} = \frac{1}{400}\ \text{s}$$

**题目 18** 在图 5.9(a) 所示的系统中，已知输入信号 $x(t)$ 的频谱 $X(j\omega)$ 如图 5.9(b) 所示，试确定并粗略画出 $y(t)$ 的频谱 $Y(e^{j\omega})$。

**系统框图：** 这是一个级联的信号处理系统：
1. 第一级调制：输入信号 $x(t)$ 与载波 $\cos(5\omega_c t)$ 相乘，得到信号 $x_1(t)$；
2. 第一级滤波：$x_1(t)$ 通过带通滤波器，通带为 $[-5\omega_c,\ -3\omega_c] \cup [3\omega_c,\ 5\omega_c]$（增益 1），输出 $x_2(t)$；
3. 第二级调制：$x_2(t)$ 与载波 $\cos(3\omega_c t)$ 相乘，得到信号 $x_3(t)$；
4. 第二级滤波：通过低通滤波器，通带 $[-3\omega_c,\ 3\omega_c]$（增益 1），输出 $y(t)$。

**输入频谱 $X(j\omega)$：** 三角形脉冲，偶对称，峰值在 $\omega=0$ 处、幅度为 1，非零范围 $[-2\omega_c,\ 2\omega_c]$。

**解：**

**步骤 1：** $x_1(t) = x(t)\cos(5\omega_c t)$

$$X_1(j\omega) = \frac{1}{2}\big[X(j(\omega-5\omega_c)) + X(j(\omega+5\omega_c))\big]$$

得到两个高度减半的三角形，中心分别位于 $\pm 5\omega_c$，跨度 $[3\omega_c, 7\omega_c]$ 和 $[-7\omega_c, -3\omega_c]$。

**步骤 2：** BPF 仅保留 $[3\omega_c, 5\omega_c] \cup [-5\omega_c, -3\omega_c]$，即每个三角形的一半：

$$X_2(j\omega) = \begin{cases}
\frac{1}{2}X(j(\omega-5\omega_c)) = \dfrac{\omega}{4\omega_c} - \dfrac{3}{4}, & \omega \in [3\omega_c,\,5\omega_c] \\[6pt]
\frac{1}{2}X(j(\omega+5\omega_c)) = -\dfrac{\omega}{4\omega_c} - \dfrac{3}{4}, & \omega \in [-5\omega_c,\,-3\omega_c]
\end{cases}$$

幅值：$[3\omega_c, 5\omega_c]$ 从 $0$ 线性增至 $\frac{1}{2}$；$[-5\omega_c, -3\omega_c]$ 从 $\frac{1}{2}$ 线性降至 $0$。

**步骤 3：** $x_3(t) = x_2(t)\cos(3\omega_c t)$

$$X_3(j\omega) = \frac{1}{2}\big[X_2(j(\omega-3\omega_c)) + X_2(j(\omega+3\omega_c))\big]$$

将 $X_2$ 左右各平移 $3\omega_c$ 并再次减半（峰值变为 $\frac{1}{4}$），得到四段：

| 频率区间 | 来源 | 形状 |
|----------|------|------|
| $[-8\omega_c,\,-6\omega_c]$ | $X_2(j(\omega+3\omega_c))$ 左支 | $\frac{1}{4}\to 0$（递减） |
| $[-2\omega_c,\,0]$ | $X_2(j(\omega-3\omega_c))$ 左支 | $0\gets\frac{1}{4}$（递减） |
| $[0,\,2\omega_c]$ | $X_2(j(\omega+3\omega_c))$ 右支 | $0\to\frac{1}{4}$（递增） |
| $[6\omega_c,\,8\omega_c]$ | $X_2(j(\omega-3\omega_c))$ 右支 | $0\gets\frac{1}{4}$（递减） |

**步骤 4：** LPF 仅保留 $[-3\omega_c, 3\omega_c]$，即中间两段：

$$Y(j\omega) = \begin{cases}
-\dfrac{\omega}{8\omega_c}, & \omega \in [-2\omega_c,\,0] \\[6pt]
\phantom{-}\dfrac{\omega}{8\omega_c}, & \omega \in [0,\,2\omega_c]
\end{cases}$$

即 $\boxed{Y(j\omega) = \dfrac{|\omega|}{8\omega_c},\quad |\omega| \le 2\omega_c}$，其余为 $0$。

**频谱形状描述：** $Y(j\omega)$ 为倒三角形（V 形），偶对称，中心 $\omega=0$ 处取最小值 $0$，在 $\omega=\pm 2\omega_c$ 处取峰值 $\frac{1}{4}$。

- ② $T = 1 \times 10^{-3}\text{ s}$

**题目 20** 试确定下列各信号的奈奎斯特频率。

- ① $x(t) = 2 + \cos(1000\pi t) + \sin(3000\pi t)$
- ② $x(t) = \left(\dfrac{\sin \omega_c t}{\pi t}\right)^2$
- ③ $x(t) = \left(\dfrac{\sin 1000\pi t}{\pi t}\right) * \left(\dfrac{\sin 2000\pi t}{\pi t}\right)$

**解：**

---

**题目 19** 截止频率 $\omega_c = 2000\pi$ rad/s，即 $f_c = 1000$ Hz。$x_1(t)$ 的最高频率为 $f_{\max} = 1000$ Hz。

奈奎斯特采样定理：$f_s \ge 2f_{\max} = 2000$ Hz，即 $T \le \dfrac{1}{2000} = 0.5 \times 10^{-3}$ s。

| 选项 | $T$ (s) | $f_s$ (Hz) | 满足 $T \le 0.5\times 10^{-3}$？ |
|------|---------|------------|:--:|
| ① | $0.25\times 10^{-3}$ | 4000 | ✓ |
| ② | $1\times 10^{-3}$ | 1000 | ✗ |
| ③ | $0.5\times 10^{-3}$ | 2000 | ✓ |
| ④ | $0.5\times 10^{-4}$ | 20000 | ✓ |

$$\boxed{\text{可选 ①、③、④}}$$

---

**题目 20**

① $x(t) = 2 + \cos(1000\pi t) + \sin(3000\pi t)$

分量频率：DC ($0$ Hz)，$500$ Hz，$1500$ Hz。最高频率 $f_{\max} = 1500$ Hz。

$$\boxed{f_{\text{Nyquist}} = 2 \times 1500 = 3000\ \text{Hz}}$$

---

② $x(t) = \left(\dfrac{\sin \omega_c t}{\pi t}\right)^2$

$\mathcal{F}\!\left\{\dfrac{\sin \omega_c t}{\pi t}\right\} = \operatorname{rect}\!\left(\dfrac{\omega}{2\omega_c}\right)$，矩形宽度 $[-\omega_c,\ \omega_c]$。

时域平方对应频域卷积：$X(j\omega) = \dfrac{1}{2\pi} \operatorname{rect}\!\left(\dfrac{\omega}{2\omega_c}\right) * \operatorname{rect}\!\left(\dfrac{\omega}{2\omega_c}\right)$，结果为三角形，支撑域 $[-2\omega_c,\ 2\omega_c]$。

最高角频率 $\omega_{\max} = 2\omega_c$。

$$\boxed{f_{\text{Nyquist}} = 2 \cdot \frac{2\omega_c}{2\pi} = \frac{2\omega_c}{\pi}\ \text{Hz}\quad\big(\omega_{\text{Nyquist}} = 4\omega_c\ \text{rad/s}\big)}$$

---

③ $x(t) = \left(\dfrac{\sin 1000\pi t}{\pi t}\right) * \left(\dfrac{\sin 2000\pi t}{\pi t}\right)$

时域卷积对应频域乘积。第一个 sinc 的频谱为 $\operatorname{rect}\!\left(\frac{\omega}{2000\pi}\right)$（宽度 $\pm 1000\pi$），第二个为 $\operatorname{rect}\!\left(\frac{\omega}{4000\pi}\right)$（宽度 $\pm 2000\pi$）。

乘积取交集（较窄者）：$X(j\omega) = \operatorname{rect}\!\left(\frac{\omega}{2000\pi}\right)$，带宽 $[-1000\pi,\ 1000\pi]$ rad/s。

$f_{\max} = \dfrac{1000\pi}{2\pi} = 500$ Hz。

$$\boxed{f_{\text{Nyquist}} = 2 \times 500 = 1000\ \text{Hz}\quad(\omega_{\text{Nyquist}} = 2000\pi\ \text{rad/s})}$$
