# 四大变换 公式手册

---

## 一、连续时间傅里叶变换（CTFT）

### 1.1 定义

$$
\boxed{X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt}
\qquad
\boxed{x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega}
$$

### 1.2 常用变换对

| $x(t)$ | $X(j\omega)$ |
|--------|-------------|
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\delta(\omega)$ |
| $\delta(t - t_0)$ | $e^{-j\omega t_0}$ |
| $e^{j\omega_0 t}$ | $2\pi\delta(\omega - \omega_0)$ |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$ |
| $\sin(\omega_0 t)$ | $-j\pi[\delta(\omega - \omega_0) - \delta(\omega + \omega_0)]$ |
| $u(t)$ | $\dfrac{1}{j\omega} + \pi\delta(\omega)$ |
| $\operatorname{sgn}(t)$ | $\dfrac{2}{j\omega}$ |
| $e^{-at}u(t),\; a>0$ | $\dfrac{1}{a + j\omega}$ |
| $t e^{-at}u(t),\; a>0$ | $\dfrac{1}{(a + j\omega)^2}$ |
| $t^n e^{-at}u(t),\; a>0$ | $\dfrac{n!}{(a + j\omega)^{n+1}}$ |
| $\dfrac{t^{n-1}}{(n-1)!}e^{-at}u(t),\; a>0$ | $\dfrac{1}{(a + j\omega)^n}$ |
| $e^{-a|t|},\; a>0$ | $\dfrac{2a}{a^2 + \omega^2}$ |
| $\dfrac{1}{a^2 + t^2}$ | $\dfrac{\pi}{a} e^{-a|\omega|}$ |
| $\operatorname{rect}\!\left(\dfrac{t}{\tau}\right)$ | $\tau\operatorname{sinc}\!\left(\dfrac{\omega\tau}{2\pi}\right)$ |
| $\dfrac{W}{\pi}\operatorname{sinc}(Wt)$ | $\operatorname{rect}\!\left(\dfrac{\omega}{2W}\right)$ |
| $\dfrac{\sin(\omega_0 t)}{\pi t}$ | $\operatorname{rect}\!\left(\dfrac{\omega}{2\omega_0}\right)$ |
| $\sum_{n=-\infty}^{+\infty} \delta(t - nT)$ | $\dfrac{2\pi}{T}\sum_{k=-\infty}^{+\infty} \delta\!\left(\omega - \dfrac{2\pi k}{T}\right)$ |
| $\displaystyle\sum_{k=0}^{\infty} a^k \delta(t - kT),\; |a|<1$ | $\dfrac{1}{1 - a e^{-j\omega T}}$ |

### 1.3 性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $A x_1 + B x_2$ | $A X_1 + B X_2$ |
| **时移** | $x(t - t_0)$ | $e^{-j\omega t_0} X(j\omega)$ |
| **频移** | $e^{j\omega_0 t} x(t)$ | $X(j(\omega - \omega_0))$ |
| **时间反转** | $x(-t)$ | $X(-j\omega)$ |
| **尺度变换** | $x(at)$ | $\dfrac{1}{|a|} X\!\left(\dfrac{j\omega}{a}\right)$ |
| **时域卷积** | $x(t) * h(t)$ | $X(j\omega) H(j\omega)$ |
| **频域卷积** | $x(t) h(t)$ | $\dfrac{1}{2\pi} X(j\omega) * H(j\omega)$ |
| **$n$阶微分** | $\dfrac{d^n x}{dt^n}$ | $(j\omega)^n X(j\omega)$ |
| **积分** | $\displaystyle\int_{-\infty}^{t} x(\tau) d\tau$ | $\dfrac{X(j\omega)}{j\omega} + \pi X(0)\delta(\omega)$ |
| **频域微分** | $t^n x(t)$ | $j^{\,n} \dfrac{d^{\,n} X}{d\omega^{\,n}}$ |
| **对偶性** | $X(jt)$ | $2\pi x(-\omega)$ |
| **帕斯瓦尔** | $\displaystyle\int |x(t)|^2 dt$ | $\displaystyle\frac{1}{2\pi}\int |X(j\omega)|^2 d\omega$ |

**常用逆变换**：

| $X(j\omega)$ | $x(t)$ |
|-------------|--------|
| $\cos(a\omega)$ | $\dfrac{1}{2}[\delta(t + a) + \delta(t - a)]$ |
| $\cos(a\omega + \phi)$ | $\dfrac{1}{2}[e^{j\phi}\delta(t + a) + e^{-j\phi}\delta(t - a)]$ |
| $u(\omega)$ | $\dfrac{1}{2}\delta(t) - \dfrac{1}{j2\pi t}$ |
| $\dfrac{2\sin[a(\omega - \omega_0)]}{\omega - \omega_0}$ | $e^{j\omega_0 t}[u(t + a) - u(t - a)]$ |

### 1.4 周期信号的 CTFT

$$
X(j\omega) = 2\pi \sum_{k=-\infty}^{+\infty} X[k] \,\delta(\omega - k\omega_0)
$$

## 二、离散时间傅里叶变换（DTFT）

### 2.1 定义

$$
\boxed{X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n}}
\qquad
\boxed{x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega}
$$

> $X(e^{j\omega})$ 是 $\omega$ 的连续函数，周期为 $2\pi$。

### 2.2 常用变换对

| $x[n]$ | $X(e^{j\omega})$ |
|--------|-----------------|
| $\delta[n]$ | $1$ |
| $\delta[n - n_0]$ | $e^{-j\omega n_0}$ |
| $1$（常数序列） | $2\pi \sum_{k} \delta(\omega - 2\pi k)$ |
| $e^{j\omega_0 n}$ | $2\pi \sum_{k} \delta(\omega - \omega_0 - 2\pi k)$ |
| $\cos(\omega_0 n)$ | $\pi\sum_k [\delta(\omega - \omega_0 - 2\pi k) + \delta(\omega + \omega_0 - 2\pi k)]$ |
| $\sin(\omega_0 n)$ | $-j\pi\sum_k [\delta(\omega - \omega_0 - 2\pi k) - \delta(\omega + \omega_0 - 2\pi k)]$ |
| $u[n]$ | $\dfrac{1}{1 - e^{-j\omega}} + \pi \sum_k \delta(\omega - 2\pi k)$ |
| $a^n u[n],\; |a| < 1$ | $\dfrac{1}{1 - a e^{-j\omega}}$ |
| $(n+1) a^n u[n],\; |a| < 1$ | $\dfrac{1}{(1 - a e^{-j\omega})^2}$ |
| $n a^n u[n],\; |a| < 1$ | $\dfrac{a e^{-j\omega}}{(1 - a e^{-j\omega})^2}$ |
| $a^{|n|},\; |a| < 1$ | $\dfrac{1 - a^2}{1 - 2a\cos\omega + a^2}$ |
| $R_M[n] = \begin{cases} 1, & 0 \le n < M \\ 0, & \text{其他} \end{cases}$ | $e^{-j\omega\frac{M-1}{2}} \dfrac{\sin(\omega M/2)}{\sin(\omega/2)}$ |
| $\dfrac{\sin(Wn)}{\pi n},\; 0 < W < \pi$ | $\begin{cases} 1, & |\omega| < W \\ 0, & W < |\omega| \le \pi \end{cases}$ |

### 2.3 性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $a x_1 + b x_2$ | $a X_1 + b X_2$ |
| **时移** | $x[n - n_0]$ | $e^{-j\omega n_0} X(e^{j\omega})$ |
| **频移** | $e^{j\omega_0 n} x[n]$ | $X(e^{j(\omega - \omega_0)})$ |
| **时间反转** | $x[-n]$ | $X(e^{-j\omega})$ |
| **共轭** | $x^*[n]$ | $X^*(e^{-j\omega})$ |
| **时域卷积** | $x_1[n] * x_2[n]$ | $X_1 X_2$ |
| **频域卷积** | $x_1[n]\, x_2[n]$ | $\dfrac{1}{2\pi}\displaystyle\int_{-\pi}^{\pi} X_1(e^{j\theta}) X_2(e^{j(\omega-\theta)}) d\theta$ |
| **一阶差分** | $x[n] - x[n-1]$ | $(1 - e^{-j\omega}) X(e^{j\omega})$ |
| **累加** | $\displaystyle\sum_{k=-\infty}^{n} x[k]$ | $\dfrac{X}{1 - e^{-j\omega}} + \pi X(e^{j0})\sum_k\delta(\omega - 2\pi k)$ |
| **频域微分** | $n x[n]$ | $j \dfrac{d X}{d\omega}$ |
| **帕斯瓦尔** | $\displaystyle\sum_n |x[n]|^2$ | $\displaystyle\frac{1}{2\pi}\int_{-\pi}^{\pi} |X|^2 d\omega$ |

## 三、拉普拉斯变换

### 3.1 定义

**双边**：
$$
\boxed{X(s) = \int_{-\infty}^{+\infty} x(t) e^{-st} dt},\quad s = \sigma + j\omega
$$

**单边**：
$$
\boxed{\mathcal{X}(s) = \int_{0^-}^{\infty} x(t) e^{-st} dt}
$$

> **傅里叶变换是拉普拉斯变换在虚轴上的特例**：$X(j\omega) = X(s)\big|_{s=j\omega}$（当 $j\omega \in \text{ROC}$）

### 3.2 ROC 规律

| 信号类型 | ROC 形状 | 边界 |
|----------|---------|------|
| 右边（因果）信号 | $\Re\{s\} > \sigma_{\min}$ | 最右极点实部 |
| 左边（反因果）信号 | $\Re\{s\} < \sigma_{\max}$ | 最左极点实部 |
| 双边信号 | $\sigma_R < \Re\{s\} < \sigma_L$ | 交集 |
| 时限信号 | 整个 s 平面 | — |

> **因果+稳定** $\iff$ 所有极点 $\Re\{p\} < 0$，ROC 包含虚轴

### 3.3 常用变换对

| $x(t)$ | $X(s)$ | ROC |
|--------|--------|-----|
| $\delta(t)$ | $1$ | 全平面 |
| $\delta(t - t_0)$ | $e^{-s t_0}$ | 全平面 |
| $u(t)$ | $\dfrac{1}{s}$ | $\Re\{s\} > 0$ |
| $-u(-t)$ | $\dfrac{1}{s}$ | $\Re\{s\} < 0$ |
| $t u(t)$ | $\dfrac{1}{s^2}$ | $\Re\{s\} > 0$ |
| $t^n u(t)$ | $\dfrac{n!}{s^{\,n+1}}$ | $\Re\{s\} > 0$ |
| $e^{-at}u(t)$ | $\dfrac{1}{s + a}$ | $\Re\{s\} > -a$ |
| $-e^{-at}u(-t)$ | $\dfrac{1}{s + a}$ | $\Re\{s\} < -a$ |
| $t e^{-at}u(t)$ | $\dfrac{1}{(s + a)^2}$ | $\Re\{s\} > -a$ |
| $t^n e^{-at}u(t)$ | $\dfrac{n!}{(s + a)^{n+1}}$ | $\Re\{s\} > -a$ |
| $\dfrac{t^{n-1}}{(n-1)!}e^{-at}u(t)$ | $\dfrac{1}{(s + a)^n}$ | $\Re\{s\} > -a$ |
| $\cos(\omega_0 t)u(t)$ | $\dfrac{s}{s^2 + \omega_0^2}$ | $\Re\{s\} > 0$ |
| $\sin(\omega_0 t)u(t)$ | $\dfrac{\omega_0}{s^2 + \omega_0^2}$ | $\Re\{s\} > 0$ |
| $e^{-at}\cos(\omega_0 t)u(t)$ | $\dfrac{s + a}{(s + a)^2 + \omega_0^2}$ | $\Re\{s\} > -a$ |
| $e^{-at}\sin(\omega_0 t)u(t)$ | $\dfrac{\omega_0}{(s + a)^2 + \omega_0^2}$ | $\Re\{s\} > -a$ |
| $t\cos(\omega_0 t)u(t)$ | $\dfrac{s^2 - \omega_0^2}{(s^2 + \omega_0^2)^2}$ | $\Re\{s\} > 0$ |
| $t\sin(\omega_0 t)u(t)$ | $\dfrac{2\omega_0 s}{(s^2 + \omega_0^2)^2}$ | $\Re\{s\} > 0$ |
| $e^{at}u(-t)$ | $-\dfrac{1}{s - a}$ | $\Re\{s\} < a$ |
| $\displaystyle\sum_{k=0}^{\infty} \delta(t - kT)$ | $\dfrac{1}{1 - e^{-sT}}$ | $\Re\{s\} > 0$ |
| $u(t) - u(t - \tau)$ | $\dfrac{1 - e^{-s\tau}}{s}$ | 全平面 |

### 3.4 性质（双边变换）

| 性质 | 时域 | s 域 |
|------|------|------|
| **线性** | $a x_1 + b x_2$ | $a X_1 + b X_2$ |
| **时移** | $x(t - t_0)$ | $e^{-s t_0} X(s)$ |
| **s 域平移** | $e^{s_0 t} x(t)$ | $X(s - s_0)$ |
| **尺度变换** | $x(at)$ | $\dfrac{1}{|a|} X\!\left(\dfrac{s}{a}\right)$ |
| **时域微分** | $\dfrac{dx}{dt}$ | $s X(s)$ |
| **$n$阶微分** | $\dfrac{d^n x}{dt^n}$ | $s^n X(s)$ |
| **s 域微分** | $-t x(t)$ | $\dfrac{dX}{ds}$ |
| **高阶 s 域微分** | $(-t)^n x(t)$ | $\dfrac{d^n X}{ds^n}$ |
| **时域积分** | $\displaystyle\int_{-\infty}^{t} x(\tau) d\tau$ | $\dfrac{1}{s} X(s)$ |
| **卷积** | $x_1(t) * x_2(t)$ | $X_1(s) X_2(s)$ |

### 3.5 单边变换 —— 时域微分

| 阶数 | 单边变换 |
|------|---------|
| 一阶 | $s\mathcal{X}(s) - x(0^-)$ |
| 二阶 | $s^2\mathcal{X}(s) - s x(0^-) - x'(0^-)$ |
| $n$阶 | $s^n\mathcal{X}(s) - s^{n-1}x(0^-) - \cdots - x^{(n-1)}(0^-)$ |

### 3.6 初值定理与终值定理

$$
x(0^+) = \lim_{s \to \infty} s X(s)
$$

$$
\lim_{t \to \infty} x(t) = \lim_{s \to 0} s X(s)
$$

> 终值定理条件：$sX(s)$ 所有极点 $\Re\{p\} < 0$（原点最多单极点）。

## 四、z 变换

### 4.1 定义

**双边**：
$$
\boxed{X(z) = \sum_{n=-\infty}^{+\infty} x[n] z^{-n}},\quad z = r e^{j\omega}
$$

**单边**：
$$
\boxed{\mathcal{X}(z) = \sum_{n=0}^{\infty} x[n] z^{-n}}
$$

> **DTFT 是 z 变换在单位圆上的特例**：$X(e^{j\omega}) = X(z)\big|_{z=e^{j\omega}}$（当 $|z|=1 \in \text{ROC}$）

### 4.2 ROC 规律

| 序列类型 | ROC 形状 | 边界 |
|----------|---------|------|
| 右边（因果）序列 | $|z| > r_{\min}$ | 最大极点模 |
| 左边（反因果）序列 | $|z| < r_{\max}$ | 最小极点模 |
| 双边序列 | $r_R < |z| < r_L$ | 交集 |
| 有限长序列 | 全平面（可能除 $0, \infty$） | — |

> **因果+稳定** $\iff$ 所有极点 $|p| < 1$，ROC 包含单位圆

### 4.3 常用变换对

| $x[n]$ | $X(z)$ | ROC |
|--------|--------|-----|
| $\delta[n]$ | $1$ | 全平面 |
| $\delta[n - n_0]$ | $z^{-n_0}$ | $n_0>0$：除 $z=0$；$n_0<0$：除 $z=\infty$ |
| $u[n]$ | $\dfrac{1}{1 - z^{-1}} = \dfrac{z}{z - 1}$ | $|z| > 1$ |
| $-u[-n-1]$ | $\dfrac{1}{1 - z^{-1}}$ | $|z| < 1$ |
| $n u[n]$ | $\dfrac{z^{-1}}{(1 - z^{-1})^2} = \dfrac{z}{(z - 1)^2}$ | $|z| > 1$ |
| $n^2 u[n]$ | $\dfrac{z^{-1}(1 + z^{-1})}{(1 - z^{-1})^3}$ | $|z| > 1$ |
| $a^n u[n]$ | $\dfrac{1}{1 - a z^{-1}} = \dfrac{z}{z - a}$ | $|z| > |a|$ |
| $-a^n u[-n-1]$ | $\dfrac{1}{1 - a z^{-1}}$ | $|z| < |a|$ |
| $n a^n u[n]$ | $\dfrac{a z^{-1}}{(1 - a z^{-1})^2}$ | $|z| > |a|$ |
| $(n+1) a^n u[n]$ | $\dfrac{1}{(1 - a z^{-1})^2}$ | $|z| > |a|$ |
| $\cos(\omega_0 n) u[n]$ | $\dfrac{1 - \cos\omega_0\, z^{-1}}{1 - 2\cos\omega_0\, z^{-1} + z^{-2}}$ | $|z| > 1$ |
| $\sin(\omega_0 n) u[n]$ | $\dfrac{\sin\omega_0\, z^{-1}}{1 - 2\cos\omega_0\, z^{-1} + z^{-2}}$ | $|z| > 1$ |
| $a^{|n|},\; |a| < 1$ | $\dfrac{1 - a^2}{(1 - a z^{-1})(1 - a z)}$ | $|a| < |z| < 1/|a|$ |
| $a^n u[-n]$ | $\dfrac{1}{1 - z/a}$ | $|z| < |a|$ |
| $n u[-n]$ | $-\dfrac{z}{(z - 1)^2}$ | $|z| < 1$ |
| $(-1)^n n u[n]$ | $\dfrac{-z^{-1}}{(1 + z^{-1})^2}$ | $|z| > 1$ |
| $(n-1)^2 u[n-1]$ | $\dfrac{z + 1}{(z - 1)^3}$ | $|z| > 1$ |
| $\dfrac{a^n}{n+1} u[n]$ | $-\dfrac{z}{a}\ln\!\left(1 - \dfrac{a}{z}\right)$ | $|z| > |a|$ |

**常用逆变换（因果）**：

| $X(z)$ | $x[n]$ |
|--------|--------|
| $\dfrac{1}{z - a}$ | $a^{n-1}u[n-1]$ |
| $\dfrac{z}{(z - a)^2}$ | $n a^{n-1}u[n]$ |
| $\dfrac{z}{(z - 1)(z - 2)^2}$ | $[1 - 2^n + n2^{n-1}]u[n]$ |

### 4.4 性质（双边变换）

| 性质 | 时域 | z 域 |
|------|------|------|
| **线性** | $a x_1 + b x_2$ | $a X_1 + b X_2$ |
| **时移** | $x[n - n_0]$ | $z^{-n_0} X(z)$ |
| **z 域尺度** | $z_0^n x[n]$ | $X(z/z_0)$ |
| **时间反转** | $x[-n]$ | $X(z^{-1})$ |
| **z 域微分** | $n x[n]$ | $-z \dfrac{dX}{dz}$ |
| **高阶 z 域微分** | $n^k x[n]$ | $\left(-z \dfrac{d}{dz}\right)^k X(z)$ |
| **共轭** | $x^*[n]$ | $X^*(z^*)$ |
| **卷积** | $x_1[n] * x_2[n]$ | $X_1(z) X_2(z)$ |
| **累加** | $\displaystyle\sum_{k=-\infty}^{n} x[k]$ | $\dfrac{X(z)}{1 - z^{-1}}$ |

### 4.5 单边变换 —— 时移

| 操作 | 单边变换 |
|------|---------|
| 单位延迟 | $\mathcal{Z}_u\{x[n-1]\} = z^{-1}\mathcal{X}(z) + x[-1]$ |
| 单位超前 | $\mathcal{Z}_u\{x[n+1]\} = z\mathcal{X}(z) - z x[0]$ |
| $n_0$ 延迟 | $\mathcal{Z}_u\{x[n-n_0]\} = z^{-n_0}\mathcal{X}(z) + \sum_{k=0}^{n_0-1} x[k-n_0] z^{-k}$ |

### 4.6 初值定理与终值定理

$$
x[0] = \lim_{z \to \infty} X(z) \qquad\text{（因果序列）}
$$

$$
\lim_{n \to \infty} x[n] = \lim_{z \to 1} (1 - z^{-1}) X(z) = \lim_{z \to 1} \frac{z-1}{z} X(z)
$$

> 终值定理条件：$(z-1)X(z)$ 极点均在单位圆内。
