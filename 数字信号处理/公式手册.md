# 数字信号处理 公式与方法手册

---

## 第一章 信号与系统基础

### 周期信号判定

**CT：** $T_0 = 2\pi/\omega_0$；多分量取 LCM；$\sin^2(\cdot)=\frac12[1-\cos(2\cdot)]$；被 $u(t)$ 截断→非周期

**DT：** $\omega_0/(2\pi)=p/q\in\mathbb{Q}$ → 周期 $N_0=q$；求法：最小正整数 $N$ 使 $\omega_0 N=2\pi k$

### 系统四性

| 特性 | 判定 | LTI 充要条件 |
|------|------|------------|
| 线性 | $T\{a_1x_1+a_2x_2\}=a_1T\{x_1\}+a_2T\{x_2\}$ | — |
| 时不变 | $T\{x(t-t_0)\}=y(t-t_0)$ | $h$ 不含显式 $t$/$n$ |
| 因果 | 输出不依赖未来输入 | $h(t)=0\,(t<0)$ / $h[n]=0\,(n<0)$ |
| 稳定 | 有界入→有界出 | $\int|h|\,\mathrm{d}t<\infty$ / $\sum|h[n]|<\infty$ |

**5 类典型时变系统：** 时变系数 $g(t)x(t)$、时间反转 $x(-t)$、尺度变换 $x(at)$、分段含绝对时间、分段依赖 $n$ 符号

**无记忆 LTI：** $h[n]=K\delta[n]$（仅在 $n=0$ 非零）

**稳定性速判：** $e^{-at}u(t)$ 稳当 $a>0$；$a^n u[n]$ 稳当 $|a|<1$；$a^n u[-n]$ 稳当 $|a|>1$；$y[n]=nx[n]$ 不稳

### 概念辨析

- 因果 $\not\Rightarrow$ 稳定，稳定 $\not\Rightarrow$ 因果
- 零状态响应 = 初始为零仅由激励产生；零输入响应 = 无激励仅由初始状态产生
- 自由响应 $\neq$ 零输入（零状态中也含自由分量）
- $x(t)\sum\delta=\sum x(nT)\delta$（乘=采样）；$x(t)*\sum\delta=\sum x(t-nT)$（卷积=延拓）

## 第二章 时域分析

### 卷积

**CT：** $y(t)=\int x(\tau)h(t-\tau)\,\mathrm{d}\tau$

**DT：** $y[n]=\sum_k x[k]h[n-k]$

### 卷积性质

| 性质 | 公式 |
|------|------|
| 交换律 | $x*h = h*x$ |
| 结合律 | $(x*h_1)*h_2 = x*(h_1*h_2)$ |
| 分配律 | $x*(h_1+h_2) = x*h_1 + x*h_2$ |
| 延迟 | $y(t-t_0) = x(t-t_0)*h(t) = x(t)*h(t-t_0)$ |
| 与 $\delta$ 卷积 | $x(t)*\delta(t-t_0)=x(t-t_0)$ |
| 与冲激串卷积 | $x[n]*\sum\delta[n-kN]=\sum x[n-kN]$（周期延拓） |
| DT 延迟易错 | $y[n-1]=x[n-1]*h[n]\;\neq\;x[n-1]*h[n-1]$ |

### 经典结果

| 卷积 | 结果 |
|------|------|
| $\alpha^n u[n]*\beta^n u[n]\;(\alpha\neq\beta)$ | $\frac{\alpha^{n+1}-\beta^{n+1}}{\alpha-\beta}u[n]$ |
| $\alpha^n u[n]*\alpha^n u[n]$ | $(n+1)\alpha^n u[n]$ |
| $[u(t)-u(t-T_1)]*[u(t)-u(t-T_2)]$ | 梯形，宽度 $T_1+T_2$ |

### 时域分析

**特征方程 → 特征根 →** $y_{zi}(t)=\sum C_i e^{\lambda_i t}$，由初始条件定 $C_i$

**$H(s)\to h(t)$；** $Y_{zs}(s)=H(s)X(s)\to y_{zs}(t)$；**全响应 = $y_{zi}+y_{zs}$**

### 频域法求卷积

$$y(t)=x(t)*h(t)\;\longleftrightarrow\;Y(j\omega)=X(j\omega)H(j\omega)$$

先求 $X(j\omega)$ 和 $H(j\omega)$，相乘后部分分式展开 → 逆变换得 $y(t)$。适用于指数类信号卷积。

### 阶跃响应 → 系统函数

$$s(t)=h(t)*u(t)\;\longleftrightarrow\;S(s)=\frac{H(s)}{s}\quad\Rightarrow\quad H(s)=s\cdot S(s)$$

## 第三章 傅里叶变换

### CTFT 定义

$$\boxed{X(j\omega)=\int_{-\infty}^{\infty}x(t)\,e^{-j\omega t}\,\mathrm{d}t}$$

$$\boxed{x(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)\,e^{j\omega t}\,\mathrm{d}\omega}$$

### CTFT 变换对

| $x(t)$ | $X(j\omega)$ |
|--------|-------------|
| $\delta(t)$ | $1$ |
| $\delta(t-t_0)$ | $e^{-j\omega t_0}$ |
| $\delta'(t)$ | $j\omega$ |
| $1$ | $2\pi\delta(\omega)$ |
| $e^{j\omega_0 t}$ | $2\pi\delta(\omega-\omega_0)$ |
| $\cos\omega_0 t$ | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$ |
| $\sin\omega_0 t$ | $\dfrac{\pi}{j}[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)]$ |
| $u(t)$ | $\pi\delta(\omega)+\dfrac{1}{j\omega}$ |
| $e^{-at}u(t)\;(a>0)$ | $\dfrac{1}{a+j\omega}$ |
| $t e^{-at}u(t)\;(a>0)$ | $\dfrac{1}{(a+j\omega)^2}$ |
| $e^{-at}\cos\omega_0 t\,u(t)$ | $\dfrac{a+j\omega}{(a+j\omega)^2+\omega_0^2}$ |
| $e^{-a|t|}\;(a>0)$ | $\dfrac{2a}{a^2+\omega^2}$ |
| $\dfrac{1}{a^2+t^2}$ | $\dfrac{\pi}{a}e^{-a|\omega|}$ |
| $\operatorname{rect}\!\left(\dfrac{t}{\tau}\right)$ | $\tau\,\mathrm{Sa}\!\left(\dfrac{\omega\tau}{2}\right)=\dfrac{2\sin(\omega\tau/2)}{\omega}$ |
| $\dfrac{\sin Wt}{\pi t}=\dfrac{W}{\pi}\mathrm{Sa}(Wt)$ | $\operatorname{rect}\!\left(\dfrac{\omega}{2W}\right)$ |
| $\displaystyle\sum_{k=0}^\infty a^k\delta(t-kT)$ | $\dfrac{1}{1-ae^{-jT\omega}}$ |

### CTFT 性质

| 性质 | 时域 | 频域 |
|------|------|------|
| 线性 | $ax_1+bx_2$ | $aX_1+bX_2$ |
| 时移 | $x(t-t_0)$ | $e^{-j\omega t_0}X(j\omega)$ |
| 频移 | $e^{j\omega_0 t}x(t)$ | $X(j(\omega-\omega_0))$ |
| 尺度 | $x(at)$ | $\dfrac{1}{|a|}X\!\left(j\dfrac{\omega}{a}\right)$ |
| 时间反转 | $x(-t)$ | $X(-j\omega)$ |
| 共轭 | $x^*(t)$ | $X^*(-j\omega)$ |
| 时域微分 | $\dfrac{dx}{dt}$ | $j\omega X(j\omega)$ |
| 时域积分 | $\displaystyle\int_{-\infty}^t x(\tau)\,\mathrm{d}\tau$ | $\dfrac{X(j\omega)}{j\omega}+\pi X(0)\delta(\omega)$ |
| 频域微分 | $t x(t)$ | $j\dfrac{dX}{d\omega}$ |
| 卷积 | $x(t)*h(t)$ | $X(j\omega)H(j\omega)$ |
| 乘积 | $x(t)h(t)$ | $\dfrac{1}{2\pi}X(j\omega)*H(j\omega)$ |
| 调制 | $x(t)\cos\omega_0 t$ | $\dfrac12[X(j(\omega-\omega_0))+X(j(\omega+\omega_0))]$ |
| 对偶 | $X(jt)$ | $2\pi x(-\omega)$ |
| 帕塞瓦尔 | $\displaystyle\int|x|^2\,\mathrm{d}t$ | $\dfrac{1}{2\pi}\displaystyle\int|X|^2\,\mathrm{d}\omega$ |

> 实信号对称性：若 $x(t)$ 实，则 $X(-j\omega)=X^*(j\omega)$（共轭对称），$|X|$ 偶对称，$\angle X$ 奇对称

### 连续时间傅里叶级数 (CTFS)

**周期 $T_0=2\pi/\omega_0$ 的信号 $x(t)$：**

| | 公式 |
|---|------|
| 综合（合成） | $\displaystyle x(t)=\sum_{k=-\infty}^{\infty}a_k\,e^{jk\omega_0 t}$ |
| 分析（求系数） | $\displaystyle a_k=\frac{1}{T_0}\int_{T_0}x(t)\,e^{-jk\omega_0 t}\,\mathrm{d}t$ |
| 直流分量 | $a_0=\dfrac{1}{T_0}\displaystyle\int_{T_0}x(t)\,\mathrm{d}t$ |

**常用周期信号的 FS 系数：**

| 信号 | $a_k$ |
|------|------|
| $x(t)=\cos\omega_0 t$ | $a_{\pm1}=\dfrac12$，其余 $0$ |
| $x(t)=\sin\omega_0 t$ | $a_{\pm1}=\pm\dfrac{1}{2j}$，其余 $0$ |
| 周期冲激串 $\sum_n\delta(t-nT)$ | $a_k=\dfrac{1}{T}$（所有 $k$） |
| 周期方波（占空比 $D$） | $a_k\propto\mathrm{Sa}(k\pi D)$ |

**FS 系数收敛性：** 信号越光滑，$|a_k|$ 衰减越快。有断点时 $a_k\propto 1/k$，$k\to\infty$ 时 $a_k\to 0$。

### FS ↔ FT 的关系

周期信号的傅里叶变换是 FS 系数加权的频域冲激串：

$$\boxed{X(j\omega)=2\pi\sum_{k=-\infty}^{\infty}a_k\,\delta(\omega-k\omega_0)}$$

即：周期信号的频谱是离散的（仅在 $\omega=k\omega_0$ 处有冲激，强度 $2\pi a_k$）。

**LTI 系统对周期输入的稳态响应：**

$$x(t)=\sum_k a_k e^{jk\omega_0 t}\;\longrightarrow\;y(t)=\sum_k a_k H(jk\omega_0)\,e^{jk\omega_0 t}$$

系统仅改变各谐波的幅度和相位，输出仍是同周期的周期信号。

**吉布斯现象：** 用有限项 FS 近似有断点的信号时，在断点处出现过冲，幅度约跳变值的 9%，不随项数增加而消失。

**帕塞瓦尔（周期信号）：** $\displaystyle\frac{1}{T_0}\int_{T_0}|x(t)|^2\,\mathrm{d}t=\sum_{k=-\infty}^{\infty}|a_k|^2$

### DTFT 定义

$$\boxed{X(e^{j\omega})=\sum_{n=-\infty}^{\infty}x[n]\,e^{-j\omega n}}$$

$$\boxed{x[n]=\frac{1}{2\pi}\int_{-\pi}^{\pi}X(e^{j\omega})\,e^{j\omega n}\,\mathrm{d}\omega}$$

### DTFT 变换对

| $x[n]$ | $X(e^{j\omega})$ |
|--------|------------------|
| $\delta[n]$ | $1$ |
| $\delta[n-k]$ | $e^{-j\omega k}$ |
| $a^n u[n]\;(|a|<1)$ | $\dfrac{1}{1-ae^{-j\omega}}$ |
| $(n+1)a^n u[n]$ | $\dfrac{1}{(1-ae^{-j\omega})^2}$ |
| $\dfrac{\sin\omega_c n}{\pi n}$ | $\begin{cases}1,&|\omega|<\omega_c\\0,&\text{其余}\end{cases}$ |
| $x[n]=1$（所有 $n$） | $2\pi\sum_k\delta(\omega-2\pi k)$ |

### DTFT 性质

| 性质 | 时域 | 频域 |
|------|------|------|
| 线性 | $ax_1+bx_2$ | $aX_1+bX_2$ |
| 时移 | $x[n-n_0]$ | $e^{-j\omega n_0}X(e^{j\omega})$ |
| 频移 | $e^{j\omega_0 n}x[n]$ | $X(e^{j(\omega-\omega_0)})$ |
| 时间反转 | $x[-n]$ | $X(e^{-j\omega})$ |
| 共轭 | $x^*[n]$ | $X^*(e^{-j\omega})$ |
| 时域差分 | $x[n]-x[n-1]$ | $(1-e^{-j\omega})X(e^{j\omega})$ |
| 时域累加 | $\displaystyle\sum_{k=-\infty}^n x[k]$ | $\dfrac{X(e^{j\omega})}{1-e^{-j\omega}}+\pi X(e^{j0})\sum_k\delta(\omega-2\pi k)$ |
| 频域微分 | $n x[n]$ | $j\dfrac{dX}{d\omega}$ |
| 卷积 | $x[n]*h[n]$ | $X(e^{j\omega})H(e^{j\omega})$ |
| 乘积 | $x[n]h[n]$ | $\dfrac{1}{2\pi}X(e^{j\omega})\circledast H(e^{j\omega})$ |
| 调制 | $x[n]\cos\omega_0 n$ | $\dfrac12[X(e^{j(\omega-\omega_0)})+X(e^{j(\omega+\omega_0)})]$ |
| 帕塞瓦尔 | $\displaystyle\sum_n|x[n]|^2$ | $\dfrac{1}{2\pi}\displaystyle\int_{-\pi}^{\pi}|X(e^{j\omega})|^2\,\mathrm{d}\omega$ |

> 实序列对称性：$X(e^{-j\omega})=X^*(e^{j\omega})$（共轭对称）

### 概念

- **周期信号 → FT 是离散的**（冲激串）；时域离散 → 频域周期
- **时域压缩 → 频域展宽**：$x(at)$ 带宽 $\times|a|$
- **吉布斯现象**：有限项傅里叶级数在断点处过冲约 9%
- **LTI 特征函数**：$e^{st}\to H(s)e^{st}$；**DC 响应** $=H(0)\cdot\text{DC}_{\text{in}}$

## 第四章 拉普拉斯变换

### 定义

**双边：** $\displaystyle X(s)=\int_{-\infty}^{\infty}x(t)\,e^{-st}\,\mathrm{d}t$

**单边（工程常用）：** $\displaystyle\boxed{X(s)=\int_{0^-}^{\infty}x(t)\,e^{-st}\,\mathrm{d}t}$

**反变换：** $\displaystyle x(t)=\frac{1}{2\pi j}\int_{\sigma-j\infty}^{\sigma+j\infty}X(s)\,e^{st}\,\mathrm{d}s$

> $s=\sigma+j\omega$；ROC 是使积分收敛的 $s$ 区域

### 单边拉氏变换对（$x(t)=0,\;t<0$）

| $x(t)$ | $X(s)$ | ROC |
|--------|--------|-----|
| $\delta(t)$ | $1$ | 全 $s$ 平面 |
| $u(t)$ | $\dfrac{1}{s}$ | $\text{Re}\{s\}>0$ |
| $t^n u(t)$ | $\dfrac{n!}{s^{\,n+1}}$ | $\text{Re}\{s\}>0$ |
| $e^{-at}u(t)$ | $\dfrac{1}{s+a}$ | $\text{Re}\{s\}>-a$ |
| $t e^{-at}u(t)$ | $\dfrac{1}{(s+a)^2}$ | $\text{Re}\{s\}>-a$ |
| $t^n e^{-at}u(t)$ | $\dfrac{n!}{(s+a)^{n+1}}$ | $\text{Re}\{s\}>-a$ |
| $\cos\omega_0 t\,u(t)$ | $\dfrac{s}{s^2+\omega_0^2}$ | $\text{Re}\{s\}>0$ |
| $\sin\omega_0 t\,u(t)$ | $\dfrac{\omega_0}{s^2+\omega_0^2}$ | $\text{Re}\{s\}>0$ |
| $e^{-at}\cos\omega_0 t\,u(t)$ | $\dfrac{s+a}{(s+a)^2+\omega_0^2}$ | $\text{Re}\{s\}>-a$ |
| $e^{-at}\sin\omega_0 t\,u(t)$ | $\dfrac{\omega_0}{(s+a)^2+\omega_0^2}$ | $\text{Re}\{s\}>-a$ |
| 矩形脉冲 $[0,T]$ | $\dfrac{1-e^{-sT}}{s}$ | 全 $s$ 平面 |
| $\displaystyle\sum_{k=0}^\infty\delta(t-kT)$ | $\dfrac{1}{1-e^{-Ts}}$ | $\text{Re}\{s\}>0$ |

### 双边信号拉氏变换对

| $x(t)$ | $X(s)$ | ROC |
|--------|--------|-----|
| $-e^{-at}u(-t)$ | $\dfrac{1}{s+a}$ | $\text{Re}\{s\}<-a$ |
| $e^{at}u(-t)$ | $-\dfrac{1}{s-a}$ | $\text{Re}\{s\}<a$ |

### 性质

| 性质 | 公式 | ROC |
|------|------|-----|
| 线性 | $\mathcal{L}\{ax_1+bx_2\}=aX_1+bX_2$ | 至少 $R_1\cap R_2$ |
| 时移 | $\mathcal{L}\{x(t-t_0)u(t-t_0)\}=e^{-st_0}X(s)$ | 不变 |
| 频移 | $\mathcal{L}\{e^{-at}x(t)\}=X(s+a)$ | $R$ 平移 $-a$ |
| 尺度 | $\mathcal{L}\{x(at)\}=\dfrac{1}{a}X\!\left(\dfrac{s}{a}\right)\;(a>0)$ | $a\cdot R$ |
| 时间反转 | $\mathcal{L}\{x(-t)\}=X(-s)$ | $-R$（关于虚轴对称） |
| 时域微分 | $\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)$ | 不变 |
| s 域微分 | $\mathcal{L}\{t x(t)\}=-\dfrac{dX(s)}{ds}$ | 不变 |
| s 域积分 | $\mathcal{L}\!\left\{\dfrac{x(t)}{t}\right\}=\displaystyle\int_s^\infty X(\sigma)\,\mathrm{d}\sigma$ | 不变 |
| 时域卷积 | $\mathcal{L}\{x*h\}=X(s)H(s)$ | 至少 $R_1\cap R_2$ |
| 时域积分 | $\mathcal{L}\!\left\{\displaystyle\int_{0^-}^t x(\tau)\,\mathrm{d}\tau\right\}=\dfrac{X(s)}{s}$ | 至少 $R\cap\{\text{Re}\{s\}>0\}$ |
| 初值定理 | $x(0^+)=\lim\limits_{s\to\infty}sX(s)$ | 因果信号 |
| 终值定理 | $x(\infty)=\lim\limits_{s\to 0}sX(s)$ | 极点全在左半平面 |

### 单边拉氏变换的高阶微分性质

| 阶数 | 公式 |
|------|------|
| 一阶 | $\mathcal{L}\{x'(t)\}=sX(s)-x(0^-)$ |
| 二阶 | $\mathcal{L}\{x''(t)\}=s^2X(s)-sx(0^-)-x'(0^-)$ |
| $n$ 阶 | $\mathcal{L}\{x^{(n)}(t)\}=s^nX(s)-\displaystyle\sum_{k=0}^{n-1}s^{n-1-k}x^{(k)}(0^-)$ |

> 代入微分方程即可分出 $Y_{zi}(s)$（令 $X(s)=0$）和 $Y_{zs}(s)$（令初态$=0$）

### 反变换核心方法

| 情况 | 方法 |
|------|------|
| 含 $e^{-sT}$ 因子 | 先忽略 $e^{-sT}$ 做反变换得 $f(t)$，结果 $=f(t-T)u(t-T)$ |
| 复共轭极点 | 配方成 $(s+a)^2+\omega_0^2$，凑 $(s+a)$ 和 $\omega_0$ 的组合 |
| 分子次数 $\ge$ 分母 | 先长除分出 $\delta(t)$ 及导数项 |
| 有理真分式 | 部分分式展开 + 查表 |

### ROC → 时域方向

| ROC 相对于极点 $p$ | 时域信号 |
|:---:|---|
| $\text{Re}\{s\}>\text{Re}\{p\}$ | $e^{pt}u(t)$（右边/因果） |
| $\text{Re}\{s\}<\text{Re}\{p\}$ | $-e^{pt}u(-t)$（左边/反因果） |

### 系统函数

**微分方程 → $H(s)$：** $\displaystyle\sum_{k=0}^N a_k y^{(k)}(t)=\sum_{k=0}^M b_k x^{(k)}(t)$

$$H(s)=\frac{Y(s)}{X(s)}=\frac{\sum_{k=0}^M b_k s^k}{\sum_{k=0}^N a_k s^k}$$

**反馈系统（正反馈）：** $H(s)=\dfrac{H_1(s)}{1-kH_1(s)}$

### 稳定性判据

- **因果系统 BIBO 稳定** $\iff$ 所有极点 $\text{Re}\{s\}<0$（左半平面）
- **二阶 Routh-Hurwitz：** $D(s)=s^2+a_1s+a_0$，稳定 $\iff a_1>0,\;a_0>0$
- **因果+稳定不可兼得：** 同一 $H(s)$ 可选不同 ROC，需根据需求取舍

## 第五章 Z 变换

### 定义

**双边：** $\displaystyle X(z)=\sum_{n=-\infty}^{\infty}x[n]\,z^{-n}$

**单边（工程常用）：** $\displaystyle\boxed{X(z)=\sum_{n=0}^{\infty}x[n]\,z^{-n}}$

**反变换：** $\displaystyle x[n]=\frac{1}{2\pi j}\oint_C X(z)\,z^{\,n-1}\,\mathrm{d}z$

> $z=re^{j\omega}$；ROC 是使级数收敛的 $|z|$ 范围

### 变换对

| $x[n]$ | $X(z)$ | ROC |
|--------|--------|-----|
| $\delta[n]$ | $1$ | 全平面 |
| $\delta[n-k]$ | $z^{-k}$ | $k\!>\!0$ 除 $z\!=\!0$；$k\!<\!0$ 除 $\infty$ |
| $a^n u[n]$ | $\dfrac{1}{1-az^{-1}}=\dfrac{z}{z-a}$ | $|z|>|a|$ |
| $-a^n u[-n-1]$ | $\dfrac{1}{1-az^{-1}}=\dfrac{z}{z-a}$ | $|z|<|a|$ |
| $u[n]$ | $\dfrac{z}{z-1}$ | $|z|>1$ |
| $u[-n]$ | $\dfrac{1}{1-z}$ | $|z|<1$ |
| $n\,u[n]$ | $\dfrac{z}{(z-1)^2}$ | $|z|>1$ |
| $n\,u[-n]$ | $-\dfrac{z}{(z-1)^2}$ | $|z|<1$ |
| $n a^n u[n]$ | $\dfrac{az^{-1}}{(1-az^{-1})^2}=\dfrac{az}{(z-a)^2}$ | $|z|>|a|$ |
| $(n+1)a^n u[n]$ | $\dfrac{1}{(1-az^{-1})^2}$ | $|z|>|a|$ |
| $\dfrac{a^n}{n+1}u[n]$ | $-\dfrac{z}{a}\ln\!\left(1-\dfrac{a}{z}\right)$ | $|z|>|a|$ |
| $a^{|n|}$ | $\dfrac{1-a^2}{(1-az^{-1})(1-az)}$ | $|a|<|z|<1/|a|$ |

### 性质

| 性质 | 公式 | ROC |
|------|------|-----|
| 线性 | $\mathcal{Z}\{ax_1+bx_2\}=aX_1+bX_2$ | 至少 $R_1\cap R_2$ |
| 时移 | $\mathcal{Z}\{x[n-k]\}=z^{-k}X(z)$ | 不变（可能增减 $z=0,\infty$） |
| 频移（指数加权） | $\mathcal{Z}\{a^n x[n]\}=X(a^{-1}z)$ | $|a|\cdot R$（模值缩放 $|a|$ 倍） |
| z 域微分 | $\mathcal{Z}\{n x[n]\}=-z\,\dfrac{dX(z)}{dz}$ | 不变 |
| 时间反转 | $\mathcal{Z}\{x[-n]\}=X(z^{-1})$ | $1/R$（模值取倒数） |
| 共轭 | $\mathcal{Z}\{x^*[n]\}=X^*(z^*)$ | 不变 |
| 时域累加 | $\mathcal{Z}\!\left\{\displaystyle\sum_{k=-\infty}^n x[k]\right\}=\dfrac{X(z)}{1-z^{-1}}$ | 至少 $R\cap\{|z|>1\}$ |
| 卷积 | $\mathcal{Z}\{x[n]*h[n]\}=X(z)H(z)$ | 至少 $R_1\cap R_2$ |
| 初值定理 | $x[0]=\lim\limits_{z\to\infty}X(z)$ | 因果信号 |
| 终值定理 | $x[\infty]=\lim\limits_{z\to 1}(1-z^{-1})X(z)$ | $(1-z^{-1})X(z)$ 极点全在 $|z|<1$ 内 |

### ROC 规律

| 序列类型 | ROC |
|---------|-----|
| 右边序列 $(u[n])$ | $|z|>$ 最外极点模值 |
| 左边序列 $(u[-n-1])$ | $|z|<$ 最内极点模值 |
| 双边序列 | 环形 （极点间） |
| 有限长序列 | $0<|z|<\infty$（可能含 $0$ 或 $\infty$） |

### 反变换核心方法

| 情况 | 方法 |
|------|------|
| $|z|>|a|$（右边） | $\dfrac{z}{z-a}\to a^n u[n]$ |
| $|z|<|a|$（左边） | $\dfrac{z}{z-a}\to -a^n u[-n-1]$ |
| 对数函数（如 $\ln(1-az^{-1})$） | 幂级数展开比对系数 |
| 分子分母同次/高分子次 | 先长除分出 $\delta[n]$ 项 |
| 多重极点 | $\dfrac{z}{(z-a)^2}\to n a^{n-1}u[n]$ |

### 差分方程 → $H(z)$

$$H(z)=\frac{\sum_{k=0}^M b_k z^{-k}}{1+\sum_{k=1}^N a_k z^{-k}}$$

### 单边 Z 变换的时移性质（含初始条件）

| 移位 | 公式 |
|------|------|
| 延迟 1 | $\mathcal{Z}\{y[n-1]\}=z^{-1}Y(z)+y[-1]$ |
| 延迟 2 | $\mathcal{Z}\{y[n-2]\}=z^{-2}Y(z)+z^{-1}y[-1]+y[-2]$ |
| 延迟 $k$ | $\mathcal{Z}\{y[n-k]\}=z^{-k}Y(z)+\displaystyle\sum_{m=1}^{k}y[-m]\,z^{-(k-m)}$ |
| 超前 1 | $\mathcal{Z}\{y[n+1]\}=zY(z)-z\,y[0]$ |
| 超前 $k$ | $\mathcal{Z}\{y[n+k]\}=z^{k}Y(z)-\displaystyle\sum_{m=0}^{k-1}y[m]\,z^{k-m}$ |

> 代入差分方程 → 令 $X(z)=0$ 得 $Y_{zi}(z)$；令初态全零得 $Y_{zs}(z)$

### 稳定性判据

- **因果系统 BIBO 稳定** $\iff$ 所有极点 $|z|<1$（单位圆内）
- **同一 $H(z)$ 可选不同 ROC** → 对应因果/反因果/双边系统

### 三种实现结构

| 结构 | 方法 | 延迟单元 |
|------|------|:---:|
| 直接 II 型 | 先反馈后前馈，共用延迟链 | $\max(N,M)$ |
| 串联型 | 因式分解 $H(z)=\prod H_i(z)$，一/二阶节级联 | 各节之和 |
| 并联型 | 部分分式 $H(z)=C+\sum\frac{A_k}{1-p_k z^{-1}}$，各节求和 | 各节之和 |

## 第六章 采样定理与频谱分析

### 奈奎斯特定理

$$\boxed{f_s \ge 2f_{\max},\quad T \le \frac{1}{2f_{\max}}}$$

### 带宽计算

| 操作 | 带宽变化 |
|------|---------|
| $x_1+x_2$ | $f_{\max}=\max(f_{1\max},f_{2\max})$ |
| $x(at)$ | $f_{\max}' = |a|\cdot f_{\max}$（展宽→压缩，压缩→展宽） |
| $x_1\cdot x_2$ | $f_{\max}=f_{1\max}+f_{2\max}$（取和） |
| $x_1*x_2$ | $f_{\max}=\min(f_{1\max},f_{2\max})$（取交集） |
| $x^2(t)$ | $f_{\max}=2f_{\max}$（频域自卷积） |

### 调制 → 频谱搬移

$$\boxed{x(t)\cos\omega_0 t \;\leftrightarrow\; \frac12\big[X(j(\omega-\omega_0))+X(j(\omega+\omega_0))\big]}$$

调制将频谱搬移到 $\pm\omega_0$，幅度减半。

$(\cos\omega_0 t)^2=\frac12(1+\cos 2\omega_0 t)$ → 包含原频谱 $\frac12$ + 搬移到 $\pm 2\omega_0$ 的 $\frac14$ 倍。

### 采样恢复

- 理想 LPF 截止频率 $\omega_c$ 必须 $\ge \omega_{\max}$（信号的最高频率分量），且采样率 $f_s\ge 2f_c$
- $f_s=2f_{\max}$ 为临界采样；$f_s<2f_{\max}$ → 混叠
