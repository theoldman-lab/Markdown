# 习题

**填空题。**

1. 已知某一因果连续时间 LTI 系统的频率响应为 $H(j\omega)$，则该系统对输入信号 $x(t) = E + a_1 e^{j\omega_0 t} + a_{-1} e^{-j\omega_0 t}$ 的响应为 \_\_\_\_\_\_\_\_\_\_。

2. 求频谱 $X(j\omega) = u(\omega)$ 的傅里叶反变换 $x(t)$ 为 \_\_\_\_\_\_\_\_\_\_。

3. 设某一周期锯齿脉冲信号的傅里叶级数的系数为 $a_k$，当 $k \to \infty$ 时，$a_k \to$ \_\_\_\_\_\_\_\_\_\_。

4. 设信号 $x(t)$ 的频带为 $B$，则 $x(2t)$ 的频带为 \_\_\_\_\_\_\_\_\_\_。

5. 因果连续时间 LTI 系统 $H(j\omega)$ 对 $u(t)$ 的稳态响应为 \_\_\_\_\_\_\_\_\_\_。

6. 信号在时域拥有的总能量，等于其频谱在频域内能量的 \_\_\_\_\_\_\_\_\_\_。

7. 当用傅里叶级数的有限项和来近似信号时，在信号的断点处存在 \_\_\_\_\_\_\_\_\_\_。

8. 连续时间 LTI 系统对周期信号的响应是 \_\_\_\_\_\_\_\_\_\_。

**解答:**

1. **$E H(0) + a_1 H(j\omega_0) e^{j\omega_0 t} + a_{-1} H(-j\omega_0) e^{-j\omega_0 t}$。**
   LTI 系统以复指数为特征函数：$e^{j\omega t} \to H(j\omega) e^{j\omega t}$。常数 $E$ 对应 $\omega=0$。由叠加性即得。

2. **$\frac{1}{2}\delta(t) + \frac{1}{j2\pi t}$。**
   由 $\mathcal{F}\{u(t)\} = \pi\delta(\omega) + \frac{1}{j\omega}$，取对偶性：若 $x(t)\leftrightarrow X(j\omega)$ 则 $X(t)\leftrightarrow 2\pi x(-\omega)$。得 $u(-\omega) \leftrightarrow \frac{1}{2}\delta(t)+\frac{1}{j2\pi t}$，替换 $\omega\to-\omega$ 得 $u(\omega)$ 的逆变换。也可直接计算 $\frac{1}{2\pi}\int_0^{\infty} e^{j\omega t}d\omega$。

3. **$0$。**
   锯齿波含跳变断点（一阶不连续），傅里叶级数系数 $a_k \propto 1/k$，当 $k\to\infty$ 时 $a_k\to 0$。跳变幅度越大，系数衰减越慢（$O(1/k)$）。

4. **$2B$。**
   时域压缩 $x(at) \leftrightarrow \frac{1}{|a|} X(j\omega/a)$。$x(2t)$ 的频谱压缩为原来的 $1/2$（展宽 2 倍），非零区间 $|\omega/2| < B \Rightarrow |\omega| < 2B$。

5. **$H(0) u(t)$（或常数 $H(0)$）。**
   阶跃信号 $u(t)$ 的直流分量对应 $\omega=0$，稳态输出为 $H(j0) = H(0)$ 乘以直流增益。也可以直接用终值定理：$\lim_{t\to\infty} y(t) = \lim_{s\to 0} s\cdot H(s)\cdot (1/s) = H(0)$。

6. **$1/(2\pi)$（倍）。**
   帕塞瓦尔定理：$\int_{-\infty}^{\infty}|x(t)|^2 dt = \frac{1}{2\pi}\int_{-\infty}^{\infty}|X(j\omega)|^2 d\omega$。时域能量 = 频域能量 × $1/(2\pi)$。

7. **吉布斯现象（Gibbs phenomenon）。**
   以有限项傅里叶级数逼近有跳变断点的信号时，在断点附近出现过冲和振荡，且过冲幅度不随项数增加而消失（约 9% 的跳变幅度）。

8. **周期信号（与输入同周期）。**
   LTI 系统对周期信号的稳态响应仍是周期信号，基波周期与输入相同。系统仅改变各谐波分量的幅度和相位，不改变频率成分。

**某 LTI 系统的单位冲激响应 $h(t)$ 如图所示（系统框图为 $\delta_T(t) \to h(t) \to y(t)$），$h(t)$ 的波形为对称矩形脉冲：**

$$h(t) = \text{rect}\!\left(\frac{t}{T}\right) = \begin{cases} 1, & -\frac{T}{2} \leqslant t \leqslant \frac{T}{2} \\ 0, & \text{其他} \end{cases}$$

求该系统的频率响应。

**解答:**

频率响应 $H(j\omega)$ 是 $h(t)$ 的傅里叶变换：
$$H(j\omega)=\int_{-T/2}^{T/2} 1\cdot e^{-j\omega t}dt = \frac{e^{-j\omega t}}{-j\omega}\Big|_{-T/2}^{T/2} = \frac{e^{j\omega T/2}-e^{-j\omega T/2}}{j\omega} = \frac{2\sin(\omega T/2)}{\omega} = T\,\text{sinc}\!\left(\frac{\omega T}{2}\right).$$

**利用傅里叶变换定义，求下列信号的傅里叶变换或反变换。**

1. $x(t) = e^{-2(t-2)} u(t-2)$，求 $X(j\omega)$；

2. $X(j\omega) = \pi[\delta(\omega + 3\pi) + \delta(\omega - 3\pi)]$，求 $x(t)$。

**解答:**

1. 令 $\tau=t-2$，则 $x(t)=e^{-2\tau}u(\tau)\big|_{\tau=t-2}$。已知 $\mathcal{F}\{e^{-2t}u(t)\}=\dfrac{1}{2+j\omega}$，由时移性质：
   $$X(j\omega)=e^{-j2\omega}\cdot\frac{1}{2+j\omega}=\frac{e^{-j2\omega}}{2+j\omega}.$$

2. $$x(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty} \pi[\delta(\omega+3\pi)+\delta(\omega-3\pi)] e^{j\omega t}d\omega =\frac{1}{2}\left[e^{-j3\pi t}+e^{j3\pi t}\right] = \cos(3\pi t).$$

**对下列频域表示，求对应的连续时间信号。**

1. $X(j\omega) = \dfrac{2\sin[3(\omega - \pi)]}{\omega - \pi}$；

2. $X(j\omega) = \cos(4\omega)$；

3. $X(j\omega) = \cos\!\left(2\omega + \dfrac{\pi}{3}\right)$；

4. $X(j\omega) = |X(j\omega)| e^{j\theta(\omega)}$，其中 $|X(j\omega)| = |\omega|[u(\omega+1)-u(\omega-1)]$，$\theta(\omega)=-3\omega$。

**解答:**

1. 记 $\nu=\omega-\pi$，则 $X(j\omega)=2\sin(3\nu)/\nu$。已知矩形脉冲 $\text{rect}(t/(2a))$（$|t|<a$ 为 1）的 FT 为 $2\sin(a\omega)/\omega$。故 $2\sin(3\nu)/\nu$ 的逆变换为 $\text{rect}(t/6)$（$|t|<3$ 为 1）。再由频移性质 $X(j(\omega-\omega_0))\leftrightarrow e^{j\omega_0 t}x(t)$，取 $\omega_0=\pi$：
   $$x(t)=e^{j\pi t}[u(t+3)-u(t-3)].$$

2. $\cos(4\omega)=\frac{1}{2}e^{j4\omega}+\frac{1}{2}e^{-j4\omega}$。逆变换：
   $$x(t)=\frac{1}{2\pi}\int \frac{1}{2}(e^{j4\omega}+e^{-j4\omega}) e^{j\omega t}d\omega = \frac{1}{2}[\delta(t+4)+\delta(t-4)].$$

3. $\cos(2\omega+\frac{\pi}{3}) = \frac{1}{2}e^{j\pi/3}e^{j2\omega}+\frac{1}{2}e^{-j\pi/3}e^{-j2\omega}$。逆变换：
   $$x(t)=\frac{1}{2}e^{j\pi/3}\delta(t+2)+\frac{1}{2}e^{-j\pi/3}\delta(t-2).$$

4. $X(j\omega)=|\omega| e^{-j3\omega}\cdot[u(\omega+1)-u(\omega-1)]$。时移性质：$X(j\omega)=G(j\omega)e^{-j3\omega}\leftrightarrow x(t)=g(t-3)$，其中 $g(t)=\mathcal{F}^{-1}\{|\omega|[u(\omega+1)-u(\omega-1)]\}$。利用偶对称性：

   $$\begin{aligned}
   g(t)&=\frac{1}{2\pi}\int_{-1}^{1}|\omega| e^{j\omega t}d\omega
        =\frac{1}{2\pi}\left[\int_{-1}^{0}(-\omega)e^{j\omega t}d\omega+\int_{0}^{1}\omega e^{j\omega t}d\omega\right] \\
        &=\frac{1}{\pi}\int_{0}^{1}\omega\cos(\omega t)d\omega
        =\frac{1}{\pi}\!\left[\frac{\omega\sin(\omega t)}{t}+\frac{\cos(\omega t)}{t^2}\right]_0^1 \\
        &=\frac{1}{\pi}\!\left(\frac{\sin t}{t}+\frac{\cos t-1}{t^2}\right)\quad(t\neq0),\qquad g(0)=\frac{1}{2\pi}.
   \end{aligned}$$

   因此 $x(t)=g(t-3)$。

**频域法求卷积及系统响应。**

**第一部分：** 利用卷积性质，用频域法求下列对应信号的卷积。

1. $x(t) = e^{-t}u(t)$，$h(t) = e^{-3t}u(t)$；

2. $x(t) = t e^{-t}u(t)$，$h(t) = e^{-3t}u(t)$；

3. $x(t) = u(t+1) - u(t-1)$，$h(t) = u(t+1) - u(t-1)$。

**解答:**

1. $X(j\omega)=\frac{1}{1+j\omega}$，$H(j\omega)=\frac{1}{3+j\omega}$。
   $$Y(j\omega)=\frac{1}{(1+j\omega)(3+j\omega)}=\frac{1/2}{1+j\omega}-\frac{1/2}{3+j\omega}.$$
   逆变换：$y(t)=\frac{1}{2}(e^{-t}-e^{-3t})u(t)$。

2. 由频域微分 $tx(t)\leftrightarrow j\frac{dX}{d\omega}$：$X(j\omega)=j\frac{d}{d\omega}\!\left(\frac{1}{1+j\omega}\right)=\frac{1}{(1+j\omega)^2}$。
   $$Y(j\omega)=\frac{1}{(1+j\omega)^2(3+j\omega)}=\frac{-1/4}{1+j\omega}+\frac{1/2}{(1+j\omega)^2}+\frac{1/4}{3+j\omega}.$$
   逆变换：$y(t)=\bigl[-\frac{1}{4}e^{-t}+\frac{1}{2}t e^{-t}+\frac{1}{4}e^{-3t}\bigr]u(t)$。

3. $X(j\omega)=H(j\omega)=\frac{2\sin\omega}{\omega}$。
   $$Y(j\omega)=\left(\frac{2\sin\omega}{\omega}\right)^2=\frac{4\sin^2\omega}{\omega^2}.$$
   两相同矩形脉冲（宽度 2）的卷积为三角形脉冲（宽度 4，高度 2）：
   $$y(t)=(2-|t|)[u(t+2)-u(t-2)].$$

**第二部分：** 某因果 LTI 系统的频率响应为 $H(j\omega) = \dfrac{1}{j\omega + 3}$。若对于某一输入 $x(t)$，其输出为 $y(t) = e^{-3t}u(t) - e^{-4t}u(t)$，求 $x(t)$。

**解答:**

$$Y(j\omega)=\frac{1}{j\omega+3}-\frac{1}{j\omega+4},\qquad H(j\omega)=\frac{1}{j\omega+3}.$$

$$X(j\omega)=\frac{Y(j\omega)}{H(j\omega)}=\left(\frac{1}{j\omega+3}-\frac{1}{j\omega+4}\right)(j\omega+3)=1-\frac{j\omega+3}{j\omega+4}=\frac{1}{j\omega+4}.$$

逆变换：$x(t)=e^{-4t}u(t)$。

**某因果 LTI 系统的微分方程为**

$$\frac{d^2y(t)}{dt^2} + 5\frac{dy(t)}{dt} + 6y(t) = \frac{dx(t)}{dt} + x(t)$$

1. 求该系统的单位冲激响应 $h(t)$；
2. 若 $x(t) = t e^{-t}u(t)$，求系统响应；
3. 若 $x(t) = e^{-2t}u(t)$，求系统响应；
4. 若 $x(t) = \displaystyle\sum_{k=0}^{5} \left(\frac{1}{2}\right)^k \cos(100\pi k t)$，求系统响应。

**解答:**

**① 求 $h(t)$：** 对方程取傅里叶变换（令 $s=j\omega$）：
$$(s^2+5s+6)Y(s)=(s+1)X(s) \;\Rightarrow\; H(s)=\frac{s+1}{s^2+5s+6}=\frac{s+1}{(s+2)(s+3)}.$$

部分分式：
$$\frac{s+1}{(s+2)(s+3)}=\frac{-1}{s+2}+\frac{2}{s+3}.$$
（验证：$-1(s+3)+2(s+2)=-s-3+2s+4=s+1$。✓）

$$h(t)=[2e^{-3t}-e^{-2t}]u(t).$$

**② $x(t)=t e^{-t}u(t)$：** $X(s)=\frac{1}{(s+1)^2}$。
$$Y(s)=H(s)X(s)=\frac{s+1}{(s+2)(s+3)}\cdot\frac{1}{(s+1)^2}=\frac{1}{(s+2)(s+3)(s+1)}.$$

设 $\frac{1}{(s+1)(s+2)(s+3)}=\frac{A}{s+1}+\frac{B}{s+2}+\frac{C}{s+3}$。
$1=A(s+2)(s+3)+B(s+1)(s+3)+C(s+1)(s+2)$。

$s=-1$：$1=A\cdot1\cdot2\Rightarrow A=1/2$。
$s=-2$：$1=B\cdot(-1)\cdot1\Rightarrow B=-1$。
$s=-3$：$1=C\cdot(-2)\cdot(-1)\Rightarrow C=1/2$。

$$Y(s)=\frac{1/2}{s+1}-\frac{1}{s+2}+\frac{1/2}{s+3}.$$
$$y(t)=\left[\frac{1}{2}e^{-t}-e^{-2t}+\frac{1}{2}e^{-3t}\right]u(t).$$

**③ $x(t)=e^{-2t}u(t)$：** $X(s)=\frac{1}{s+2}$。
$$Y(s)=\frac{s+1}{(s+2)^2(s+3)}=\frac{A}{s+3}+\frac{B}{s+2}+\frac{C}{(s+2)^2}.$$

$s+1=A(s+2)^2+B(s+3)(s+2)+C(s+3)$。

$s=-3$：$-2=A\cdot1\Rightarrow A=-2$。
$s=-2$：$-1=C\cdot1\Rightarrow C=-1$。
$s=0$：$1=4A+6B+3C=-8+6B-3\Rightarrow 6B=12\Rightarrow B=2$。

$$Y(s)=\frac{-2}{s+3}+\frac{2}{s+2}-\frac{1}{(s+2)^2}.$$
$$y(t)=[-2e^{-3t}+2e^{-2t}-t e^{-2t}]u(t).$$

**④ 周期信号输入：** $x(t)=\sum_{k=0}^{5}(\frac{1}{2})^k\cos(100\pi k t)$。由 LTI 系统对正弦信号的稳态响应性质：
$$y(t)=\sum_{k=0}^{5}\left(\frac{1}{2}\right)^k|H(j\cdot 100\pi k)|\cos\!\bigl(100\pi k t+\angle H(j\cdot 100\pi k)\bigr).$$

其中 $H(j\omega)=\frac{j\omega+1}{(j\omega+2)(j\omega+3)}$：
$$|H(j\omega)|=\frac{\sqrt{1+\omega^2}}{\sqrt{(4+\omega^2)(9+\omega^2)}},\quad \angle H(j\omega)=\arctan\omega-\arctan\frac{\omega}{2}-\arctan\frac{\omega}{3}.$$

$k=0$（$\omega=0$）：$H(j0)=1/6$，该项输出为 $1/6$。

**某因果 LTI 系统的差分方程为**

$$y[n] + \frac{1}{6}y[n-1] - \frac{1}{6}y[n-2] = x[n] - x[n-1]$$

1. 求该系统的频率响应 $H(e^{j\omega})$；
2. 求该系统的单位样值响应 $h[n]$；
3. 求该系统对输入信号 $x[n] = \left(\dfrac{1}{4}\right)^n u[n]$ 的响应。

**解答:**

**① 频率响应：** 对方程取 DTFT：
$$Y(e^{j\omega})\!\left(1+\frac{1}{6}e^{-j\omega}-\frac{1}{6}e^{-j2\omega}\right)=X(e^{j\omega})(1-e^{-j\omega}).$$
$$H(e^{j\omega})=\frac{1-e^{-j\omega}}{1+\frac{1}{6}e^{-j\omega}-\frac{1}{6}e^{-j2\omega}}.$$

**② 单位样值响应：** 用 z 变换。$H(z)=\dfrac{1-z^{-1}}{1+\frac{1}{6}z^{-1}-\frac{1}{6}z^{-2}}$。分母因式分解：
$$1+\frac{1}{6}z^{-1}-\frac{1}{6}z^{-2}=0\;\Rightarrow\;6z^2+z-1=0\;\Rightarrow\;z=\frac{1}{3},\,-\frac{1}{2}.$$
$$H(z)=\frac{1-z^{-1}}{(1-\frac{1}{3}z^{-1})(1+\frac{1}{2}z^{-1})}.$$

部分分式：设 $H(z)=\frac{A}{1-\frac{1}{3}z^{-1}}+\frac{B}{1+\frac{1}{2}z^{-1}}$。
$1-z^{-1}=A(1+\frac{1}{2}z^{-1})+B(1-\frac{1}{3}z^{-1})$。

$z^{-1}=3$：$-2=A\cdot\frac{5}{2}\Rightarrow A=-\frac{4}{5}$。
$z^{-1}=-2$：$3=B\cdot\frac{5}{3}\Rightarrow B=\frac{9}{5}$。

$$H(z)=-\frac{4/5}{1-\frac{1}{3}z^{-1}}+\frac{9/5}{1+\frac{1}{2}z^{-1}}.$$
$$h[n]=\left[-\frac{4}{5}\!\left(\frac{1}{3}\right)^n+\frac{9}{5}\!\left(-\frac{1}{2}\right)^n\right]u[n].$$

**③ 对 $x[n]=(\frac{1}{4})^n u[n]$ 的响应：** $X(z)=\frac{1}{1-\frac{1}{4}z^{-1}}$。
$$Y(z)=H(z)X(z)=\frac{1-z^{-1}}{(1-\frac{1}{3}z^{-1})(1+\frac{1}{2}z^{-1})(1-\frac{1}{4}z^{-1})}.$$

部分分式：设 $Y(z)=\frac{A}{1-\frac{1}{3}z^{-1}}+\frac{B}{1+\frac{1}{2}z^{-1}}+\frac{C}{1-\frac{1}{4}z^{-1}}$。

通分后分子：$(1-z^{-1})=A(1+\frac{1}{2}z^{-1})(1-\frac{1}{4}z^{-1})+B(1-\frac{1}{3}z^{-1})(1-\frac{1}{4}z^{-1})+C(1-\frac{1}{3}z^{-1})(1+\frac{1}{2}z^{-1})$。

$z^{-1}=3$：$1-3=-2=A(1+\frac{3}{2})(1-\frac{3}{4})=A\cdot\frac{5}{2}\cdot\frac{1}{4}=\frac{5}{8}A\Rightarrow A=-\frac{16}{5}$。
$z^{-1}=-2$：$1+2=3=B(1+\frac{2}{3})(1+\frac{2}{4})=B\cdot\frac{5}{3}\cdot\frac{3}{2}=\frac{5}{2}B\Rightarrow B=\frac{6}{5}$。
$z^{-1}=4$：$1-4=-3=C(1-\frac{4}{3})(1+\frac{4}{2})=C\cdot(-\frac{1}{3})\cdot3=-C\Rightarrow C=3$。

$$Y(z)=-\frac{16/5}{1-\frac{1}{3}z^{-1}}+\frac{6/5}{1+\frac{1}{2}z^{-1}}+\frac{3}{1-\frac{1}{4}z^{-1}}.$$
$$y[n]=\left[-\frac{16}{5}\!\left(\frac{1}{3}\right)^n+\frac{6}{5}\!\left(-\frac{1}{2}\right)^n+3\!\left(\frac{1}{4}\right)^n\right]u[n].$$

**某离散时间 LTI 系统的单位样值响应为 $h[n]$，频率响应为 $H(e^{j\omega})$，且具有以下性质：**

$$\left(\frac{1}{4}\right)^n u[n] \to g[n]$$

其中 $g[n] = 0$（当 $n \geqslant 2$ 和 $n < 0$）；

$$H(e^{j\pi/2}) = 1, \qquad H(e^{j\omega}) = H(e^{j(\omega - \pi)})$$

1. 求 $h[n]$；
2. 求该系统的差分方程；
3. 求系统对 $u[n]$ 的响应。

**解答:**

**① 求 $h[n]$。** $g[n]$ 仅在 $n=0,1$ 处非零，设 $g[n]=a\delta[n]+b\delta[n-1]$。

$G(e^{j\omega})=a+be^{-j\omega}$，$X(e^{j\omega})=\frac{1}{1-\frac{1}{4}e^{-j\omega}}$。
$$H(e^{j\omega})=\frac{G(e^{j\omega})}{X(e^{j\omega})}=(a+be^{-j\omega})\!\left(1-\frac{1}{4}e^{-j\omega}\right)=a+\!\left(b-\frac{a}{4}\right)\!e^{-j\omega}-\frac{b}{4}e^{-j2\omega}.$$

由 $H(e^{j\omega})=H(e^{j(\omega-\pi)})$：当 $e^{-j(\omega-\pi)}=-e^{-j\omega}$，$e^{-j2(\omega-\pi)}=e^{-j2\omega}$。条件要求 $H$ 中 $e^{-j\omega}$ 项系数为零（否则 $H(e^{j(\omega-\pi)})$ 中该项变号不相等），故 $b-\frac{a}{4}=0$，即 $b=\frac{a}{4}$。

由 $H(e^{j\pi/2})=1$（$e^{-j\pi/2}=-j$，$e^{-j\pi}=-1$）：
$$H(e^{j\pi/2})=a-\frac{b}{4}(-1)=a+\frac{b}{4}=1.$$
代入 $b=a/4$：$a+\frac{a}{16}=\frac{17a}{16}=1\Rightarrow a=\frac{16}{17},\,b=\frac{4}{17}$。

$$H(e^{j\omega})=\frac{16}{17}-\frac{1}{17}e^{-j2\omega},\qquad h[n]=\frac{16}{17}\delta[n]-\frac{1}{17}\delta[n-2].$$

**② 求差分方程。** $H(z)=\frac{16}{17}-\frac{1}{17}z^{-2}$。$17Y(z)=16X(z)-z^{-2}X(z)$。逆变换：
$$17y[n]=16x[n]-x[n-2].$$

**③ 对 $u[n]$ 的响应：**
$$y[n]=h[n]*u[n]=\frac{16}{17}u[n]-\frac{1}{17}u[n-2].$$
展开：
$$y[n]=\begin{cases}\frac{16}{17},&n=0,1\\[4pt]\frac{15}{17},&n\geqslant2\\[4pt]0,&n<0.\end{cases}$$

**某离散因果 LTI 系统的方框图由两个子系统级联而成：**

- **左侧子系统：** 设第一个加法器的输出节点信号为 $v_1[n]$，级联中间信号为 $w[n]$，满足：

  $$\begin{cases} v_1[n] = x[n] + \dfrac{5}{6}v_1[n-1] - \dfrac{1}{6}v_1[n-2] \\[8pt] w[n] = v_1[n] - \dfrac{1}{4}v_1[n-1] \end{cases}$$

- **右侧子系统：** 设第一个加法器的输出节点信号为 $v_2[n]$，系统最终输出为 $y[n]$，满足：

  $$\begin{cases} v_2[n] = w[n] + \dfrac{1}{4}v_2[n-1] \\[8pt] y[n] = v_2[n] - v_2[n-1] \end{cases}$$

1. 求该系统的频率响应 $H(e^{j\omega})$；
2. 求该系统的差分方程；
3. 求该系统的单位样值响应 $h[n]$。

**解答:**

**① 求频率响应。** 分别对两子系统做 z 变换。

左侧：$V_1(z)=X(z)+\frac{5}{6}z^{-1}V_1(z)-\frac{1}{6}z^{-2}V_1(z)\;\Rightarrow\;V_1(z)=\dfrac{X(z)}{1-\frac{5}{6}z^{-1}+\frac{1}{6}z^{-2}}$。
$W(z)=V_1(z)(1-\frac{1}{4}z^{-1})$。
$$H_1(z)=\frac{W(z)}{X(z)}=\frac{1-\frac{1}{4}z^{-1}}{1-\frac{5}{6}z^{-1}+\frac{1}{6}z^{-2}}.$$

右侧：$V_2(z)=W(z)+\frac{1}{4}z^{-1}V_2(z)\;\Rightarrow\;V_2(z)=\dfrac{W(z)}{1-\frac{1}{4}z^{-1}}$。
$Y(z)=V_2(z)(1-z^{-1})$。
$$H_2(z)=\frac{Y(z)}{W(z)}=\frac{1-z^{-1}}{1-\frac{1}{4}z^{-1}}.$$

级联总传递函数（公因子 $1-\frac{1}{4}z^{-1}$ 零极点对消）：
$$H(z)=H_1(z)H_2(z)=\frac{1-z^{-1}}{1-\frac{5}{6}z^{-1}+\frac{1}{6}z^{-2}}.$$

频率响应：
$$H(e^{j\omega})=\frac{1-e^{-j\omega}}{1-\frac{5}{6}e^{-j\omega}+\frac{1}{6}e^{-j2\omega}}.$$

**② 求差分方程。** 由 $H(z)=\frac{1-z^{-1}}{1-\frac{5}{6}z^{-1}+\frac{1}{6}z^{-2}}$：
$$Y(z)\!\left(1-\frac{5}{6}z^{-1}+\frac{1}{6}z^{-2}\right)=X(z)(1-z^{-1}).$$
$$y[n]-\frac{5}{6}y[n-1]+\frac{1}{6}y[n-2]=x[n]-x[n-1].$$

**③ 求单位样值响应。** 分母因式分解（同差分方程题）：
$$1-\frac{5}{6}z^{-1}+\frac{1}{6}z^{-2}=\left(1-\frac{1}{2}z^{-1}\right)\!\left(1-\frac{1}{3}z^{-1}\right).$$
$$H(z)=\frac{1-z^{-1}}{(1-\frac{1}{2}z^{-1})(1-\frac{1}{3}z^{-1})}.$$

部分分式：设 $\frac{1-z^{-1}}{(1-\frac{1}{2}z^{-1})(1-\frac{1}{3}z^{-1})}=\frac{A}{1-\frac{1}{2}z^{-1}}+\frac{B}{1-\frac{1}{3}z^{-1}}$。

$1-z^{-1}=A(1-\frac{1}{3}z^{-1})+B(1-\frac{1}{2}z^{-1})$。

$z^{-1}=2$：$1-2=-1=A(1-\frac{2}{3})=\frac{1}{3}A\Rightarrow A=-3$。
$z^{-1}=3$：$1-3=-2=B(1-\frac{3}{2})=-\frac{1}{2}B\Rightarrow B=4$。

$$H(z)=-\frac{3}{1-\frac{1}{2}z^{-1}}+\frac{4}{1-\frac{1}{3}z^{-1}}.$$
$$h[n]=\left[-3\!\left(\frac{1}{2}\right)^n+4\!\left(\frac{1}{3}\right)^n\right]u[n].$$

（验证：$h[0]=-3+4=1$，$H(z)|_{z\to\infty}=1$，一致。✓）

## 九、常用公式速查

**分部积分：** $\int \omega\cos(\omega t)d\omega=\frac{\omega\sin(\omega t)}{t}+\frac{\cos(\omega t)}{t^2}$

**部分分式系数的确定：**
- 单根：$A=(s+a)Y(s)\big|_{s=-a}$
- 重根：最高次 $C=(s+a)^2Y(s)\big|_{s=-a}$，其余代入数值求解
