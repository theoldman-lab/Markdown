## 一、时域分析与系统响应

**已知某因果 LTI 系统的微分方程为：**

$$y''(t) + 3y'(t) + 2y(t) = x(t)$$

初始条件：

$$y(0^-) = 3, \quad y'(0^-) = -5$$

**求解目标：**

当 $x(t) = 2u(t)$ 时，求系统的零输入响应 $y_{zi}(t)$、零状态响应 $y_{zs}(t)$、全响应 $y_{\text{全}}(t)$ 以及单位冲激响应 $h(t)$。

**解：**

**(1) 特征方程与特征根**

由微分方程得特征方程：

$$s^2 + 3s + 2 = 0 \quad \Rightarrow \quad (s+1)(s+2) = 0$$

特征根：$s_1 = -1,\ s_2 = -2$。

**(2) 零输入响应 $y_{zi}(t)$**

设 $y_{zi}(t) = C_1 e^{-t} + C_2 e^{-2t},\ t \ge 0$。

由初始条件（因果系统，$0^+$ 时刻无跳变）：

$$\begin{cases}
y_{zi}(0^+) = y(0^-) = 3 = C_1 + C_2 \\
y'_{zi}(0^+) = y'(0^-) = -5 = -C_1 - 2C_2
\end{cases}$$

解得 $C_1 = 1,\ C_2 = 2$。

$$\boxed{y_{zi}(t) = (e^{-t} + 2e^{-2t})\,u(t)}$$

**(3) 系统函数 $H(s)$ 与冲激响应 $h(t)$**

对微分方程两边取拉氏变换（零初始状态）：

$$s^2 Y(s) + 3sY(s) + 2Y(s) = X(s)$$

$$H(s) = \frac{Y(s)}{X(s)} = \frac{1}{s^2 + 3s + 2} = \frac{1}{(s+1)(s+2)}$$

部分分式展开：

$$\frac{1}{(s+1)(s+2)} = \frac{1}{s+1} - \frac{1}{s+2}$$

$$\boxed{h(t) = (e^{-t} - e^{-2t})\,u(t)}$$

**(4) 零状态响应 $y_{zs}(t)$**

$x(t) = 2u(t)$，故 $X(s) = \dfrac{2}{s}$。

$$Y_{zs}(s) = H(s)X(s) = \frac{1}{(s+1)(s+2)} \cdot \frac{2}{s} = \frac{2}{s(s+1)(s+2)}$$

部分分式展开：

$$\frac{2}{s(s+1)(s+2)} = \frac{A}{s} + \frac{B}{s+1} + \frac{C}{s+2}$$

由留数法：

- $s = 0$：$A = \left.\dfrac{2}{(s+1)(s+2)}\right|_{s=0} = 1$
- $s = -1$：$B = \left.\dfrac{2}{s(s+2)}\right|_{s=-1} = \dfrac{2}{(-1)(1)} = -2$
- $s = -2$：$C = \left.\dfrac{2}{s(s+1)}\right|_{s=-2} = \dfrac{2}{(-2)(-1)} = 1$

$$Y_{zs}(s) = \frac{1}{s} - \frac{2}{s+1} + \frac{1}{s+2}$$

$$\boxed{y_{zs}(t) = (1 - 2e^{-t} + e^{-2t})\,u(t)}$$

**(5) 全响应 $y_{\text{全}}(t)$**

$$y_{\text{全}}(t) = y_{zi}(t) + y_{zs}(t) = (e^{-t} + 2e^{-2t})u(t) + (1 - 2e^{-t} + e^{-2t})u(t)$$

$$\boxed{y_{\text{全}}(t) = (1 - e^{-t} + 3e^{-2t})\,u(t)}$$

验证：$y_{\text{全}}(0^+) = 1 - 1 + 3 = 3$，$y'_{\text{全}}(0^+) = e^{-t} - 6e^{-2t}\big|_{t=0} = 1 - 6 = -5$，与初始条件一致。

## 二、拉氏反变换

**根据以下拉氏变换及收敛域，确定时间函数：**

**①** 

$$F(s) = \frac{1}{s^2 + 9}, \quad \text{ROC}: \text{Re}\{s\} > 0$$

**②** 

$$F(s) = \frac{s+1}{s^2 + 5s + 6}, \quad \text{ROC}: -3 < \text{Re}\{s\} < -2$$

**③** 

$$F(s) = \frac{s^2 - s + 1}{s^2 + 2s + 1}, \quad \text{ROC}: \text{Re}\{s\} > -1$$

**④** 

$$F(s) = \frac{s+2}{s^2 + 7s + 12}, \quad \text{ROC}: -4 < \text{Re}\{s\} < -3$$

**⑤** 

$$F(s) = \frac{2}{1 - e^{-2s}}, \quad \text{ROC}: \text{Re}\{s\} > 0$$

**解：**

---

**①** $F(s) = \dfrac{1}{s^2 + 9} = \dfrac{1}{3} \cdot \dfrac{3}{s^2 + 3^2}$，ROC: $\text{Re}\{s\} > 0$（右边信号）。

$$\boxed{f(t) = \frac{1}{3}\sin(3t)\,u(t)}$$

---

**②** $F(s) = \dfrac{s+1}{s^2 + 5s + 6} = \dfrac{s+1}{(s+2)(s+3)}$

部分分式展开：

$$\frac{s+1}{(s+2)(s+3)} = \frac{-1}{s+2} + \frac{2}{s+3}$$

ROC: $-3 < \text{Re}\{s\} < -2$：
- 极点 $s = -2$ 位于 ROC 左侧 → $\dfrac{-1}{s+2}$ 对应**左边信号**：$\dfrac{1}{s+2} \leftrightarrow -e^{-2t}u(-t)$，故 $\dfrac{-1}{s+2} \leftrightarrow e^{-2t}u(-t)$
- 极点 $s = -3$ 位于 ROC 右侧 → $\dfrac{2}{s+3}$ 对应**右边信号**：$\dfrac{2}{s+3} \leftrightarrow 2e^{-3t}u(t)$

$$\boxed{f(t) = e^{-2t}u(-t) + 2e^{-3t}u(t)}$$

---

**③** $F(s) = \dfrac{s^2 - s + 1}{s^2 + 2s + 1}$

分母为 $(s+1)^2$（$s=-1$ 处有二重极点）。先做多项式除法：

$$F(s) = 1 - \frac{3s}{(s+1)^2}$$

再展开：

$$\frac{s}{(s+1)^2} = \frac{(s+1) - 1}{(s+1)^2} = \frac{1}{s+1} - \frac{1}{(s+1)^2}$$

$$\therefore\ F(s) = 1 - 3\left(\frac{1}{s+1} - \frac{1}{(s+1)^2}\right) = 1 - \frac{3}{s+1} + \frac{3}{(s+1)^2}$$

ROC: $\text{Re}\{s\} > -1$（右边信号）：

$$\boxed{f(t) = \delta(t) - 3e^{-t}u(t) + 3te^{-t}u(t)}$$

---

**④** $F(s) = \dfrac{s+2}{s^2 + 7s + 12} = \dfrac{s+2}{(s+3)(s+4)}$

部分分式展开：

$$\frac{s+2}{(s+3)(s+4)} = \frac{-1}{s+3} + \frac{2}{s+4}$$

ROC: $-4 < \text{Re}\{s\} < -3$：
- 极点 $s = -3$ 位于 ROC 左侧 → $\dfrac{-1}{s+3}$ 对应左边信号：$e^{-3t}u(-t)$
- 极点 $s = -4$ 位于 ROC 右侧 → $\dfrac{2}{s+4}$ 对应右边信号：$2e^{-4t}u(t)$

$$\boxed{f(t) = e^{-3t}u(-t) + 2e^{-4t}u(t)}$$

---

**⑤** $F(s) = \dfrac{2}{1 - e^{-2s}}$，ROC: $\text{Re}\{s\} > 0$

由 ROC 知 $\text{Re}\{s\} > 0$，故 $|e^{-2s}| = e^{-2\sigma} < 1$，利用几何级数展开：

$$\frac{2}{1 - e^{-2s}} = 2\sum_{n=0}^{\infty} e^{-2ns}$$

由拉氏变换的时移性质 $\mathcal{L}\{\delta(t - 2n)\} = e^{-2ns}$：

$$\boxed{f(t) = 2\sum_{n=0}^{\infty} \delta(t - 2n)}$$

即周期为 $2$、强度为 $2$ 的周期冲激串。

## 三、信号的拉氏变换

**求下图所示的各种信号的拉氏变换（图像信号表达式）：**

**(a)** 三角形脉冲信号 $x_1(t)$：

$$x_1(t) = (1-t)[u(t) - u(t-1)]$$

即在 $0 \le t \le 1$ 区间内为直线 $1-t$，其余为 $0$。

**(b)** 正弦半波信号 $x_2(t)$：

$$x_2(t) = \sin(\pi t)[u(t) - u(t-1)]$$

即在 $0 \le t \le 1$ 区间内为 $\sin(\pi t)$，其余为 $0$。

**(c)** 周期矩形脉冲信号 $x_3(t)$：

由一系列宽度为 $T/2$、高度为 $1$ 的矩形脉冲组成，周期为 $T$。第一个脉冲区间：$0 \le t < T/2$。

$$x_3(t) = \sum_{n=0}^{\infty} [u(t-nT) - u(t-nT-T/2)]$$

**(d)** 分段指数衰减信号 $x_4(t)$：

- $0 \le t < 1$：$x_4(t) = e^{-t}$
- $1 \le t < 2$：$x_4(t) = -e^{-(t-1)}$
- $2 \le t < 3$：$x_4(t) = e^{-(t-2)}$
- $3 \le t < 4$：$x_4(t) = -e^{-(t-3)}$
- 以此类推。

**解：**

---

**(a)** $x_1(t) = (1-t)[u(t) - u(t-1)]$

将信号改写为斜坡信号的叠加：

$$x_1(t) = u(t) - t\,u(t) + (t-1)u(t-1)$$

取拉氏变换：

$$\mathcal{L}\{u(t)\} = \frac{1}{s},\quad \mathcal{L}\{t\,u(t)\} = \frac{1}{s^2},\quad \mathcal{L}\{(t-1)u(t-1)\} = \frac{e^{-s}}{s^2}$$

$$\boxed{X_1(s) = \frac{1}{s} - \frac{1}{s^2} + \frac{e^{-s}}{s^2} = \frac{s - 1 + e^{-s}}{s^2}}$$

---

**(b)** $x_2(t) = \sin(\pi t)[u(t) - u(t-1)]$

利用 $\sin(\pi t) = \sin(\pi(t-1) + \pi) = -\sin(\pi(t-1))$：

$$x_2(t) = \sin(\pi t)u(t) + \sin(\pi(t-1))u(t-1)$$

$$\mathcal{L}\{\sin(\pi t)u(t)\} = \frac{\pi}{s^2 + \pi^2}$$

$$\boxed{X_2(s) = \frac{\pi}{s^2 + \pi^2}(1 + e^{-s})}$$

---

**(c)** $x_3(t) = \sum_{n=0}^{\infty} [u(t-nT) - u(t-nT-T/2)]$

这是一个周期信号，先求单周期 $x_p(t) = u(t) - u(t-T/2)$ 的拉氏变换：

$$X_p(s) = \frac{1 - e^{-sT/2}}{s}$$

周期信号的拉氏变换公式：$X(s) = \dfrac{X_p(s)}{1 - e^{-sT}}$

$$X_3(s) = \frac{1 - e^{-sT/2}}{s(1 - e^{-sT})} = \frac{1 - e^{-sT/2}}{s(1 - e^{-sT/2})(1 + e^{-sT/2})}$$

$$\boxed{X_3(s) = \frac{1}{s(1 + e^{-sT/2})}}$$

---

**(d)** $x_4(t)$ 分段指数衰减信号

由分段定义，将$n$段积分求和：

$$X_4(s) = \sum_{n=0}^{\infty} \int_{n}^{n+1} (-1)^n e^{-(t-n)} e^{-st}\,dt$$

计算单段积分：

$$\int_{n}^{n+1} e^{-(t-n)} e^{-st} dt = e^n \int_{n}^{n+1} e^{-(s+1)t} dt = \frac{e^{-sn}}{s+1}\left[1 - e^{-(s+1)}\right]$$

$$\therefore\ X_4(s) = \frac{1 - e^{-(s+1)}}{s+1} \sum_{n=0}^{\infty} (-e^{-s})^n$$

ROC 满足 $|e^{-s}| < 1$ 时几何级数收敛：

$$\sum_{n=0}^{\infty} (-e^{-s})^n = \frac{1}{1 + e^{-s}}$$

$$\boxed{X_4(s) = \frac{1 - e^{-(s+1)}}{(s+1)(1 + e^{-s})}}$$

## 四、由阶跃响应求输入信号

已知某系统的单位阶跃响应：

$$s(t) = (1 - e^{-2t})u(t)$$

求当输出响应为以下值时的输入信号 $x(t)$：

$$y(t) = (-e^{-2t} + e^{-t})u(t)$$

**解：**

先求系统函数 $H(s)$。阶跃响应 $s(t) = (1 - e^{-2t})u(t)$ 的拉氏变换：

$$S(s) = \frac{1}{s} - \frac{1}{s+2} = \frac{2}{s(s+2)}$$

阶跃响应对应输入 $u(t) \leftrightarrow 1/s$，故：

$$H(s) = \frac{S(s)}{1/s} = \frac{2}{s+2}$$

输出 $y(t) = (-e^{-2t} + e^{-t})u(t)$ 的拉氏变换：

$$Y(s) = -\frac{1}{s+2} + \frac{1}{s+1} = \frac{-(s+1)+(s+2)}{(s+1)(s+2)} = \frac{1}{(s+1)(s+2)}$$

$$\therefore\ X(s) = \frac{Y(s)}{H(s)} = \frac{\frac{1}{(s+1)(s+2)}}{\frac{2}{s+2}} = \frac{1}{2(s+1)}$$

$$\boxed{x(t) = \frac{1}{2}e^{-t}u(t)}$$

## 五、由输入/输出求系统函数

**题目 1：**

已知某稳定的 LTI 系统，当 $t > 0$ 时 $x(t) = 0$，且输入的拉氏变换为：

$$X(s) = \frac{s+2}{s-2}$$

系统的输出为：

$$y(t) = \left[ -\frac{2}{3}e^{2t}u(-t) + \frac{1}{3}e^{-t}u(t) \right]$$

**求解目标：**

① 系统函数 $H(s)$ 及其收敛域 (ROC)；

② 单位冲激响应 $h(t)$。

**题目 2：**

一 CT LTI 系统有以下微分方程描述：

$$y''(t) - y'(t) - 2y(t) = x(t)$$

**求解目标：**

① 求系统的 $H(s)$，画出零、极点图；

② 求系统的 $h(t)$，并说明其因果、稳定等性质。

**解：**

**题目 1：**

先求 $Y(s)$。由 $y(t) = -\frac{2}{3}e^{2t}u(-t) + \frac{1}{3}e^{-t}u(t)$：

$$\mathcal{L}\{e^{2t}u(-t)\} = -\frac{1}{s-2},\ \text{ROC}: \text{Re}\{s\} < 2$$

$$\mathcal{L}\{e^{-t}u(t)\} = \frac{1}{s+1},\ \text{ROC}: \text{Re}\{s\} > -1$$

$$Y(s) = -\frac{2}{3}\left(-\frac{1}{s-2}\right) + \frac{1}{3}\cdot\frac{1}{s+1} = \frac{2}{3(s-2)} + \frac{1}{3(s+1)}$$

通分：$Y(s) = \dfrac{2(s+1)+(s-2)}{3(s-2)(s+1)} = \dfrac{3s}{3(s-2)(s+1)} = \dfrac{s}{(s-2)(s+1)}$

ROC: $\text{Re}\{s\} \in (-1, 2)$（两个分量 ROC 的交集）。

已知 $X(s) = \dfrac{s+2}{s-2}$。由 $x(t)=0\ (t>0)$ 知其为左边信号，ROC: $\text{Re}\{s\} < 2$。

① 系统函数：

$$H(s) = \frac{Y(s)}{X(s)} = \frac{s}{(s-2)(s+1)} \cdot \frac{s-2}{s+2} = \frac{s}{(s+1)(s+2)}$$

系统稳定 → $H(s)$ 的 ROC 须包含 $j\omega$ 轴。极点 $s=-1,-2$ 均在左半平面，故 ROC 取 $\text{Re}\{s\} > -1$。

$$\boxed{H(s) = \frac{s}{(s+1)(s+2)},\quad \text{ROC}: \text{Re}\{s\} > -1}$$

② 部分分式展开：

$$\frac{s}{(s+1)(s+2)} = \frac{-1}{s+1} + \frac{2}{s+2}$$

$$\boxed{h(t) = (-e^{-t} + 2e^{-2t})\,u(t)}$$

---

**题目 2：**

$$H(s) = \frac{1}{s^2 - s - 2} = \frac{1}{(s-2)(s+1)}$$

① 零点：无（有限零点）；极点：$s = 2,\ s = -1$。

零极点图（s 平面）：实轴上 $s=-1$ 和 $s=2$ 处各有一个极点（×）。

② 部分分式展开：

$$H(s) = \frac{1}{(s-2)(s+1)} = \frac{1/3}{s-2} - \frac{1/3}{s+1}$$

系统 $H(s)$ 有三种可能的 ROC，对应三种不同性质的 $h(t)$：

| ROC | $h(t)$ | 因果性 | 稳定性 |
|-----|--------|--------|--------|
| $\text{Re}\{s\} > 2$ | $\frac{1}{3}(e^{2t} - e^{-t})u(t)$ | 因果 | 不稳定（ROC 不含 $j\omega$ 轴） |
| $-1 < \text{Re}\{s\} < 2$ | $-\frac{1}{3}e^{2t}u(-t) - \frac{1}{3}e^{-t}u(t)$ | 非因果 | 稳定（ROC 含 $j\omega$ 轴） |
| $\text{Re}\{s\} < -1$ | $\frac{1}{3}(-e^{2t} + e^{-t})u(-t)$ | 反因果 | 不稳定（ROC 不含 $j\omega$ 轴） |

## 六、双边信号与拉氏变换

**题目 1：**

设：

$$y(t) = x(t) + Ax(-t)$$

其中输入信号：

$$x(t) = Be^{-t}u(t)$$

已知 $y(t)$ 的拉氏变换为：

$$Y(s) = \frac{s}{s^2 - 1}, \quad \text{ROC}: -1 < \text{Re}\{s\} < 1$$

**求解目标：**

试确定常数 $A, B$ 的值。

**题目 2：**

某因果 LTI 系统具备以下性质：

① 当激励 $x(t) = e^{2t}$（对全部 $t$）时，输出 $y(t) = \frac{1}{6}e^{2t}$；

② $h(t)$ 满足下列微分方程：

$$\frac{dh}{dt} + 2h(t) = e^{-4t}u(t) + bu(t)$$

这里 $b$ 是一个未知常数。

**求解目标：**

试求 $b$、$H(s)$、$h(t)$。

**解：**

**题目 1：**

由 $y(t) = x(t) + A x(-t)$ 两边取拉氏变换：

$$x(t) = B e^{-t}u(t) \quad \leftrightarrow \quad X(s) = \frac{B}{s+1},\ \text{ROC}: \text{Re}\{s\} > -1$$

$$x(-t) = B e^{t}u(-t) \quad \leftrightarrow \quad \mathcal{L}\{x(-t)\} = -\frac{B}{s-1},\ \text{ROC}: \text{Re}\{s\} < 1$$

$$Y(s) = X(s) + A\cdot\mathcal{L}\{x(-t)\} = \frac{B}{s+1} - \frac{AB}{s-1}$$

通分：

$$Y(s) = \frac{B(s-1) - AB(s+1)}{(s+1)(s-1)} = \frac{B[(1-A)s - (1+A)]}{s^2 - 1}$$

已知 $Y(s) = \dfrac{s}{s^2 - 1}$，比较分子系数：

$$\begin{cases}
B(1-A) = 1 \\
-B(1+A) = 0
\end{cases}$$

由第二式：$1+A=0 \Rightarrow A=-1$。代入第一式：$B(1-(-1)) = 2B = 1 \Rightarrow B = \dfrac{1}{2}$。

$$\boxed{A = -1,\quad B = \frac{1}{2}}$$

---

**题目 2：**

由条件①及 LTI 系统的特征函数性质：输入 $e^{st}$ 时输出为 $H(s)e^{st}$，故：

$$H(2) = \frac{1}{6}$$

对条件②中 $h(t)$ 的微分方程取拉氏变换（因果系统，$h(0^-)=0$）：

$$sH(s) + 2H(s) = \frac{1}{s+4} + \frac{b}{s}$$

$$H(s) = \frac{1}{(s+2)(s+4)} + \frac{b}{s(s+2)}$$

代入 $s=2$：

$$\frac{1}{4 \cdot 6} + \frac{b}{2 \cdot 4} = \frac{1}{6}\ \Rightarrow\ \frac{1}{24} + \frac{b}{8} = \frac{1}{6}$$

$$\frac{b}{8} = \frac{1}{6} - \frac{1}{24} = \frac{3}{24} = \frac{1}{8}\ \Rightarrow\ b = 1$$

代回 $H(s)$ 并化简：

$$H(s) = \frac{1}{(s+2)(s+4)} + \frac{1}{s(s+2)} = \frac{s + (s+4)}{s(s+2)(s+4)} = \frac{2(s+2)}{s(s+2)(s+4)} = \frac{2}{s(s+4)}$$

因果系统，ROC: $\text{Re}\{s\} > 0$。

部分分式展开：$\dfrac{2}{s(s+4)} = \dfrac{1/2}{s} - \dfrac{1/2}{s+4}$

$$\boxed{b = 1,\quad H(s) = \frac{2}{s(s+4)},\ \text{Re}\{s\} > 0,\quad h(t) = \frac{1}{2}(1 - e^{-4t})u(t)}$$

## 七、反馈系统稳定性分析

**【例 6.17】** 图 6.11 所示为一反馈系统，已知子系统的单位冲激响应 $h_1(t) = (2e^{-2t} - e^{-t})u(t)$。

- **(a)** 时域框图：输入 $x(t)$ 经过加法器进入子系统 $h_1(t)$，输出为 $y(t)$；同时输出 $y(t)$ 经过增益 $k$ 反馈至加法器（正反馈）。
- **(b)** s域框图：输入 $X(s)$ 经过加法器进入子系统 $H_1(s)$，输出为 $Y(s)$；同时输出 $Y(s)$ 经过增益 $k$ 反馈至加法器。

**求：**

① 为使系统稳定，实系数 $k$ 应满足什么条件？

② 在临界稳定的条件下，求整个系统的单位冲激响应 $h(t)$。

**解：**

先求前向通路 $H_1(s)$：

$$h_1(t) = (2e^{-2t} - e^{-t})u(t) \ \leftrightarrow\ H_1(s) = \frac{2}{s+2} - \frac{1}{s+1} = \frac{s}{(s+1)(s+2)}$$

由 s 域框图，正反馈系统：

$$Y(s) = H_1(s)[X(s) + kY(s)]$$

$$Y(s) - kH_1(s)Y(s) = H_1(s)X(s)$$

$$H(s) = \frac{Y(s)}{X(s)} = \frac{H_1(s)}{1 - kH_1(s)} = \frac{\dfrac{s}{(s+1)(s+2)}}{1 - \dfrac{ks}{(s+1)(s+2)}}$$

$$H(s) = \frac{s}{(s+1)(s+2) - ks} = \frac{s}{s^2 + 3s + 2 - ks} = \frac{s}{s^2 + (3-k)s + 2}$$

① 分母 $D(s) = s^2 + (3-k)s + 2$。二阶系统稳定的充要条件（Routh-Hurwitz）：所有系数同号且 $> 0$。

$D(s)$ 中 $a_2 = 1 > 0$，$a_1 = 3 - k$，$a_0 = 2 > 0$。只需 $a_1 > 0$：

$$3 - k > 0 \quad \Rightarrow \quad \boxed{k < 3}$$

② 临界稳定时 $k = 3$，此时 $a_1 = 0$，极点位于虚轴。

$$H(s) = \frac{s}{s^2 + 2},\quad \text{极点}: s = \pm j\sqrt{2}$$

$$\boxed{h(t) = \cos(\sqrt{2}\,t)\,u(t)}$$

（由 $\mathcal{L}\{\cos(\omega_0 t)u(t)\} = \dfrac{s}{s^2 + \omega_0^2}$ 直接得出。）

## 八、微分方程与系统综合

**已知某因果 LTI 系统的微分方程为：**

$$y''(t) + 4y'(t) + 3y(t) = x'(t) + 2x(t)$$

**求：**

① 系统的 $H(s)$，零、极点图；

② $y(0^-) = y'(0^-) = 1$，$x(t) = e^{-2t}u(t)$ 时 $y(t)$；

③ 当激励 $x(t) = u(-t) + 2u(t)$ 时求 $y(t)$；

④ 画出模拟框图。

**解：**

① 对微分方程取拉氏变换（零初始状态）：

$$s^2Y(s) + 4sY(s) + 3Y(s) = sX(s) + 2X(s)$$

$$H(s) = \frac{s + 2}{s^2 + 4s + 3} = \frac{s + 2}{(s + 1)(s + 3)}$$

零点：$s = -2$。极点：$s = -1,\ s = -3$。

零极点图（s 平面）：实轴上 $s=-2$ 处有零点（○），$s=-1$ 和 $s=-3$ 处各有极点（×）。

② 已知 $y(0^-) = y'(0^-) = 1$，$x(t) = e^{-2t}u(t)$ → $X(s) = \dfrac{1}{s+2}$。

带初始条件的拉氏变换：

$$[s^2Y - s y(0^-) - y'(0^-)] + 4[sY - y(0^-)] + 3Y = (s+2)X$$

$$(s^2 + 4s + 3)Y - (s + 5) = (s+2)X$$

代入 $X(s) = 1/(s+2)$：

$$Y(s) = \frac{1 + (s+5)}{s^2 + 4s + 3} = \frac{s + 6}{(s+1)(s+3)}$$

部分分式展开：

$$\frac{s+6}{(s+1)(s+3)} = \frac{5/2}{s+1} - \frac{3/2}{s+3}$$

$$\boxed{y(t) = \left(\frac{5}{2}e^{-t} - \frac{3}{2}e^{-3t}\right)u(t)}$$

③ $x(t) = u(-t) + 2u(t)$。

利用叠加原理，分别求两个分量的响应。

**分量一：** $x_1(t) = u(-t)$，$X_1(s) = -\dfrac{1}{s}$，ROC: $\text{Re}\{s\} < 0$。

$$Y_1(s) = H(s)X_1(s) = -\frac{s+2}{s(s+1)(s+3)}$$

部分分式展开（ROC: $-1 < \text{Re}\{s\} < 0$）：

$$-\frac{s+2}{s(s+1)(s+3)} = -\frac{2/3}{s} + \frac{1/2}{s+1} + \frac{1/6}{s+3}$$

- $-\dfrac{2/3}{s}$，ROC $\text{Re}\{s\} < 0$ → $\dfrac{2}{3}u(-t)$
- $\dfrac{1/2}{s+1}$，ROC $\text{Re}\{s\} > -1$ → $\dfrac{1}{2}e^{-t}u(t)$
- $\dfrac{1/6}{s+3}$，ROC $\text{Re}\{s\} > -1$ → $\dfrac{1}{6}e^{-3t}u(t)$

$$y_1(t) = \frac{2}{3}u(-t) + \left(\frac{1}{2}e^{-t} + \frac{1}{6}e^{-3t}\right)u(t)$$

**分量二：** $x_2(t) = 2u(t)$，$X_2(s) = \dfrac{2}{s}$，ROC: $\text{Re}\{s\} > 0$。

$$Y_2(s) = \frac{2(s+2)}{s(s+1)(s+3)} = \frac{4/3}{s} - \frac{1}{s+1} - \frac{1/3}{s+3}$$

ROC: $\text{Re}\{s\} > 0$（均为右边信号）：

$$y_2(t) = \left(\frac{4}{3} - e^{-t} - \frac{1}{3}e^{-3t}\right)u(t)$$

叠加得全响应：

$$y(t) = y_1(t) + y_2(t) = \frac{2}{3}u(-t) + \left[\frac{4}{3} - \frac{1}{2}e^{-t} - \frac{1}{6}e^{-3t}\right]u(t)$$

（可验证 $y(0^-) = y(0^+) = 2/3$，$y'(0^+) = 1$，满足微分方程。）

$$\boxed{y(t) = \frac{2}{3}u(-t) + \left(\frac{4}{3} - \frac{1}{2}e^{-t} - \frac{1}{6}e^{-3t}\right)u(t)}$$

④ 模拟框图。令中间变量 $W(s) = \dfrac{X(s)}{s^2 + 4s + 3}$，则 $Y(s) = (s+2)W(s)$。

时域表示为 $w'' + 4w' + 3w = x$，$y = w' + 2w$。框图如下：

## 九、由零极点求系统函数

**【例 6.20】** 有一因果稳定 CT 系统，其 $H(s)$ 的零、极点如图 6.12 所示，已知当 $x(t) = |\cos t|$ 时，系统输出的直流分量为 $\frac{5}{\pi}$。

**图示信息（图 6.12）：**

- 零点（○）：$\sigma = 2$（即 $s = 2$）
- 极点（×）：$s = -1 + j2$ 和 $s = -1 - j2$，以及 $\sigma$ 轴负半轴上有一个极点（具体数值未知，设为 $s = p$）。

**求：**

① 系统的 $H(s)$；

② 当 $x(t) = 1$ 时，系统的输出 $y(t)$。

**解：**

① 由零极点信息，设系统函数为：

$$H(s) = K \cdot \frac{s - 2}{(s + 1 - j2)(s + 1 + j2)(s - p)} = K \cdot \frac{s - 2}{(s^2 + 2s + 5)(s - p)}$$

系统因果稳定，极点均在左半平面 → $p < 0$。

利用直流分量条件求 $H(s)$。$| \cos t |$ 是周期为 $\pi$ 的周期信号，其直流分量（平均值）为：

$$\text{DC}_{\text{in}} = \frac{1}{\pi}\int_0^\pi |\cos t|\,dt = \frac{2}{\pi}\int_0^{\pi/2} \cos t\,dt = \frac{2}{\pi}$$

LTI 系统输出直流分量：$\text{DC}_{\text{out}} = H(0) \cdot \text{DC}_{\text{in}}$。已知 $\text{DC}_{\text{out}} = \dfrac{5}{\pi}$，故：

$$H(0) \cdot \frac{2}{\pi} = \frac{5}{\pi} \quad \Rightarrow \quad H(0) = \frac{5}{2}$$

而 $H(0) = K \cdot \dfrac{0-2}{5 \cdot (-p)} = \dfrac{2K}{5p} = \dfrac{5}{2}$，得 $K = \dfrac{25}{4}p$。

$$\boxed{H(s) = \frac{\frac{25}{4}p\,(s - 2)}{(s^2 + 2s + 5)(s - p)},\quad p < 0}$$

② 当 $x(t) = 1$（对所有 $t$）时，系统处于稳态，输出为直流响应：

$$y(t) = H(0) \cdot 1 = \frac{5}{2}$$

$$\boxed{y(t) = \frac{5}{2}}$$
